# Smoke Test Suite

Comprehensive smoke tests for the quant_projects platform.

## Overview

This test suite verifies basic functionality across all packages and should complete in under 2 minutes. It's designed to quickly validate that the system is operational after changes or in a new environment.

## Test Coverage

### 1. Package Imports (`test_imports.py`)
- All 4 core packages import successfully (dataaccess, factor_engine, factor_optimizer, quant_evaluator)
- Key exports are accessible
- Version information is available

### 2. Backend Availability (`test_backends.py`)
- **numpy**: Core numerical computing (required)
- **numba**: JIT compilation for performance
- **polars**: High-performance dataframes
- **cupy**: GPU acceleration (optional, skipped if unavailable)
- **pandas**: Data manipulation
- **duckdb**: SQL analytics engine

### 3. Basic Workflows (`test_workflows.py`)
- DataAccess: Store initialization and basic operations
- FactorEngine: Basic functionality checks
- FactorOptimizer: Import and initialization
- QuantEvaluator: Metrics calculation readiness

### 4. CLI Tools (`test_cli_tools.py`)
- Python scripts: Syntax validation and --help flag support
- Shell scripts: Bash syntax validation

### 5. Documentation (`test_documentation.py`)
- Main README existence
- Package documentation
- Docs directory structure
- Markdown file readability (including Chinese)

### 6. Benchmarks (`test_benchmarks.py`)
- Benchmark scripts exist and have valid syntax
- Benchmark documentation is available
- Results analysis tools are present

## Running Tests

### Quick Run
```bash
cd /home/shw/quant_projects
python3 tests/smoke/run_smoke_tests.py
```

This will:
- Run all smoke tests
- Generate a detailed report at `tests/smoke/SMOKE_TEST_REPORT.md`
- Exit with code 0 if all tests pass

### Manual Pytest
```bash

python3 -m pytest tests/smoke/ -v

# Run specific test category
python3 -m pytest tests/smoke/test_imports.py -v

python3 -m pytest tests/smoke/test_benchmarks.py -v
```

## Performance Target

Target: < 2 minutes  
Typical: 5-15 seconds

## Skipped Tests

Some tests are expected to be skipped in certain environments:

- **cupy tests**: Skipped when no GPU is available
- **Full workflow tests**: Skipped when optional dependencies are missing
- **Version tests**: Skipped for packages without version metadata

Skipped tests do not indicate failure.

## Test Philosophy

These smoke tests follow these principles:

1. **Fast**: Complete in seconds, not minutes
2. **Broad**: Cover all major packages and functionality
3. **Forgiving**: Skip when optional dependencies are missing
4. **Informative**: Provide clear failure messages
5. **Automated**: Can run in CI/CD pipelines

## Adding New Tests

When adding new smoke tests:

1. Keep them fast (< 1 second per test)
2. Use `pytest.skip()` for missing optional dependencies
3. Test import and basic initialization, not full functionality
4. Add to the appropriate test file or create a new category
5. Update this README with the new test category

## Troubleshooting

### Common Issues

**ImportError for packages**: Some packages may have missing dependencies. Install with:
```bash
cd package_dir
pip install -e .
```

**ModuleNotFoundError for internal modules**: Some packages have complex internal structure. Smoke tests use try/except to skip gracefully.

**Timeout on benchmark help**: Some benchmarks have heavy imports. Smoke tests now check syntax only.
