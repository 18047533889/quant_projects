# 有界因子轴物化：复用与身份边界

实现集中在 `adapters/source_axis_materializer.py`，公共函数签名不变。

当源轴并非精确匹配、`memory_bounded=True`，且共同轴与目标轴一致时，
共同轴校验已经产生最终所需的位置数组，直接复用，无需再查一次位置。
打乱轴的适用测试中，显式 `get_indexer` 调用从 4 次降到 2 次。
共同轴大于目标轴时仍单独查目标位置；无界路径仍保留 pandas reindex
的快照语义，输出与输入共享存储的处理没有放宽。

复用和普通位置查找共用原来的连续切片判断。即使目标只是源面板的
连续子块，也不会为了减少查找而退化成大规模 fancy-index 拷贝。
对无界路径观察到的额外两次查找来自 pandas reindex，不是 Index.equals。

## 修复的身份碰撞

pandas `Index([1]).equals(Index([True]))` 可为 True，但整数源轴的位置
查找会拒绝布尔目标。仅使用 equals 会错误地复制另一个身份的值。
现在精确轴快速路径与位置复用均增加布尔/非布尔区分；日期和资产轴、
有界和无界写入均有回归。NumPy 整数与 Python 整数仍保持兼容。
