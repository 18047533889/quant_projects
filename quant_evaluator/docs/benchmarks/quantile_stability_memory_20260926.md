# quantile_stability 日期对分块：内存 A/B（2026-09-26）

compute_quantile_rank_stability 在每个因子上比较有效日期的所有无序对，
并在两日共同有限分位桶上重新排名后计算 Spearman 相关。
修复前虽然相关计算分块，仍在循环前展开所有日期对的收益和掩码；
多年历史使这部分临时数组按日期数平方增长。

本次只把日期对的输入收集移入原有 65,536 对分块，保留
np.triu_indices 的配对次序、排名公式、相关计算及最终有限值均值。
因此不是算法复杂度优化；日期对数量仍为 T(T-1)/2。
