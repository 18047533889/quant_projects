不同定义可以共存，但不得在同一 ID、阈值或结果标签下混用。此次不降低外部挖掘 gate，不发布生产因子，不重跑历史大数据。

## 2. 统一符号与输入合同

- 因子面板 X[t,n,f]：时间、资产、因子三个轴。标签 Y[t,n]；有效配对由因子/标签 validity 及有限值共同决定。
- 因子方向在训练窗决定并冻结。不得看测试表现后翻号。负 IC 表示反向关联，不自动取绝对值。
- 标签显式提供 decision_time、label_start_time、label_end_time。QE 不猜测已经 shift 几次；跨 split 尚未成熟标签应由合同排除。
- 日期只按实际输入/交易日历解释；252 是年化频率约定，不表示252自然日。自然月统计与21个观测块必须区分。
- NaN/无效证据不等于0。缺失不得进入平均值分母；报告应同时给 observation_count、sample_unit、valid/status/reason。
- 元数据中的 registry status=stable 不等于交易可执行或 GPU 已认证。实验性、unsupported、纯诊断项不可直接当生产筛选标准。

## 3. IC、RankIC 与稳定性

每日 Pearson：

```math
IC_t=\frac{\sum_{i\in V_t}(x_{ti}-\bar x_t)(y_{ti}-\bar y_t)}{\sqrt{\sum_{i\in V_t}(x_{ti}-\bar x_t)^2\sum_{i\in V_t}(y_{ti}-\bar y_t)^2}}
```


其中 $`V_t`$ 是当日因子与标签共同有效的资产集合；均值仅在这个集合内计算。
按日独立计算，常量截面不可用；不将整张stock-date面板展平后求相关。
RankIC 是同日有效配对的平均并列秩之间 Pearson，即 Spearman，不是相关系数的绝对值。

公开注册指标 pearson_ic / rank_ic / 两种 daily series，以及 ICSeries 派生指标，默认至少20个配对/日。
原始低层 compute_daily_ic 仍可用显式 min_assets，不能把低层实验参数误当公开默认。
公开 mean 默认至少1个有效日；IR/标准差等通常至少20日。均值可用而IR不可用是允许的，不代表日期筛选不同。
同一族 finite daily series 的均值与 IR 分子使用相同日期；IR=mean(IC)/std(IC,ddof=1)。
IR 不年化；恰好恒定序列不可用。很小但非零标准差不能随意阈值抹为0。

CPU公开接口复用(method,min_assets)缓存；GPU按同样门槛构造序列。结果 provenance.ic_sample_policy 记录method、min_assets、等权、IR ddof与不年化标识。
对显式不同 min_assets 的请求，定义本来就不同；不得只比较数值而忽略策略。需要统一覆盖时，对均值与IR都传相同 min_assets。
每个指标自己的 min_periods 仍控制是否输出，不改变逐日 IC 的有效配对集合。

IC std、正比率、滚动均值/IR、中位数、近期与历史差、符号一致性等详见逐指标目录。
t值/普通p值、HAC、block bootstrap分别依赖不同独立性/相关性假设，不能将raw ICIR直接称为显著性概率。
多重检验必须绑定实际候选族；p值数量相等不能证明成员真实性。

## 4. 分桶与形状指标

桶号从低因子到高因子，0为最低组、Q-1为最高组。分位边界并列值策略是计算定义的一部分；不能未声明就用 rank(first) 打散并列值。
同值可能集中到一桶；空桶为缺证据，不补0，也不假称每桶恰好N/Q只。
统计分桶收益以有效标签计算，和交易组合先选仓后估值不是同一对象。
QuantileReturnArtifact派生形状默认Q=5、每桶有效样本至少10、每桶有效日通常至少20；请求的quantile_builder_parameters可覆盖。各桶均值可能来自不同日期，必须披露。

令各组时均收益为 g_q：
- quantile_monotonicity = count(g[q+1]>g[q]) / 有效相邻对数。范围[0,1]，平坦与全降都为0，无有效相邻对为NaN。
- [0,1,2,3,4,5,6,7,8,-100] 的相邻比例为8/9，不能称“强且平滑的正向因子”。
- 新增 quantile_rank_monotonicity 是 Spearman(q,g_q)，范围[-1,1]，平均并列秩；至少3桶且全部桶均值有限，否则NaN，平坦也NaN。适用于需要方向含义的筛选，和相邻比例不互换。当前CPU公开入口支持，不冒充已验证CUDA实现。外部gate需显式换指标名，并独立核定阈值。
- 曲率是有效连续三桶二阶差分均值；尾部不对称是(g_top-g_mid)-(g_mid-g_bottom)。
- adjacent spread 是相邻差绝对值均值；cliff是边缘差，二者不能替代收益幅度、风险或覆盖。
- quantile_spread=g_top-g_bottom 是统计差，不是默认100%总敞口组合收益。

日单调性比例、跨窗口形状稳定性、bootstrap rank agreement又是不同对象。
应联合看组收益曲线、Top-Bottom、有效桶/相邻对数、桶内人数和各桶有效日；不要用单一分数遮蔽尾组暴跌。

## 5. 组合时钟、资本与成本

### 5.1 独立 cohort 研究组合

信号日t选择，按delay交易期入场，持有H期。示例delay=1,H=1：t+1入场，t+2取得一期收益并到期；周末不是额外交易期。
持有期收益输入记在区间结束时，不能把已经按信号日对齐的未来标签再当日收益传入。
重叠H期cohort分配资本；多空默认每批+0.5/-0.5，不是+1/-1。
cohort自带入场/退出成本，即使相邻cohort持有相同资产也不净额合并；窗口末未到期按ongoing政策，不虚构退出。
H=1、每侧c=0.0025的同仓稳定批次会有入场0.25%+退出0.25%，目标换手却为0；这是研究交易假设，不是真实连续持仓成本。
不应宣称该成本包括冲击、印花税、滑点、借券、融资、成交约束。

### 5.2 连续目标组合

半L1目标换手：


```math
\tau_t=\frac12\sum_{i=1}^{N}|w_{ti}-w_{t-1,i}|
```


其中 $`w_{ti}`$ 是第 $`t`$ 期资产 $`i`$ 的目标权重。首期缺少前仓时为NaN；若要计算初次入场，应显式提供零仓前值。
每笔买卖单边费率c对应成交名义量sum(abs(delta w))，费用为c*sum(abs(delta w))，不是未经解释的c*tau。
目标权重没有交易前价格漂移，不等于实际成交额，不能标作逐笔真实成本。
rank proxy权重按有效因子的平均秩归一化；有效日期中缺信号资产明确为零proxy权重，不足人数的整日保持未知。
通用权重接口的任何未知坐标使该次总换手未知；显式零权重才能代表现金/退出，不能对共同有限子集求和后报低换手。
position-size weighted turnover另有归一化分母，是诊断量，不能拿来替代成交费用。

### 5.3 缺失收益

strict持有组合先用信号选仓，再检查持仓估值；未知估值不等于0。交易资格与估值可用性是两种合同。
legacy compute_long_short_returns默认zero_fill是兼容假设；drop仅统计有标签资产，也可能改变被评估集合。新接线优先明确严格策略或cohort/等总敞口接口。
整个报价轴fail与仅持仓未知两种拒绝范围不同，调用前需读逐项默认参数。未交易资产缺报价不必意味着已持仓无法估值。

## 6. 收益、风险与年化

财富 `W_0=1; W_t=W_(t-1)*(1+r_t)`。破产达到零后吸收，不允许负净值经过再次相乘“复活”。
累计收益为W_T-1；CAGR为 `exp(sum(log1p(r))*A/T)-1`，A一般252，T必须对应本接口的有效观察期/明确时钟。
drop缺失会压缩观测时间，不可宣称真实日历年化；保留时钟/覆盖一起报告。

相对超额财富 `W_top_net/W_benchmark-1`，不是 `prod(1+r_top-r_benchmark-cost)-1`。
单期Top10%、基准5%：相对财富4.7619048%，算术主动收益5%。两者都可研究，名称必须区别。
基准为输入资产轴等权时不得写沪深300；不以稀疏因子标签共同有效集动态决定基准。

最大回撤为正损失幅度，含初始本金：


```math
W_0=1,\qquad P_t=\max_{0\le s\le t}W_s,\qquad \mathrm{MDD}=\max_t\left(1-\frac{W_t}{P_t}\right)
```


其中 $`W_t`$ 为净值，$`P_t`$ 为包含初始本金的历史最高净值。
[-10%,0,+5%]最大回撤10%，不能因第一日是序列起点就漏掉。外部负号展示可用-10%，但须保持阈值方向。
绝对净值回撤与相对基准财富回撤是不同风险对象；旧-30%门槛不能无解释沿用。

Sharpe为平均单期超额收益/样本标准差 * sqrt(A)，常见默认年无风险利率按A线性摊分。长期重叠持有、自相关下sqrt(A)不是无条件精确。
raw ICIR与Sharpe名称、样本单位和阈值不同。0.5倍正尺度不改变无成本Sharpe，但融资与成本会改变结果。
Sortino需声明MAR及下行分母；Calmar为同一CAGR/正MDD，零回撤不输出伪无穷。
VaR/CVaR的置信水平、经验分位插值和正损失/负收益符号遵照具体函数，不能仅看“95”推断。
回撤持续期、恢复期、underwater面积、最差日历月/季/年与滚动窗口各有不同分母，见完整目录。

## 7. 其他指标族的阅读方式

- 覆盖/质量：分子是哪个有效集合、分母是全轴还是可交易集必须明确；不得跨因子平均后当单因子覆盖。
- 分布：均值/方差/偏度/峰度、分位数、极端比例、集中度均是信号或收益特定对象的统计，不是利润。
- 时间稳定性：滞后相关、变化强度、窗口统计只说明稳定性，不证明预测能力。
- 暴露：输入行业/风险因子必须PIT；回归载荷和中性化IC不等于已实现交易中性。
- 交互：成对相关、条件增量、互补/替代需声明比较集与共同样本；不能将矩阵隐式汇总为标量赢家。
- 泛化：训练/验证/测试、retention/delta等绑定明确证据；禁止测试集调参。
- 检验：HAC、bootstrap、FDR/多重比较必须披露参数与族，指标status并不替代方法适用性。
- MI：本次不恢复CogAlpha展平互信息；未计算只可标not_computed，不写成“实测mi=0”。

## 10. 三个可手算的例子

### 换手：半 L1 与费用不是同一个数

两只资产上期权重 $`(0.6,0.4)`$，本期权重 $`(0.2,0.8)`$：


```math
\tau=\frac12\bigl(|0.2-0.6|+|0.8-0.4|\bigr)=0.4
```


换手率为40%，买卖成交名义量合计80%。若每笔成交单边费率为0.1%，此例费用占本金的比例为：


```math
C=0.001\times(0.4+0.4)=0.0008=0.08\%
```


这只解释连续目标权重口径，不替换上文独立 cohort 的入场/退出计费模型。

### 相对财富：不是直接相减

策略净收益10%、基准收益5%，从相同初始本金开始：


```math
R_{\mathrm{relative}}=\frac{1.10}{1.05}-1\approx4.7619\%,\qquad R_{\mathrm{active}}=10\%-5\%=5\%
```


两个数各有用途，但不是同一指标。多期时应先明确是在复利财富上取比值，还是在逐期主动收益上做统计。

### 单调性：方向分数与相邻上升比例不同

三桶平均收益依次为 $`(3\%,2\%,1\%)`$：两对相邻桶均未上升，而桶序与收益秩完全反向。


```math
M_{\mathrm{adjacent}}=\frac{0+0}{2}=0,\qquad M_{\mathrm{rank}}=\mathrm{Corr}((1,2,3),(3,2,1))=-1
```


若三桶都为1%，相邻严格上升比例仍为0，但有符号相关系数因零方差不可用，不应填成0。这里的三桶数值是假定已满足分桶样本要求后的均值。
