# 量化平台使用总览

> **这是 monorepo 总入口文档。** 读数据走 `data_access`，算因子走 `factor_engine`，数据真源在 COS / 本地镜像。  
> 更新日期：2026-07-19  
> 仓库：https://github.com/18047533889/quant_projects

---

## 0. 先分清三件事

| 你要做什么 | 用什么 | 详细文档 |
|------------|--------|----------|
| 读 A 股 / 美股 / 因子 Parquet | **`data_access`**（`get_store()`） | [dataaccess 用户手册](../dataaccess/docs/用户使用手册.md) |
| 用 DSL / 算子批量算因子并落盘 | **`factor_engine`** | [FactorEngine 完全指南](../factor_engine/docs/FactorEngine完全指南.md) |
| 同步 COS、部署读数服务、投递校验 | **scripts / service** | 下文第 5–7 章 |

**路径约定（务必记住）：**

| 说法 | 含义 |
|------|------|
| 磁盘目录 | 仓库里是 **`dataaccess/`**（无下划线） |
| Python 包名 | 代码里永远写 **`from data_access import ...`** |
| pip subdirectory | monorepo 安装用 `#subdirectory=dataaccess` |

```text
COS Parquet（A股 LQTP / 美股 Massive）
        │
        ▼
 dataaccess/  ←→  import data_access
   get_store() · datasets.yaml · COS mirror/remote · DuckDB
        │
        ▼  data_source.type: data_access
 factor_engine/
   DSL → planner → backend → MultiIndex Series → factor lake / staging
```

## 2. 读数据：`data_access`（日常 80%）

### 2.1 本地读

```python
from data_access import get_store

store = get_store()
df = store.read_frame(
    "ashare_stock_daily",
    columns=["TradeDate", "Symbol", "Close"],
    time_range=("2024-01-01", "2024-01-31"),
)
# 宽表列（因子引擎常用）
cols = store.load_columns(
    "ashare_stock_daily",
    columns=["Close", "Volume"],
    time_range=("2024-01-01", "2024-06-30"),
)
```

### 2.2 常用数据集名

以 `dataaccess/config/datasets.yaml` 为准。常见：

| 数据集 | 用途 |
|--------|------|
| `ashare_stock_daily` | A 股日线价量 |
| `us_stocks_sip_day_aggs` | 美股日线 |
| `factor_lake` / `factor_lake_staging` | 已发布 / 草稿因子 |

完整清单与字段：见用户手册第 5–6 章。

### 2.3 COS 远程读（无本地全量镜像）

```bash
export DATA_ACCESS_COS_READ_MODE=remote   # 或 auto
export DATA_ACCESS_COS_S3_ENDPOINT=cos.ap-guangzhou.myqcloud.com
export COS_SECRET_ID=...
export COS_SECRET_KEY=...
```

PIT / 面板语义见 [COS语义与PIT契约.md](../dataaccess/docs/COS语义与PIT契约.md)。

### 2.4 读 → 算 → 写（不改源数据）

```python
store.compute_and_write(
    "SELECT TradeDate AS datetime, Symbol AS asset, Close AS value, "
    "CAST(strftime(TradeDate, '%Y') AS INTEGER) AS year FROM {{ashare_stock_daily}}",
    read_datasets=["ashare_stock_daily"],
    read_time_ranges={"ashare_stock_daily": ("2024-01-01", "2024-01-31")},
    write_dataset="factor_lake_staging",
    factor_id="close_raw_v1",
    partition_by=["year"],
)
# 晋升全员可见：store.publish_from_staging(...)
```

### 2.5 HTTP 远程读数（同事机不必 clone 全库）

**服务端**（有数据盘的机器）：

```bash
source env.sh
pip install -e "./dataaccess[service]"
export DATA_ACCESS_API_KEY=团队密钥
data-access-server --host 0.0.0.0 --port 8765
# Docker：见 dataaccess/deploy/README.md
```

**客户端**：

```bash
pip install "data-access[client] @ git+https://github.com/18047533889/quant_projects.git#subdirectory=dataaccess"
```

```python
from data_access.service.client import DataAccessClient
client = DataAccessClient("http://读数服务器:8765", api_key="团队密钥")
df = client.read_frame("ashare_stock_daily", columns=["Close"], time_range=("2024-01-01", "2024-01-31"))
```

主要 HTTP 接口：`/health` `/v1/datasets` `/v1/read` `/v1/read/arrow-stream`。

## 3. 算因子：`factor_engine`

### 3.1 最小 Python 示例（A 股）

```python
from api import col, rank, ts_mean
from api.factor import Factor
from api.mining_integration import default_ashare_pv_data_source_config
from backend.pandas_backend import PandasBackend
from runtime.engine import FactorEngine
from storage.factory import build_data_source

source = build_data_source(
    default_ashare_pv_data_source_config(
        start_date="2024-01-01",
        end_date="2024-06-30",
    )
)
engine = FactorEngine(backend=PandasBackend(), data_source=source)
factor = Factor(name="mom3_rank", expr=rank(ts_mean(col("close"), 3)))
out = engine.run(factor)
print(out["result"].head())
```

生产更推荐 **YAML + `FactorEngine.run_from_config` / `materialize_from_config`**，以及批量 `run_many`（见 `factor_engine/runtime/README.md` §8）。

### 3.2 数据源配置（推荐）

```yaml
data_source:
  type: data_access          # 必走登记表，不要硬编码路径
  dataset: ashare_stock_daily
  fields:
    close: Close
    volume: Volume
  start_date: "2019-01-01"
  end_date: "2026-06-30"
backend:
  type: auto                 # DuckDB SQL 下推 + Polars/Pandas fallback
```

快捷 preset：`default_ashare_pv_data_source_config()`、`default_ashare_pv_valuation_data_source_config()` 等（`api/mining_integration.py`）。

### 3.3 算子 / DSL 规则

- 白名单：`factor_engine/docs/dsl_operators_reference.md`
- 写法：`docs/算子与导入教程.md`（逻辑用 `and_` / `or_` / `not_`，不要用 Python `and`/`or`）
- 投递契约：`docs/miner_delivery_spec.md`

### 3.4 落盘位置

默认因子湖：`data/factors/lake/`（或 `FACTOR_LAKE_ROOT`）。草稿写 `factor_lake_staging`，发布走 `data_access.publish_from_staging`。

## 4. 端到端：从读行情到因子评估

典型链路（本仓库已有脚本）：

1. **同步数据**：`bash scripts/sync_ashare_lqtp_cos.sh StockDailyBar`

## 8. 常见坑

| 现象 | 原因 / 处理 |
|------|-------------|
| `ModuleNotFoundError: data_access` | 未 `source env.sh` 或未 `pip install -e ./dataaccess` |
| 文档写 `dataaccess/` 找不到目录 | 磁盘目录是 **`dataaccess/`** |
| pip `#subdirectory=data_access` 失败 | monorepo 请用 **`dataaccess`** |
| 读到空表 / 缺文件 | 先 sync COS，或改 `DATA_ACCESS_COS_READ_MODE=remote` |
| 因子算子 parse 失败 | 对照 `dsl_operators_reference.md` 白名单 |
| 直接 `pd.read_parquet` | 禁止；换盘、审计、预算都会失效 |
