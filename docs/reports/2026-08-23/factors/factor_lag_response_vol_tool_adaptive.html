设计意图： Simplifies the parent by replacing the manual EMA volume ratio with the classify_volume_regime active tool, reducing code while preserving the economic mechanism: lagged return amplified by normalized volume and volatility, with regime-adaptive smoothing for robustness in high residual volatility states.

因子路由 / 公式   延迟响应自适应 (vol 工具)

cs_rank(ema((close/ts_delay(close, 5) - 1) * log(vol_ratio) * (atr_20/close), span=10))
依赖列: open, high, low, close, volume, style_gate_resvol_high

📝 计算步骤 (一步一步解释)

  1. 1) ret_5 = (close - ts_delay(close, 5)) / ts_delay(close, 5) 5 日动量
  2. 2) vol_ratio = volume / ts_mean(volume, 20) 量比
  3. 3) atr_20 = ts_atr(high, low, close, 20) 20 日 ATR
  4. 4) atr_norm = atr_20 / close 波动调整
  5. 5) raw = ret_5 * log(vol_ratio) * atr_norm
  6. 6) smoothed = ema(raw, span=10) EMA 平滑
  7. 7) factor = cs_rank(smoothed)
说明：含义: 多窗口动量 × 量能 × 波动率, IC 为负 (反向因子)。字段: ts_atr 见 OP_DOC; ts_delay 见 OP_DOC。
