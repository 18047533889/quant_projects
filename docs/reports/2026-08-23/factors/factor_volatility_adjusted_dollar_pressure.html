设计意图： Volatility-adjusted dollar pressure measures directional dollar imbalance scaled by recent volatility, capturing risk-adjusted buying/selling pressure. EMA smoothing reduces noise, and ATR provides volatility normalization. The rank transform delivers a stable cross-sectional ordering suitable for balanced IC, RankIC, and MI.

因子路由 / 公式   波动调整的美元压力

cs_rank(-abs(ret) * log(volume) / ts_std(20, ret))
依赖列: open, high, low, close, volume

📝 计算步骤 (一步一步解释)

  1. 1) ret = 日收益
  2. 2) abs(ret) * log(volume) 美元压力
  3. 3) ts_std(20, ret) 20 日收益标准差 (波动率)
  4. 4) score = -pressure / vol 负号 + 波动率归一
  5. 5) factor = cs_rank(score)
说明：含义: 压力低且波动率低的标的 → 稳态 → 反向选股 (取负)。

输入字段

字段含义说明

low最低价当日成交最低价；计算日内振幅 / 下影线

volume成交量 (股数)默认未平减；反映参与度
ret日收益(close - ts_delay(close, 1)) / ts_delay(close, 1)

算子

算子含义
absabs(x) → 绝对值
loglog(x) → 自然对数 ln(x)
ts_stdts_std(x, n) → x 在过去 n 天的滚动标准差 (rolling std)
