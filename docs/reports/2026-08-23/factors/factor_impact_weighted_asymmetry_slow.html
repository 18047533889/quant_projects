The slower reference and signal average reduce sensitivity to isolated candle-volume shocks and target the parent's predictive stability and turnover bottleneck while preserving its bounded, scale-normalized economic mechanism and strong l

因子路由 / 公式   慢速冲击加权不对称 (大单不对称)

cs_rank(ema(span=20, sign(ret) * abs(ret) * amount))
依赖列: open, high, low, close, volume

📝 计算步骤 (一步一步解释)

  1. 1) ret = 日收益
  2. 2) sign(ret) * abs(ret) = ret (有方向)
  3. 3) impact = ret * amount 资金冲击 = 方向 × 资金量
  4. 4) smoothed = ema(span=20, impact) 长窗口 EMA 平滑
  5. 5) factor = cs_rank(smoothed)
说明：含义: 慢速资金加权动量; 大资金顺势推动的标的长期占优。

"kw">class="kw">def factor_impact_weighted_asymmetry_slow(df): """Measure smoothed impact-weighted downside asymmetry with a slower baseline.""" df_copy = df.copy() close = df_copy["close"] volume = df_copy["volume"] safe_close = close.where(close > 0.0) prev_close = safe_close.shift(1) safe_volume = volume.where(volume > 0.0) ret = (safe_close / prev_close - 1.0).replace([np.inf, -np.inf], np.nan) dollar_volume = (prev_close * safe_volume).replace([np.inf, -np.inf], np.nan) impact = (ret.abs() / dollar_volume).replace([np.inf, -np.inf], np.nan) impact_base = impact.rolling(30, min_periods=15).median() impact_base = impact_base.where(np.isfinite(impact_base) & (impact_base > 0.0)) relative_impact = (impact / impact_base).replace([np.inf, -np.inf], np.nan).clip(upper=10.0) downside = ret.clip(upper=0.0).pow(2) * relative_impact upside = ret.clip(lower=0.0).pow(2) * relative_impact downside_mean = downside.rolling(30, min_periods=15).mean() upside_mean = upside.rolling(30, min_periods=15).mean() asymmetry = downside_mean - upside_mean total_stress = downside_mean + upside_mean factor = (asymmetry / total_stress.replace(0.0, np.nan)).replace([np.inf, -np.inf], np.nan) df_copy["factor_impact_weighted_asymmetry_slow"] = factor "kw">class="kw">return df_copy["factor_impact_weighted_asymmetry_slow"]
