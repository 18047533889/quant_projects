设计意图： Mutation: replaced absolute return with squared return to amplify larger price moves while preserving the core amount-weighted mechanism. Squared returns emphasize extreme intraday price changes, potentially improving tail sensitivity and signal strength.

因子路由 / 公式   成交额加权平方冲击 (价格变化被资金参与放大)

cs_rank(amount_weighted_mean(close.pct_change()^2, amount))
依赖列: trading_datetime, TradingDay, open_price, high_price, low_price, close_price, volume, amount

📝 计算步骤 (一步一步解释)

  1. 1) close.pct_change() 当日收益率 ret
  2. 2) ret^2 单日波动能量
  3. 3) 用 amount (成交额) 作权重，对 ret^2 在时间维度上做加权平均
  4. 4) factor = cs_rank(...) 截面分位排名
说明：amount_weighted_mean 在 FE DSL 中没有直接算子 → 用通用 ‘金额加权’ 语义近似。含义: 资金参与越重的波动，越值得定价 → 反向因子, 即 IC 为正时代表低冲因子有溢价。
