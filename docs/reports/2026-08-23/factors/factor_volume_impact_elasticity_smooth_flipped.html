设计意图： A 40-session rolling slope measures how strongly price returns co-move with changes in log volume, with the longer window reducing transient covariance noise. Windows with negligible volume variation are excluded instead of using an extremely small denominator, preventing unstable spikes in constant- or near-constant-volume conditions. The signal remains a single-stock OHLCV-derived raw factor.

因子路由 / 公式 ⚠ 已翻转（IC<0）   量能冲击弹性 (平滑, 翻转)

-cs_rank(ema(span=10, abs(ret) / log(volume)))
依赖列: open, high, low, close, volume

📝 计算步骤 (一步一步解释)

  1. 1) elasticity = abs(ret) / log(volume) 单位量能带来的收益弹性
  2. 2) ema(span=10, elasticity) 短窗平滑
  3. 3) 已加负号翻转
说明：低量能但高收益 = 弹性高 = 主力控盘, IC<0 → 翻转。
