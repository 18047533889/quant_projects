设计意图： Simplifies the intraday asymmetry measure by using simple moving averages instead of exponential, reducing sensitivity to recent outliers and improving stability. Window increased to 40 for a more persistent asymmetry signal.

因子路由 / 公式   日内不对称 SMA 比 (下行 SMA / 上行 SMA)

cs_rank(sma_down / sma_up)
依赖列: open, high, low

📝 计算步骤 (一步一步解释)

  1. 1) 把当日 (high-low)/close 分拆为 up 段 (close>open) 和 down 段 (close<open)
  2. 2) sma_down = ts_mean(down_range, 20)
  3. 3) sma_up = ts_mean(up_range, 20)
  4. 4) ratio = sma_down / sma_up 下行/上行幅度比
  5. 5) factor = cs_rank(ratio)
说明：含义: ratio 越大 → 下跌时振幅更大 → 风险越大 → 排名靠后 → IC 为正代表低 ratio 标的占优。
