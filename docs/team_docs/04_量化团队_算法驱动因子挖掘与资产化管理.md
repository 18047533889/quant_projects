## 执行摘要（汇报可整段使用，须与**五安检** 后文可勾选 对齐）

**范式**  
本组**不再** 采用「单手工拍脑袋+单次回测」的作坊式挖因子，而采用 **7×24 多引擎、多偏置** 的**并行** 搜索（**不** 等于**无纪律** 堆回测；**冲突** 与试次**预算** 见[篇三](#P04-part3)）：**结构化演化**（显式公式的可辩护搜索）、**协同强化**（以**组合增量** 而非单因子 IC 为奖励）、**大模型智能体**（假设—代码—审计闭环，**防默写** 公知结构）、**信息论/拓扑**（**非线性依赖** 与**体制切换** 的线索）。四引擎的**搜索偏置** 不同，**合流** 到同一**候选池**，再经统一**五安检** 漏斗。

**五安检（与 [篇四～七、篇十四](#P04-part4) 对齐；汇报只讲名字，细则见后）**  

1. **假发现/复杂度**：**禁止** 以单一 in-sample 指标入库；**DSR/罚复杂度**、**多假设/登记/锁箱**、**超参/窗长敏感性**。  
2. **交易与摩擦**：**净表现** 思维（**扣费/滑点/换手**）；**高换手纸面收益** 无效。  
3. **正交与增量**：对现有核心库的 **边际解释力** 与**相关/残差** 检验；**红海** 因子**不准** 凑数。  
4. **体制与尾部**：在**压测窗** 与 **IC 半衰** 上**可辩护**；**动量/风格拥挤** 的**预警** 与**标签**。  
5. **白盒与量纲**：**经济含义/类别** 可写清；**量纲/语法** 有约束；**无法一句话说清的** 长公式 **低置信**。

**全生命周期**  
因子是**数字资产**：**入池、版本、监控、压缩、重参数、条件化、末位清退**。**末位 5%（可调）+**「**新信号若打不过即将淘汰的末位，则本周期不增库**」**铁律**（见 [篇十一](#P04-part11)），**逼** 团队追求**浓度** 而非**数量**。

**与模型组（03）**  
**模型组**（[03](03_量化团队_模型与实验规范.md)）：在**可辩护** 的 WFO/试次 纪律下，负责**学权重、** **不确定度与交付契约** 规定的输出对象；**消费** 已注册因子池的方式亦在 03 写清。**因子组**（本文）：在入库前**提出候选** 并**完成** 假发现/正交/时间律等**防线** 上的可验收材料。**若** 因子侧在信息集或标签上**一次** 出现**时间维泄漏**（[篇七](#P04-part7) 与 01/02/03 的 PiT/对齐），则模型侧**任何** 再严格的 **OOS 叙述在前提上都不成立**；这不是「可事后用模型调回来」 的问题。**WFO、gap、MLflow** 的**数学与主叙事** 在 03 篇八/八续，**本稿不重复**。

**讲给组员听**  
> 我们**不** 比谁挖得多，我们比谁**漏得少**：机器每秒一万个式子，**真工作** 在**拒绝** 那 99.9% 的「历史巧合」。

|  | 引擎 A 演化 | 引擎 B 协同 RL | 引擎 C LLM/Agent | 引擎 D 信息/拓扑 |
|--|------------|----------------|------------------|------------------|

### 0.3.1 缩写与英文**括注**（**一眼** 能懂，**不** 当定义）

> 作用：正文里 英文/简写 第一次见 若**没** 跟括号，就**以本表** 念中文；**正式定义** 仍以上表 + 长文 为准。与 03 的表 **不逐字相同**（两边分工不同）。

| 文里常见 | **建议读法 / 括注** |
|----------|-------------------|
| **GIGO** | 音读「吉高」可；义：**垃圾进、垃圾出**（上游脏 → 下游**上限** 低）。 |
| **OOS** | *out-of-sample*，**样本外**（**未** 参与调参/选优 的那段）。 |
| **WFO** | *walk-forward*，常口播「**时间向前/多段滚动**」；指「训—验—测」 按**日历** 多折 前推，**与** 混洗 K 折 不是 同一主张（详 03 篇八）。 |
| **HPO** | *hyperparameter optimization*，**超参/结构 搜索**；常接 `trial/试次`、`leaderboard`（八续 纪律）。 |
| **IC / RankIC / ICIR** | 信息系数 / 秩IC / 信息**比**（IC 与噪声**相对** 强度）；**不是** 分类准确率。 |
| **DSR** | *deflated* Sharpe 思路，**经多重试验/复杂度 打折** 的夏普 叙述（篇四）。 |
| **PiT** | *point-in-time*，在时刻 \(t\) **只能** 用 **当时已可得** 的信息（**防** 把未来 混进 历史）。 |
| **TCA** | *trading cost* / *transaction cost* 总称习惯：交易**成本/冲击/滑点** 意识。 |
| **A/B/C** | **03 篇三** 任务 类型；**A** 横截面/日 多票，**B** 时序 为主，**C** 两阶/混合 须写**结构**图。 |
| **TDA** | *topological data analysis*（拓扑数据分析），常用 **持久同调** 等；**贵、** 多落研究档。 |
| **RAG** | *retrieval*-augmented，**检索增强**（加知识库/文档，**不** 等于 不用 回测）。 |
| **AST** | 抽象**语法** 树（看式子 结构/距离 用）。 |
| **PPO** 等 | **RL**=强化学习；PPO/REINFORCE 是**其中** 算法 名，本文只作**方法地图**，**不** 绑实现。 |
| **DSR**（易混） | **Deflated Sharpe**（统计） vs **Deep Symbolic Regression**（引擎 A 系），**勿** 混读。 |
| **GSGP / TGP / LGP** | 遗传/符号 规划 各**流派** 缩写，记「**在式子 空间里 搜**」 即可。 |
| **MAP-Elites / QD** | 多样性/地图 式 搜索 简写；防**全体 挤成 一种形状**。 |
| **Regime** | 市场/宏观 **体制/状态** 分段（**非** 日常口语「政体」）。 |
| **OOS/锁箱** | **锁箱**=事先登记、事后**不** 改口 的 OOS 报告 窗。 |

**常见错用**（**反例**）  
- 把 **回测** 上最好的**单个** 窗当**唯一** 证据。  
- 把**相关** 当 **因果**；把**论文** 的设定当你们**的** 可得数据。

# 篇一 战略、资产流与组织边界

## 1.1 本组在流水线中的位置

**一句话**：**因子组** 负责「**在极低信噪比下持续提出可辩护候选，并通过统一安检** 把**可资产化的 Alpha 特征** 交给下游**模型与策略** 消费」。  

**不做什么**（**越权**）  
- **不** 在组内**单独** 宣布「**可直接上实盘** 的最终仓位」（策略/交易主责+风控）。  
- **不** 以「我们模型」为口径——**消费模型** 的**验证与再训练** 在 [03](03_量化团队_模型与实验规范.md)。

**要做什么**（**本组主责**）  
- 维护**可审计** 的**因子定义、版本、来源引擎、** **数据域、** **PiT 假设**。  
- 维护**淘汰与预警** 规则，让资产库**有代谢**。

## 1.2 从候选到入库的**资产流**（角色/阶段 语言）

```mermaid
flowchart LR
  subgraph eng [多引擎作业]
    A1[引擎A_演化]
    A2[引擎B_协同RL]
    A3[引擎C_LLM多智能体]
    A4[引擎D_信息论拓扑]
  end
  P[统一候选池]
  G[五道安检_漏斗]
  R[注册与版本_元数据]
  D[下游_模型与策略]
  eng --> P --> G --> R --> D
```

**阶段**（**口语** 对照，**非** 对外的**唯一** 定义）  
- **多引擎** 的产出进入 **P（候选池）**；**G（五安检）** 是**可入库** 的**闸门**；**R→D** 是**元数据+版本** 之后**模型/策略** 的**长周期** 消费。  
- **反例**（**已** 含于上条）：**没** 过 **G** 的候选当「**先** 给模型组试试」= **元数据/审计** 上**不成立**，**应** 拒收或**退回** 补登记。

## 1.3 RACI（**简化**，可用团队名替换人名）

| 活动 | 因子组 A | 数据/基座 C | 模型组 R | 策略/交易 I |
|------|------------|-------------|-----------|-------------|
| 因子**定义/版本** | A | C | C | I |
| **PiT/可得日** 事实 | C | A | I | I |
| **入池** 标准 | A | I | C | I |
| **回测/验证口径** 对齐 02/03 | C | I | A | I |

> **A/R/C/I 含义** 以组织惯例为准；**不在此** 贴任何组内**路径**。

## 1.4 与模型组（03）的**责任分界**（**可照念**；**不** 用**行业** 俚语）

- **因子组**（本文）：在**可审计** 流程下**提出** 因子候选，使每一候选具备**可注册** 的**定义、** **数据域、** **PiT/可得、** **版本、** **来源引擎** 与 04/篇二～七 的**防假发现/正交/时间律** 材料；**不** 在本文内**包干** 模型权重的训练与[03]规定的 **HPO/试次** 主叙事。  
- **模型组**（[03](03_量化团队_模型与实验规范.md)）：在[03]的 **WFO+八续** 框架下，对**已注册** 因子池的**消费方式、** 损失/契约与**时序** 可迁移的**OOS 表述** 负主责。  
- **GIGO** 在此处的**可执行** 含义见 [0.3 术语句](#P04-terms) 条：**上游** 的**时间泄漏/假发现/拥挤** 不是「**下游多训几轮**」 就能在**同一** OOS 定义下**消失** 的**随机误差**。

**讲给组员听**  
> 对外交付的**不是** 裸 `series` 一列，而是**能过五安检、** 经济含义在登记里**可写清、** 在未来日历与统计口径上**能辩护** 的**可注册对象** 及其**元数据**。

## 1.5 负责人**补遗**：约束、存量与易漏项（**与** 篇四～七、十～十四 **对读**）

> **定位**：执行摘要与五安检的**展开**；**不** 替代 [篇十](#P04-part10)[篇十一](#P04-part11) 的**流程**正文。文献/报告中的**框架名**（如 **AlphaPROBE**、**CogAlpha**）列在 [§2.0.1a](#P04-engines-methods-grid) 仅作**方法地图**，**不** 表示本组已落地某商业/闭源系统。

- **假发现与试验预算**：**禁止** 以单一 in-sample **IC/夏普** 入库；**Deflated Sharpe**、复杂度罚、**锁箱 OOS**、**八续** 试次登记与 [篇四](#P04-part4) 对表；**早停**：训/验 **IC 断崖** 式子**不** 微调救场。  
- **经济学标签（白盒）**：机器输出式子须能**一句话** 归类（动量/反转/流动性/微观结构…）；**说不清的** 长式=**低置信** 或**研究档**。  
- **增量 > 绝对 IC**：入库看**对核心库** 的**边际**与**残差**；高相关 **> 阈值** → **正交化/Gram–Schmidt/聚类每簇 1–3 个代表** 再交接（[篇五](#P04-part5)）。  
- **摩擦、容量、做空可达**：适应度宜含 **净费** 思想（RankIC−λ·换手 等**通称**，λ **组内**成文）；**流动性 mask**、**大盘/小盘** 分层报告；多空**不对称** 市场须**单独** 报 **多头腿** 与**空头腿**（防「只会做空端」伪 alpha）。  
- **PiT / 公司行为 / 财报可得日**：价格**复权口径**、财报**公告日** 相对**报告期**——与 [篇七](#P04-part7)、**01** 对表；因子组是**时间律** **首道闸**。  
- **引擎与算力**：**子式/AST 哈希缓存**、禁重复求值；算子**向量化**底线；与 [篇八](#P04-part8) **合流** 防 **OOM**。  
- **下游契约**：`Factor_ID`、版本、来源引擎、数据域、换手级别、宇宙与**时间轴**——禁**散装 CSV**（[篇九](#P04-part9)）。  
- **存量（不是只挖新的）**：弱因子 **Meta-factor/压缩**、**动态窗/阈值重寻**（老树送 **B/贝叶斯优化**）、**Regime 条件化** `F'=F·1{状态}`；与 [篇十](#P04-part10) 对表。  
- **代谢**：**IC 半衰**、**拥挤** 代理、**末位 5%+不增库**（[篇十一](#P04-part11)）。  
- **LLM 特有风险**：预训练 **cut-off** 可能导致**隐蔽前视**（把未来宏观当「推理」）；工程上**时间戳阻断**、或将 LLM **限** 在**语法/结构**角色；**多智能体** **不** 替代 **WFO** 主叙事。

### 2.0.1a 四引擎 **方法**（**仅** 通称/框架/算法**列举**）

> **读法**（**不是** 操作手册、**不** 绑定仓库/类/版本/论文数字）：下表从**业界面谱+顶会/期刊通称** **归并** 到 04 的**四**引擎，便于培训「点名」；**同一** 名字只**归一格主战场**（**与** [§2.5](#P04-part2) **扩展**对读）。**监督学习/端到端**（LSTM/Transformer/Mamba 等）是 **03** 主叙事——若用于**产隐式表征** 再**蒸馏** 成可注册式子，在本文 **C/A** 里以 **「后处理链」** 出现，**不** 与「符号候选主生成」混算。  
> **易混**：**Deflated Sharpe**（[篇四](#P04-part4) 记 **DSR**）与 **深度符号回归 DSR**（*Deep Symbolic Regression*，下列 **A** 系）**同名**——读表**看** **章节**。

#### 引擎 A：结构化演化 / 符号系（**显式** 式子/程序/图）

- **经典表示与基线实现**：Koza **TGP**；**LGP**；**STGP**；**CGP**；**GEP/基因表达式编程**；**GGGP/语法引导/ CFG-GP**；**符号回归**；**gplearn**；**gpquant**；**PySR**；gplearn 金融变体。

- **适应度/目标**（**思想名**）：**MSE/IC/RankIC/Sharpe-Ratio GP**；**Liu–Zhou–Zhu** 系 **横截面 Sharpe** 直接极大化。  
- **质量多样性与层次化**：**AutoAlpha**；**层次化热启动**；**PCA-QD**；**MAP-Elites**；**CVT-Map-Elites**；**NSGA-II/III**；**SPEA2**；**IBEA**；**Novelty Search**；**岛屿/多档案**；**词法选择 Lexicase**；**ε-Lexicase**；**Warm-Start GP**。  
- **几何语义与膨胀控制**：**GSGP**；**语义 GP**；*semantic* 类交叉/变异。  
- **表示为 DAG/张量/AutoML**：**AlphaEvolve**；**文法+类型/量纲** 剪枝；**AlphaCFG** 思路。  
- **其他无梯度/混合**：**差分进化 DE**；**CMA-ES**；**模拟退火/爬山**；**GPU-张量/遗传-张量** 式因子评估（**通称**）。  
- **工业种子与算子语汇**（**数据侧** 基准，**非** 引擎可执行体）：**WorldQuant 101 / Alpha101**；**Alpha191**；**Qlib Alpha158**；**Kakushadze 公式** 族。  

#### 引擎 B：协同 RL / 序列决策（**组合增量** 奖励、**RPN-MDP** 等）

### 2.0.2 自读扩写：上表**每一行** 在**交付与验证链** 里**具体** 接哪里（**无** 形象类比，**有** 可核对要点）

**A（结构化演化 / 符号系）在组织里交付什么**  
- **TGP、LGP、GSGP、遗传规划、符号回归** 共同的数学对象，是在**文法/类型系统** 约束下的**可执行表达式的搜索**：个体是一棵语法树或一段程序；适应度 = **样本内/样本外** 的**预测-收益对齐** 指标 + **树深/子式数量** 等**复杂度罚**，有时再加**多样性/地图（QD、MAP-Elites）** 以防群体塌缩到**结构几乎相同** 的高分式。  
- **与 03 的接口（类型 A 最常见）**：试验登记**须** 写明「因子按**交易日×标的** 给出数值，评估以**横截面** 相关/分组为主」。符号引擎的产出进 **FactorLake** 后，对 `transformer_demo` 等管线而言就是**一列** 特征；**不** 要求与 PyTorch 网络**同形**。  
- **可核对例子（**结构，非**收益承诺**）**：一候选式含 `ts_rank(f1,5)` 与 行业去均值叠套时，在 PR/试验说明**必须** 写清：`5` 的**时间延迟** 与 01/02 里**可交易/可得** 的 bar 是否一致、行业归属使用 **PiT 行业** 还是**静态**；否则 [篇四](#P04-part4) 的「可辩护」与 03 篇五/篇八 的**泄漏检查** 无法执行。

**B（组合边际、策略迭代）在组织里约束什么**  
- **PPO、A2C、REINFORCE** 与「**GFlowNet 类思想**」在此行的归类理由，是**把“下一步产什么子式/从库里加哪块” 当成序列决策**；**奖励** 上若写「单因子样本内 IC」，与「库内**已高度同向** 的一堆动量**仍各自 IC 高」 会**不矛盾**——所以本组在管理口径上**显式** 要求**对组合的边际**（例如边际夏普、在固定换手规则下的**增量** 指标），以逼退**模式崩溃/克隆**。  
- **与 04 正交/增量、03 篇七/篇八 的关系**：[04 篇五](#P04-part5) 规定新因子在**去冗余** 后仍有解释力；[03 篇七](03_量化团队_模型与实验规范.md#P03-part7) 把**过拟/体制** 与指标挂钩；[03 篇八](03_量化团队_模型与实验规范.md#P03-part8) 规定**时间向前的 OOS** 主叙述。**RL 训练日志** 里若出现「在测试窗上再调**奖励权重** 直到好看」，在文本归类上**等同** 篇八 的**伪 OOS/段内选优** 问题，**须** 与篇八 8.3.2/八续 的纪律**对读**，04 不另起一套**冲突** 规则。

**C（LLM + 工具链）的硬边界**  
- **AST/结构距**：把表达式解析为树后，在树上定义**与公知/已入库式** 的**近** 与**远**；**近** 未必错，**须** 在登记里**说明** 与公开来源的关系与**改动了哪一步算子/窗口**。  
- **RAG+工具+沙盒回测**：自然语言**只** 当**工作记忆**与**可检索假设** 的壳；**唯一** 可写入注册表的「事实」是**可复现回测/可重复数值实验** 的输出。与 [03 篇六 契约](03_量化团队_模型与实验规范.md#P03-part6-contract) 的接口：进动态池/模型输入的，必须落到**实数向量/分数/分布参数** 的**可检验** 定义，**不得** 仅「模型 JSON」而无**张量/表行** 对应。

**D（信息/拓扑）为什么默认多落研究档**  
- **互信息/转移熵/图消息传递** 的估计在**小样本+强噪+非稳** 下**方差大**；把估计值**直接** 当**生产** 因子，常常等价于在实验说明里**少写** 了**估计**、**窗长** 与**多重** 试次 的[篇四](#P04-part4) 防线。  
- **TDA/持久同调** 作特征时，计算与存储成本**可预见地高**；**在** 未过 04 篇十/篇十四 的**成本与延迟** 评估前，默认标为**研究档**。**与 03 篇八 WFO** 的**不替代** 关系是分工：[03] 的 WFO+gap 是**时序** 上「训/验/测 日历」的**主**可迁移叙述；D 行结果若声称「泛化好」，**仍须** 走同一套**日期** 与**宇宙** 的 OOS 表述，**不能** 用一张信息图**代替** 时间向前多折。

## 2.1 引擎 A：结构化演化与符号系（TGP/LGP/CGP/GSGP 等**地图**）

- **要一句话讲清**：把因子当**可执行结构**，在**算子+终端** 集合里**搜索**；**交叉/变异** 是**无梯度** 探索。  
- **坑 1 代码膨胀**：树/式子**无界变长** → 适应度**虚假抬升** → **篇四** 的复杂度罚与**剪枝** 必配。  
- **坑 2 语法型交叉**：破坏子树 = **误伤** 好模块 → **语法规约+QD**。  
- **GSGP**（**地图项**）：**语义** 几何操作 → 景观**更平滑**；代价常是**可解释** 的直观性**下降** → **对 C 与五安检** 要**对表** 决定**可入库档**。

**反例**  
- 「跑了一百代、树很深、样本内很爽」= **还** 没过 **1/2** 道安检。  

**讲给组员听**  
> 符号系**不保证** 在**全样本** 上**可迁移**；它**只保证** 解在**你声明的** 文法+终端里**可执行**、**可静态** 检查类型与量纲。**可执行、可检查** 仍**不能** 替代 [篇四](#P04-part4) 的**假发现** 防线与[03 篇八](03_量化团队_模型与实验规范.md#P03-part8) 的**时间向前** 叙述。

## 2.2 引擎 B：协同与序列决策（PPO/REINFORCE/分布/ GFlow 思想等**地图**）

- **要一句话讲清**：把「**下一步放哪个 token/子式**」当 **MDP**；**奖励** 不只看单因子 IC，而看 **Δ组合表现**（**边际**）。  
- **坑 模式崩溃**（与 2.0 表同）：**总** 在动量-反转**邻域** 刷奖励 → 库内 **0.9 相关** 一片。  
- **管理句**：**奖励设计** 是因子组**战略**，**不是** 调参**技巧**；需**成文** 与**版本**（见 [篇三](#P04-part3) 试验登记链接思想）。

**反例**  
- 用「池里已经**全是** 动量型」的库，**仍** 以单 IC 当奖励=**鼓励** 克隆。

## 2.3 引擎 C：LLM 多智能体（**假设链**+**式子链**）

# 篇三 7×24 多管线、算力与**冲突** 仲裁

## 3.1 为何**必须** 并行多引擎

- **单引擎**= **单偏置**；在**非稳** 市场，**会** 集体**错在同一个盲区**。  
- **多引擎**= **在「搜索」层** 做 **ensemble of biases**，再**用同一安检** 收束，**不** 是「三套**重复** 回测**同一** 无纪律」。

**反例**  
- 三引擎**各自** 以**不** 可比的数据切片**刷榜**= **三份** 不可比垃圾。

## 3.2 算力**经济学**（原则）

- **先** 省评估：**子式** 去重/缓存/向量化是**组内工程纪律**（[篇八](#P04-part8)），**后** 扩卡。  
- **队列/优先级**（**占位**，由基础设施定）：**生产候选** 评估 **>** **研究** 扫参 **>** 可重复**失败** 的**重复** 试跑。  
- 与**模型组** 的**资源争用**（GPU/大内存）**不** 在 04 定数字；**只** 定**原则**：**训练** 与**挖掘评估** 分**环境** 或**时段**，**不** 互相**顶死** 生产。

**讲给组员听**  
> 7×24 **不是** 7×24 **烧回测**；是 **7×24 有** **纪律** 的**排队** 与**杀低价值作业**。

## 3.3 试验登记、编号与**可辩护** 叙事

- **每** 个「看起来很好」 的结果**必须** 有：**试验 ID、** **假设/引擎、** **数据域与窗、** **与五安检 的对照**、**负向** 结果**至少一行**（[篇四](#P04-part4) 精神，与 03 篇九**哲学** 一致，**不** 抄 03 模板表）。

**反例**  
- 「**昨晚** 跑出 **RankIC=0.15**」但**不** 知**第几次** 试的 → **1** 道安检=**不通过**（多假设没登记）。

## 3.4 与篇二、篇八 的**接口**

- **统一候选池** 的**去重** 与 **Hash** 思想见 [篇八](#P04-part8)；**禁止** 三引擎**重复** 计同一**子式** 占满内存。

## 3.5 管线**画像** 与**争用** 时怎么裁（**占位表**，数字由基础设施定）

> 下表是**给负责人排会** 用的**语言级** 工具，**不** 绑具体集群名。列「典型瓶颈」是**问排查顺序** 用，**不是** 比谁的引擎更高级。

| 管线（与篇二 2.0 对应） | 算力/内存**典型** 型 | 常见瓶颈**症状** | 与模型组**争用** 时**优先** 保谁 |
|-------------------------|------------------------|------------------|-----------------------------------|
| A 演化/公式搜索 | **CPU+RAM** 大，GPU 可低 | 种群里大量子式求值 → **内存/缓存** 抖动 | 若同期有**大模型训练**，**挖因子评估** 让出整段**夜间** 或**独立队列**；**不** 与训练抢同机大内存。 |
| B 协同 RL/组合边际 | **GPU+CPU** 中到高 | **奖励** 方差大、有效轨迹少 → 看似在跑、**不** 产候选 | **同卡** 上**不** 与 03 的**长时** 训练**叠** 同一**进程**；**必须** 分环境或**硬** 时段。 |
| C LLM/Agent | **GPU 显存** + **长时** I/O | 审计/多轮对话 → **尾延迟** 拖垮「登记过的」**固定** 评估 | **可中断** 的**探索** 让路给**有 ID** 的**注册评估**；**不** 用「还在聊」 当**迟交** 借口。 |
| D 信息论/拓扑 | **CPU+定制** 核 | 成对/高阶**统计** 重 → **O(n²)** 感 | **大窗** 全样本**一次** 跑通**前**，**先** 做 [篇四](#P04-part4) 的**子样本** 诚实预检。 |

**裁决三句话**（能写进周会纪要即可）  

1. 有**试验 ID+登记** 的作业优先于**临时**手搓脚本（与 [篇四](#P04-part4) 一致）。  
2. 能证明已做**子式去重/缓存** 的管线优先于**反复**重算同一子式、占满热路径的作业（[篇八](#P04-part8)）。  
3. **可收口的失败**（明确不过某道安检）优先于**长期**驻留的「希望式」调参；后者须被杀或**降级** 到**研究档**。

**讲给组员听**  
> 排队的目的不是**公平** 分**蛋糕**，是**让** 先过安检、**有** 登记的人**不** 被**野路子** 顶死。

# 篇四 评价、假发现与**统计** 纪律

## 4.0 **禁止** 的入库口径（**硬**）

- **只** 报 **in-sample 最优** 的 IC/RankIC/夏普。  
- **无** 试验次数说明的**冠军** 式子。  
- **对** 同一数据**反复** 看结果再**改** 式子/窗（**窥视** 检验集）而不**升级锁箱**。

**管理句**  
> 我们相信**过程可辩护**，不迷信**一个** 好数字。

## 4.1 指标**家族**（**定义写清**）

- **IC/RankIC/ICIR**：与 [03](03_量化团队_模型与实验规范.md) 一致精神；**未来收益定义** 与 **T+N** 与 [02](02_量化团队企业级研发规范.md) **回测** 可交易假设**一致**。  
- **DSR/复杂度罚**：在团队内**显式** 或**隐式** 实施其一：**树深/节点/自由参数/算子** 数进**罚项** 或**否决规则**。  
- **半衰/衰减曲线**：见 [篇十一](#P04-part11)。

**反例**  
- 用**不同** 的**未来** 窗比**不同** 的**候选**= **自嗨** 排行榜。

## 4.2 保留集/检验/锁箱（**思想** 必讲）

- **训练/调** 的窗 **≠** **报告** 的 OOS/锁箱；**一旦** 决定「**收**」某候选，**须** 在**未** 参与**调** 的窗上**预注册** 再报。  
- **不** 与 [03 篇八 WFO](03_量化团队_模型与实验规范.md#P03-part8) 重复定义数学；**只** 强调：**因子** 的**过拟** **叠加** 在模型过拟**上** = **相乘的坏**。

**讲给组员听**  
> **锁箱** 是防你自己：你**最** 想看的那个窗，**最** 可能骗你。

## 4.3 多假设、试次数与**诚实** 的效应量

- **不** 要求人人会算每一篇多重比较修正；**要求** 人人会答：**你一共试了多少** 个**相关** 假设？**哪** 个是**先** 定的主假设？

# 篇五 正交、**增量** 与**红海** 去重

## 5.0 **入池** 的**金标准**（**观念**）

- **不** 是「**又** 一个 0.04 IC」，是「**在** 控住风格/行业/已知因子后，**还** 能解释**残差** 的**那一点**」。

**反例**  
- 与**Top-50 核心** **平均 0.75 相关** 的「新因子」= **不新**。

## 5.1 相关、聚类与**代表** 因子

- **截面** 时间序列的 **Pearson/Spearman** 相关矩阵是**管理工具**，**不** 是**物理真理**。  
- **做法**：**先** 聚类**再** 每类**只留** 代表（或**对代表** 做**正交** 残差入池）。  
- **阈值** 由组**定** 并**写**；**不** 在 04 给** magic number** 当**唯一** 真理。

## 5.2 正交化/残差（**概念**）

- **对** 已知风格/行业/**核心库** 做**回归** 取**残差** 作为**候选** 的**纯净度** 检验。  
- **Gram-Schmidt** 等是**实现** 选项，**不** 要求全员手推公式；**要** 求**能复现** 的**批处理** 描述。

**讲给组员听**  
> **红海** 里**不** 缺「看起来」强的因子，缺**的** 是**另一维** 的**独立** 风险源。

## 5.3 信息论在**去冗余** 的**边界**

- **MI/NMI** 可作**非线** 冗余**信号**；**不** 替代**经济** 解释与**交易** 成本检验（[篇六](#P04-part6)）。

**篇五 小结**  
- PPT 一表：**入池=增量** 四步；一图：聚类+代表。

# 篇八 表达式、算子与**算力** 工程（**原则**，无路径）

## 8.0 **要** 扛住的**工业** 问题

- **组合爆炸** 的**子式** 在**一代** 遗传里**被** 重复评估 **10⁶ 次** → **不** 缓存= **无** 论多少 GPU 都**烧光**。

## 8.1 **子式** 去重/缓存（**思想** 必成文）

- 对**语法树/有向子式** 做**可哈希** 的**归一**（变量顺序、**常数** 归一 等 由工程定）。**命中** 则**不** 重算。  
- **不** 写实现语言；**要求** 在**内规** 里**可验收**「**同一** 子式**一** 次」。

**反例**  
- 实习生**报告** OOM= **8** 章**前** 就该问「**有** 没有**子式** 级** dedup**」。

## 8.2 向量化/原生核/批**处理**

- **组内** 应**有** 算子**库** 的**性能** 基线；**不** 在 04 规定语言。  
- **批** 与**分块** 的**内存** 上界= **与** 篇三 队列**合** 议。

## 8.3 与**多引擎** 的**合流**

- **A/B** 的**高** 吞吐依赖 **8.1**；**C** 的**沙盒** 失败重试 依赖 **8.2** 的**低** 延迟**评估** 管线。

**篇八 小结**  
- PPT 一表：**子式** 去重、向量化、**批** 三行。

# 篇十一 半衰、**拥挤**、**末位 5%** 与 **Sunset**

## 11.0 **IC 半衰** 与**标签**

- 计算 **T+1…T+k** 的**衰减** 曲线；**快** 衰= 标 **High-Decay** 并**提示** 下游**延迟/执行** 要求。

## 11.1 **拥挤** 与 **spread/分化** 预警（**管理** 叙述）

- 当**经典** 风格**多空** 特征**极** 度**收敛**= **动量/风格** **踩踏** 风险**上升**；**不** 给**外** 部**可** 验数字；**要** 在组内**有** **一** 套**可** 计算**的** 代理指标 与**处置** 流程（**降** 权/冷**却** 期/会议）。

## 11.2 **末位 5%** 与**不增** 铁律

- 每**月/季** 以 **边际** 贡献**或** 多目标**分** 排名，**强** 制**清** 库末 **5%**（**比例** 可调，**要** 成文）。  
- **新** 候选**未** 能在**同** 套**正交+摩擦** 规则下**打** 赢**将** 被淘汰**的** 末**位**= **本** 期**不** 增**库**（**可** 设**例** 外**审批** 阀）。

**反例**  
- **只** 加**不** 减= **特征** 表**无** 限**长**= **人** 与**机** 都**慢** 死。

**讲给组员听**  
> 好图书馆的秘诀：借得出去的书，和舍得扔的书，一样重要。

**篇十一 小结**  
- PPT 一屏：**5%** + **不增库** + **半衰/拥挤** 两指标名。
