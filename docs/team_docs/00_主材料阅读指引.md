**建议顺序（先总后分）**

0. **先读** [量化平台使用总览](../量化平台使用总览.md)（安装、读数、算因子、文档地图）。  
1. **再读文档一** [§0 快速导读](01_data_access_duckdb_全量变更与迁移指南.md#0-分钟读懂)（重点 **§0.2** 与**代码示例**），再读 **§1～§4**；要完整 API 时读 **§10**。  
2. 再读**文档二**中的 **[强制]** 与（如适用）**附录 A**。  
3. 若你负责**模型/实验**而不仅是数据管道，再读**文档三**（**模型组专章**；数据与工程**底线**仍以 01+02 为准）。  
4. 若你负责**算法驱动挖因子、因子库与评审、对接模型侧因子质量**，再读**文档四**（与 01/02/03 **分工** 见该文**篇〇**；**不** 展开本仓目录与 API）。  
5. 在 **Claude Code** 中改 `dataaccess/` / `data_access` 或各层读数时，将 skill **加入上下文**后再让 AI 写代码。

**说明**：本文与 skill 中示例一律使用**占位**路径与 `YOUR_*` 数据集名，不假设读者能访问组内内网或内部数据机。
