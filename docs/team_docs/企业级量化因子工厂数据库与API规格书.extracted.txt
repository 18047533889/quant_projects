企业级量化因子工厂数据库与 API 规格书
面向工程组、数据工程组与平台组的字段约束、索引、Schema、接口与错误码规范
本规格书用于把主文档和工程实施附录中的工程对象落到数据库表、索引策略、Schema 协议和 API 合约层面。设计目标是保证字段命名统一、读写边界清晰、结果可复现、服务可幂等、对象可审计，并为未来扩展到基本面、另类数据和超级 Alpha 场景预留足够空间。
第一章 规格书原则
规格原则
原则
说明
强约束输入
上游方法自由演进，但进入因子工厂时必须满足统一 Schema
弱耦合服务
对象模型统一，但注册、评估、标签、路由和特征服务相互解耦
先审计后优化
先保证可回放、可解释、可追责，再做性能极致优化
PIT 优先
所有可能存在历史修订的数据都为 Point-in-Time 查询预留字段
生产隔离
实验态写入和生产态写入必须有物理或逻辑隔离

第十一章 迁移策略与版本升级规则
建议所有数据库表和 API Schema 都有显式版本。字段新增尽量后向兼容；字段删除必须经过双版本过渡期；任何影响历史重放的结构性变更都必须伴随迁移脚本、回滚方案和历史数据验证计划。
结语
数据库与 API 是因子工厂的骨骼系统。若骨骼不稳，再优秀的上游挖掘方法和下游评估逻辑都无法长期稳定运行。建议团队在正式开工前，先以本规格书为基础完成一次字段审查、索引审查、接口审查和回放审查，再进入编码阶段。
