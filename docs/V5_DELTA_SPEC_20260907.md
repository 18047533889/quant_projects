### D01 · 公开组合指标仍可能跨因子错误归因

**P0｜可见源码剩余｜来源：C01**

**为什么保留：** 公开 facade 对 returns-panel 指标用索引0，再将同一值写入全部 factor_id；上游包装器将 LabelBundle 作为 returns。底层多空函数的正确修复不能自动消除这一入口错误。

**实施：**
1. 以已存在的逐因子组合/执行轨迹为收益输入，禁止股票(T,N)标签与组合(T,F)收益互换。
2. 返回按factor_id及metric-instance绑定的值/序列，市场统计只能进入context。
3. 修真实公共入口及FO消费者，不另写一个无人调用的正确函数。

**验收：**
1. f与-f在零成本同规格下保留相反的毛多空PnL；单个与批量一致。
2. 增加无关第三因子不改变原两个结果；LS Sharpe来自各自组合。

**本地已修时：**复用现有代码与相关通过证据关闭，不重复实施。涉及数值、参数或证据定义变化时，仅按依赖关系失效受影响旧制品；政策变化只重评分，不能无故全量重落值。

### D09 · 健康卡空门通过，且门集合没有真正来自政策

**P0｜可见源码剩余｜来源：C08, C07**

**为什么保留：** 序列输入直接返回；默认空tuple使all([])=True；Mapping分支遍历模块INTEGRITY_GATE_IDS，而不是传入policy.admission_floors.integrity_gate_ids。

**实施：**
1. 只改这个实际剩余边界：按用途政策验证required gate覆盖/唯一性/状态/引用。

3. 队列以引用提交，单GPU长驻worker；实盘优先级与全量研究隔离。

**验收：**
1. FULL_AUDIT不隐式少算；100k逻辑清单不用创建100k完整面板数组。
2. 报告真实峰值主机/设备/输出存储与吞吐，不把注释性能当实测。

**本地已修时：**复用现有代码与相关通过证据关闭，不重复实施。涉及数值、参数或证据定义变化时，仅按依赖关系失效受影响旧制品；政策变化只重评分，不能无故全量重落值。

### D28 · 二元信号的RankIC与直接rank的finite语义应统一

**P1｜数值与适用性边界｜来源：C24, C12, C07**

**为什么保留：** GPU Spearman将distinct floor绑定min_obs/2，会拒绝一些数学上可计算的二元信号；rank primitive部分入口仅排NaN而非全部nonfinite，method/axis参数也未完整执行。

**实施：**
1. 把数学可定义（双方至少两个不同有效值）与统计证据足够分开；稀疏离散profile可计算但不虚高可信度。
2. kernel入口统一finite/axis/tie策略；不支持参数显式拒绝。
3. 使用事件组/类别效果作为补充证据，不把高ties一概判差。

**验收：**
1. 二元与连续标签可产生定义正确的ties-aware Spearman，同时标证据限制。
2. Inf与NaN的无效mask一致；不支持method不能悄悄按average跑。

## 2. QE要补什么：四类用途、同一指标权威，不把所有因子都强塞多空

这里的名称是**规范能力名/实例设计**，不是宣称仓库没有对应函数。先用现有 registry、artifact builder、回测执行轨迹绑定；已有正确实现不新增第二份。每项必须注明：`canonical_id / definition_version / output_axes / unit / direction / profile / required_inputs / parameters / min_samples / update_mode / evidence_scope`。

### 2.1 四类画像与调用关系

| profile | 目标 | 应包含 | 不应强行要求 |
|---|---|---|---|
| SIGNAL_DIAGNOSTIC | 因子有没有排序/非线性/事件信息 | 原始IC与RankICIR、10/20层、期限面、覆盖、状态与形状 | 假装可成交的净收益、凭空容量 |
| LONG_SHORT_RESEARCH | 用多空探针表达两端信息 | ±0.5的gross=1探针、两腿归因、成本情景、暴露、风险 | 没借券也叫可执行实盘；高LS必然代表多头好 |
| LONG_ONLY_RESEARCH | 纯多头选股、指数增强或避雷 | 1.0多头组合、基准超额、主动风险、底部排除、净成本 | 所有股票都能做空；一定要LS Sharpe高 |
| MODEL_FEATURE | 为某个指定模型/特征集提供信息 | 固定表示、OOF新增/替换/组删除、输入健康与复杂度 | 每个特征都独立可交易、全截面RankIC必须高 |

`EXECUTABLE_RELEASE`是以上策略用途的进一步认证范围，只有实际股票池、规则、成交、资金、借券与成本证据齐全才能签发；不是换一个profile字符串。原始因子、处理版本、模型表示、具体组合是不同对象；同一因子可以有多个用途结果，不覆盖彼此。

### 2.2 预测与形状：补齐真正有辨识力的证据

| 能力 | 规范定义/输出 | 默认使用与限制 |
|---|---|---|
| RankIC均值与每日序列 | 每时点对同一有效交集内因子/标签做average-tie秩相关，再按预声明时间权重汇总 | 不展平T×N计算一个相关；方向在训练内冻结 |
| RankICIR_raw | 有效每日RankIC的均值 / 样本标准差(ddof=1) | 默认不年化；零方差/不足样本是未定义，不是无穷高分 |
| Pearson IC | 同信息集、同mask的线性相关 | 与Spearman并列诊断，不混同别名 |
| HAC均值区间/t统计 | 对“每日截面IC序列”的均值做相依稳健推断 | T是时点数，不是股票格数；有间断时间要明确处理，不能删日期伪造等间隔 [W04] |
| 预测期限面 | H1/H5/H10/H20各自的IC、分层效应与成熟样本，输出H×F及time证据 | 同时提供共同成熟窗口比较和各期限全可用窗口，不能只给均值或用IC自相关代替 |
| 10/20层剖面 | 逐日逐层收益、人数、可交易人数、效应差及区间 | 同一次合法排序复用；ties不足时减少实际层数，禁止用证券编号强切 |
| 尾部相邻对比 | 顶层相对邻近多层、底层相对邻近多层 | 顶/底改善方向跟随冻结orientation，不用绝对值掩盖变号 |
| U/倒U/不对称/离散型 | 类型、模板效应、样本外一致性、残差 | 类型不是S级/D级；类型检验与修复在开发区完成，验证区只确认 |
| 条件与事件效果 | 已声明event/行业/状态内的IC或收益差、样本和跨事件稳定性 | 条件必须在决策时可知；不能用未来收益定义有利状态 |
| 近期退化 | 最近成熟窗口与不重叠历史参考的差值与区间 | 同时输出数据覆盖/风格变化，不能把缺数据当alpha衰减 |

**避免重复算与重复加分：** RankIC均值、其t统计、RankICIR、IC正比例相关性很强。它们分别表示效应、证据、波动与稳定性，不应在总分中当四份独立alpha重复奖励。HAC/块重采样不是免疫数据挖掘的许可证，仍需搜索族和封存纪律。[W03/W04]

### 2.3 多空评价：必须同时给两腿、风险抵消与成本来源

标准研究探针定义：top集合收益为`R_L`，bottom股票集合的**持有收益**为`R_B`。长短两侧初始名义分别0.5、-0.5，资本分母为预声明NAV，gross exposure目标1.0。`R_L-R_B`是spread诊断，不应与0.5资金配置的实际NAV收益混名。

在不涉及价格漂移/费用的单期固定权重说明下：

\[
R_{LS}=0.5R_L-0.5R_B,
\quad
Var(R_{LS})=0.25Var(R_L)+0.25Var(R_B)-0.5Cov(R_L,R_B).
\]

实际回测使用股数、现金、融资和净额交易，不能每期偷偷重置权重而不计费用。bottom股票收益和short腿PnL符号相反，必须分别命名。

| 多空指标族 | 必须返回 | 重要解释 |
|---|---|---|
| 毛/净收益与NAV | gross、net-base、net-stress各自序列，算术均值和CAGR分开 | 收益期间、gross/net资本、费用和执行都绑定，不复利H期重叠标签 |
| 净Sharpe/Sortino/Calmar | 明确rf、MAR、downside分母、年化与回撤定义 | 默认Sharpe年化仅作描述；串行相关不靠sqrt(252)解决推断 [W01] |
| 长腿贡献/短腿贡献 | 对NAV的有符号PnL贡献、税费/滑点/borrow各自归因 | LS好可能只因为bottom极差；不代表top有正alpha |
| 两腿相关/对冲效果 | `corr(R_L,R_B)`、协方差、LS波动降低量 | 用bottom持有收益计算的相关性与signed-short相关性相反；不统一“相关越低越好” |
| 风格与市场暴露 | net/gross、beta、行业、size、liquidity、集中度及漂移 | 特征已中性不等于组合已中性；不用自报标签免除检查 |
| 下行/尾部/水下 | 最大回撤、ES95、最差真实月、最长水下、删失恢复 | 共同消费同一净值和episode；缺估值不压缩日历 |
| 空头可执行性 | 借券覆盖、费率分布、不可借导致的未成交、召回与替换 | 假设borrow rate≠有券可借；无数据保留研究探针身份 |
| 容量/成本曲线 | 目标资金量下的净效用、参与率、成本分解、break-even | 不用低换手或高相关性直接推算可容纳资金 |

不建议把“长腿和短腿都盈利”作为硬门：在一个市场环境下某腿为负仍可能合理对冲。应检查其是否服务预声明用途，以及组合扣成本后的独立价值和约束。腿贡献占比在总PnL接近0时不要用不稳定的除法；可报告原始贡献及以`sum(abs(contributions))`归一化的描述比例。

### 2.4 纯多头：至少增加/接通以下指标

| 能力 | 公式/内容 | 使用目的 |
|---|---|---|
| 纯多头净收益/NAV | 1.0资金的top篮子或真实优化多头组合，包含现金与费用 | 不是把LS长腿0.5放大一个指标就算完成 |
| active_return | `a_t = r_portfolio_net,t - r_benchmark,t` | 区分市场beta与选股增值；基准类型必须匹配 |
| tracking_error | `std(a_t,ddof=1)*sqrt(P)`，另给未年化与推断口径 | 度量偏离基准的主动风险 |
| information_ratio | `mean(a_t)/std(a_t)*sqrt(P)`；分母0返回未定义 | 不是用组合Sharpe代替；不拿ICIR与portfolio IR比较 |
| beta与回归alpha | 对净超额收益做明确风险因子回归，给HAC区间 | 回归alpha是该模型下的描述，不等于因果解释；不能反向调历史仓位 |
| 相对财富/相对回撤 | `relative_NAV = NAV_portfolio / NAV_benchmark`，再计算其回撤 | 不把`cumprod(1+rP-rB)`称为可交易相对净值 |
| 跑赢比例与周期分布 | 在固定月/季/开发fold上的超额分布、最差超额段 | 月份不足时显式不完整；不只报总平均 |
| 市场上涨/下跌期表现 | 固定定义下的分组效用、样本数、净值压力 | 条件是描述，不默认鼓励只在回看有利状态开仓 |
| 头部分层宽度稳健性 | top10%、top20%或预声明TopK的净效用变化 | 判断利润是否只依赖少数极端股；有限预算而非扫所有K |
| 底部排除收益 | 从同一基准组合剔除bottom部分并按冻结规则再分配，比较前后净效用/风险 | “不会买坏股票”可以是纯多头价值；不冒充可卖空alpha |
| 持仓集中度与活跃度 | 权重HHI/有效持仓数、最大单股/行业、平均投资比例、现金拖累 | 不交易的全现金不能仅靠0回撤取得优秀策略评级 |
| 实际成本/可成交覆盖 | 真实买卖换手、订单金额、min fee、涨跌停/停牌与未成交 | 可执行性只能由当时规则和实现确认，不从未来价格存在猜测 |

**基准默认：** 库级研究使用同一PIT可投股票池的市值加权总回报参考，明确权重何时可知；同时给等权参考作为风格诊断。不是“业绩基准”。用户正式产品需显式指定跟踪指数/总收益版本/币种/时钟。沪深300、全A等不能无说明互换；分钟VWAP组合也不能悄悄减close-to-close指数收益。

**对比例子：** 市场-20%、组合-10%，算术超额为+10个百分点；相对财富为`0.9/0.8-1=12.5%`。两者都正确但定义不同。多头可有较好的选股等级，同时因绝对回撤超过风险预算而不能通过部署门。

### 2.5 模型特征、冗余与增量：必需但不对十万因子全部重训

模型特征必须绑定`model_recipe / baseline_feature_set / training_budget / folds / seeds / target / fee_profile`。最低限度支持：新增特征的OOF效用差、替换同族旧特征的差、删除整个相关簇的差、不同seed/fold稳定性、缺失/尺度/推理延迟。

优先低成本线性/固定基准模型做初筛，对少量候选再做真实目标模型的配对重训。残差IC只是廉价线索，不是最终增量证明。研究表明非线性交互和相对既有因子的新增贡献很重要，但这些文献不提供本项目可直接套用的IC门槛。[W06/W07]

`f`和`f²`在某些分布下相关性为0，后者却完全由前者决定：低相关不等于新增信息。重复公式、来源血缘、非线性变换与实际模型贡献共同解释；不能把每个处理版本都统计为独立发现。

### 2.6 哪些是核心、哪些不应首轮强算

- **廉价共同底座**：合法性、覆盖/finite/ties、逐日IC、raw ICIR、10层、方向/源标签、基础信号变化。全量审计模式按显式请求全部逐项交代，不自动删因子。
- **入围必要评价**：20层/类型诊断、LO与LS两腿、base净成本、回撤水下、状态稳定、有限H期限/延迟检查、配对差值证据。
- **选择性重评价**：完整借券/冲击与资金曲线、block bootstrap、模型增量、全局相似图重建、DSR/PBO等。只对适用候选运行，未运行有状态，不装作已经算0。

不要为了“指标很多”新增大量同义Sharpe、IC、波动指标。优先补齐能改变决策的LO增量、腿贡献、实际成本、执行延迟、族内替换和证据不确定性。

## 3. 费用与执行默认值：可以直接运行，但不冒充实际账户成本

### 3.1 三层成本模型

**GROSS_DIAGNOSTIC**：显式0成本、无容量认证，用来定位信号结构。旧gross函数可以保持兼容，必须命名清楚。

**NET_ASSUMED**：本版默认研究费表＋滑点/融资情景，输出`ASSUMED_COST`。没有订单数时不能假称已经精确计入最低佣金；没有借券时仍不能认证short可执行。

**NET_EXECUTABLE**：实际/规范化订单、成交、价格、费用合同、现金/借券与可交易限制共同决定。沿用现有回测/执行域，不让QE或FO再造一套撮合器。

### 3.2 沪深普通A股研究初始费表

本表不适用于ETF、可转债、存托凭证、港股、美股或北交所的所有特殊情况。税费按有效日期加载，不将最新费率套回历史。公开税务公告、结算机构通知原文转载与券商收费公示支持税费与最低收费示例；**万2.5佣金、滑点、冲击、融资/borrow均是本版研究假设，不是用户真实合同**。[W08–W11/W16]

| 项目 | 推荐研究默认 | 适用范围/说明 |
|---|---:|---|
| 佣金 | 成交额2.5bps，买卖分别收 | 假设含经手/证管、不含过户与印花税；券商套餐不同时按included_components解包，避免双算 |
| 最低佣金 | 5元/实际计费订单组/方向 | 研究订单模式默认；部分成交归组由broker规则定义，不能按每个fill重复扣5元 |
| 卖出印花税 | 5bps；买入0 | 2023-08-28起减半后的普通A股研究费表；之前相应有效段为10bps，不无日期回填 |
| 过户费 | 0.1bps，双边 | 2022-04-29起公开标准口径；若佣金套餐已含则不另扣，按账户/市场分解 |
| 基础总滑点 | 单边5bps | 已包括一般spread/小单执行偏差的统一假设，默认不再额外叠加另一份half-spread |
| 滑点压力 | 单边2.5/5/10/20bps | 改变执行假设，不把法定税费机械乘2/4 |
| 冲击模型 | 默认FIXED_SLIPPAGE_PROFILE，不宣称已标定impact | 可额外启用平方根压力模型，但与固定总滑点的重叠部分必须扣除/重定义 |
| short借券费 | 年化8%，压力3%/8%/20% | 仅假设的研究short情景；需计日历天数、费率变化、缺券和召回；不是有券证明 |
| 融资利率 | 年化4% | 仅对实际负现金/借款余额计息，不按全部gross exposure再扣一遍 |
| 闲置现金收益 | 0%研究假设 | 正式任务使用指定cash curve；风险调整用的rf曲线另有ID，避免把融资与rf重复当费用 |
| 借券收益返还/short rebate | 0%研究假设 | 不假设short卖出现金可无约束再投资 |
| 日成交参与率上限 | 5%为研究初始情景，另跑1%/10% | 是风险情景不是“5%以内一定能成交”；按实际执行窗口可得成交量检查 |
| 研究资金规模 | 1,000万元；附100万/1亿压力 | 影响最低佣金、订单规模与冲击，不宣称容量等于这个数 |

1bp=0.0001=0.01%。大额订单不触发最低佣金且不额外叠加冲击时：买入`2.5+0.1+5=7.6bps`，卖出`2.5+0.1+5+5=12.6bps`，同名义完整往返`20.2bps`。该示例不是整个组合每次调仓的固定扣点，更不是只有成交一次也扣一整轮。

**最低收费例子：** 1000元订单，佣金按最低5元即50bps，而非2.5bps。模型净效用对小资金/碎单可能明显不同。没有订单信息的probe应报告`MIN_FEE_NOT_MODELED`，不能把名义比例估计升级为实际净收益。

**历史税费规则：** 新建/复用`FeeSchedule`需按`market/instrument/account/side/effective_from/effective_to/included_components`解析。历史缺少费段应显式阻断正式净评价；可以指定研究假设，但须保留`ASSUMED_HISTORY`。2026-09-07后的新运行要按现有政策更新机制复核最新费表，不能把本文件当永久法规。

### 3.3 成交成本必须由实际买卖金额计算

以执行前经过价格漂移的权重`w^-`与目标`w*`作说明：

\[
B_t=\sum_i\max(w^*_{it}-w^-_{it},0),\qquad
S_t=\sum_i\max(w^-_{it}-w^*_{it},0).
\]

比例费用为`B_t*c_buy + S_t*c_sell`；证券卖出交易（含short sale）按对应规则计算卖方税费，买入回补不再当卖出收税。仓位跨零、跨cohort相抵、现金约束和部分成交需要实际交易账本处理。

展示的单边换手可为`0.5*(B+S)`，但**不能把它直接乘一个单边费率**代替上述费用。比如多头换掉20%股票是买20%加卖20%，不是只交易20%。无成交不应产生佣金；不允许负换手带来“交易返利”。

净PnL分解至少为：持仓价格/公司行动PnL + 现金收益 - commission - tax - transfer/explicit fees - implementation_slippage - borrow - financing。用实际成交价估值时，滑点通常已经在execution-vs-reference差里，不能再次从NAV扣同一份。

### 3.4 冲击与容量不能靠一个默认费率完成

需要资金曲线时，可把`impact_per_notional = eta * sigma_daily * sqrt(abs(order_notional)/ADV)`作为**待校准的压力模型**，eta、ADV回看、波动估计、订单归组与成交窗口显式配置。推荐压力值eta=0.5、1.0，不称行业最优。固定5bps已经是包含一般执行偏差的简化情景；启用impact profile时应改用明确的spread/临时偏差基础项，避免和总滑点双算。

使用训练期或此前真实成交校准，在验证区检验预测误差和保守覆盖。不能在测试区挑一个恰好让策略盈利的eta。交易成本取决于交易规模、标的和执行方式，实证机构研究支持这种校准思路，但不支持把某个固定bps当所有股票的真实成本。[W05]

break-even cost应在固定信号/约束下求使净经济效用到零的成本阈值；若成本参数也会改变最优交易量，则重新执行组合层，不用一条简单比例冒充新的最优容量。

### 3.5 成本缓解不必损坏因子本身

允许少量组合级候选：入场top10%、持有到跌出top20%的buy/hold buffer、no-trade band、降低调仓频率、延迟交易、净额相抵。它们改变交易政策而不改变原因子值，应有独立PortfolioRecipe和评价，不在FP重写一个“低换手因子”。Novy-Marx与Velikov研究支持考察buy/hold spread作为简单成本缓解方式，但本项目的10%/20%仍只是待验证初始取值。[W02]

## 4. RankICIR门槛和多维分级：替换旧AI表，不只是把1.50调低

### 4.1 先确认口径，再评价高不高

当前`compute_icir`明确计算`mean(IC)/std(IC,ddof=1)`，没有年化。[C04] 因此旧表中的1.50/1.10/0.85若直接绑定该raw ICIR，就是相当严格的“每日IC均值相对其波动”条件，不能当作普通因子普遍必须满足的准入标准。若有人把年化值混进同一栏，则含义完全不同，必须先纠正身份。

例如：平均每日RankIC=0.02，标准差=0.08，raw RankICIR=0.25。假设252个独立同分布观测，简单均值t统计约为`0.25*sqrt(252)=3.97`；但H期标签重叠、时序依赖、筛选偏差存在时，这不是最终显著性，需要HAC/块重采样和试验族处理。raw ICIR=1.50在同一简化假设下对应t≈23.81；这说明门槛尺度很强，不证明所有达到它的因子一定错误。

ICIR、portfolio information ratio、Sharpe是不同指标。不要因为名字里都有IR，就给它们共用同一阈值。ICIR可以为负、可以大于1；零方差是未定义，不通过epsilon强造分数。分钟频默认报告raw ICIR，必要时按日汇总/时间块做推断，不机械乘`sqrt(252*每天bar数)`宣称巨大年度能力。

### 4.2 评级对象不是一个字母，而是四层记录

```text
来源/结构/机制标签
    + 每个适用指标的原值与效应等级
    + 每个健康维度的子等级、证据等级、缺口/阻断
    + 面向某个用途的准入状态
```

推荐维持现有14个父维度，扩展子维度与用途对象，避免为了“更多维度”拆成彼此重复的几十个总分。组合相关维度可分别挂LO、LS两个scope。来源/机制分类与表现分级分开：量价、财务、事件、风格控制等不排列好坏。

**必须单独保存：** `factor_definition_ref / recipe_ref / representation_ref / portfolio_spec_ref / horizon / universe / data_as_of / evaluation_ref / metric_instance / effect_grade / evidence_level / policy_version / calibration_ref / applicability / reason_codes`。

不再使用脱离这些上下文的永久“因子A级”。同一因子可以是“预测B+，纯多头效用A，LS效用C，成本B，数据A+，证据E2”，最终适合LO而不适合LS。

### 4.3 所有指标都要有分类，但不是所有数字都该强行S到D

MetricSpec增加或复用`evaluation_role`：

| role | 例子 | 处理 |
|---|---|---|
| PERFORMANCE_HIGHER | 有向IC、净效用增量 | 可给效应等级 |
| RISK_LOWER | 同风险规格下的回撤/成本利用率 | 可给风险等级 |
| TARGET_RANGE | beta接近目标、gross exposure在预算内 | 按偏离目标/容忍区评级，不按数值越低越好 |
| DIAGNOSTIC_ONLY | U型标签、H峰值位置、两腿相关 | 给类型、数值、稳定/异常标签，不伪造通用优劣 |
| INTEGRITY_BOOLEAN | PIT/标签成熟/证据匹配 | PASS/FAIL/UNKNOWN，硬门不折算成总分 |
| SAMPLE_EVIDENCE | 有效日/有效事件组、CI宽度 | 决定证据强度，不被当作收益优势重复加分 |

用户要求“每项有分类和标签”应完整满足，但不应因此让正常的高相关对冲两腿得到坏分，或让非单调U型必然D。

### 4.4 14个父维度的具体分级规则

| 父维度 | 子维度/主证据 | 怎么评级 | 是否一般硬门 |
|---|---|---|---|
| predictive_power | 有向RankIC/raw ICIR；形状映射效应；事件效果；模型条件增量 | 按预声明机制分支定primary，不以某一个强指标抵消另一个实际方向失败 | 独立线性alpha有最低效应；模型/形状走专属通道 |
| stability | 多fold方向、周期分布、近期配对退化、收益/IC变号 | 评价共同窗口与长期/近期差异，避免用低IC波动本身奖励无信息因子 | 正式候选至少有足够跨窗证据 |
| robustness | OOS差值、参数平台区、子样本、负控、选择频率 | 保留有效自由度、试验数和区间；validation/train仅在分母有意义时作为辅助 | 泄漏绝对失败；统计不确定可观察而非伪D |
| turnover | 信号rank变化、成员变化、实际交易金额、方向分解 | 以单位净价值的交易负担/执行可行性为主；不规定所有快信号必须慢 | 部署时交易预算/可执行性有门 |
| capacity | 不同资金量的参与率、fill、冲击与净价值 | 在指定AUM和执行方式下评级；没有impact/borrow数据标未证实 | 正式容量认证必需 |
| cost_drag | 固定持仓下费用、净/毛差、break-even余量 | 比较实际成本预算与净效用；毛alpha近0不算夸张retention比率 | 净部署不能用gross-only证据 |
| drawdown | LS绝对、LO绝对及相对回撤；水下/恢复 | 先统一资本/风险规格，再按预声明风险预算利用率评级 | 预算超限不由高IC抵消 |
| tail_risk | ES、最差真实月、尾部集中、无法退出损失 | 绝对尾部和benchmark-relative尾部分开，针对使用角色判断 | 部署有预算门，不强求避险特征单独正收益 |
| data_coverage | eligible覆盖、全池覆盖、finite、distinct、数据缺口 | 区分连续/离散/事件，统计每因子实际可用性 | 对应数据合同必须通过 |
| freshness | 字段公告/知识时间、更新节奏、信号有效期、陈旧比例 | 量价按bar SLA，财务按应有公告周期，事件按事件TTL | PIT/过期输入有硬门；正常低频不罚 |
| complexity | 增量计算代价、依赖源、延迟、恢复、存储 | 按实际边际成本，不只数公式长度；共享DAG可以降低成本 | 实时SLA/资源预算有门 |
| economic_sense | 来源、机制假设、可反驳预测、适用边界 | 采用DOCUMENTED/UNCONFIRMED/CONTRADICTED等证据标签；不让LLM给高分充准入 | 机制不明可研究；LLM不可替代统计证据 |
| shape_quality | 类型、尾部异常、跨窗模板稳定、可表达性 | 按MONOTONIC/U/TAIL/DISCRETE等分支，保留样本与区间 | 形状适用性有门，不要求天然单调 |
| regime_sensitivity | 行业/size/beta/liquidity暴露、环境条件效应、漂移 | 以用途目标看“是否不希望的暴露”，不一律奖励全中性 | 组合约束有门；状态特征可以保留状态信息 |

**跨维但不能遗漏的两个判定：** 完整性（PIT/时钟/成熟/身份）和相对当前库/模型的新增或替代价值。它们有独立状态，不隐藏进总分。

### 4.5 给可运行的冷启动展示锚点，但不再让两列数字决定整个因子

只适用于**初始沪深A股日频、宽股票池、已冻结方向、相同H10目标与证据口径**的展示/路由起点。H1/H5/H20、分钟、事件型和其它市场必须独立校准。两列分别产生两个子指标等级，**不是要求同一行两个条件同时成立才给因子一个总等级**。

| 单指标效应等级 | 有向RankIC均值下限 | raw RankICIR下限 |
|---|---:|---:|
| S+ | 0.040 | 0.50 |
| S | 0.030 | 0.35 |
| A+ | 0.022 | 0.25 |
| A | 0.016 | 0.18 |
| B+ | 0.010 | 0.12 |
| B | 0.005 | 0.06 |
| C | 0.000 | 0.00 |
| D | 有向均值<0 | 有向ICIR<0 |

C表示效应弱或尚未达到上述实用起点，不等于“完全没有信息”；零方差/不足样本不进入该表，保持UNDEFINED/INSUFFICIENT。负方向可在训练内产生反向候选，但不允许用测试集绝对值重获好等级。此表是本报告建议的**cold-start configuration（冷启动配置）**，不是统计bootstrap结果，也不是行业标准。

旧表从B+就要求raw ICIR≥0.45，其强度接近本版单指标S级；不适合直接成为所有因子的普遍门。更重要的是，即使把阈值降低，仍必须实行本节的多维证据和用途判定，否则只是在更宽松地选噪声。

### 4.6 不让任意固定数值成为永久“最优标准”：离线校准协议

1. **确定cohort。** 市场、bar频率、目标H、PIT股票池和使用角色先固定；再按大类（连续/离散/事件/财务等）做必要细分。不按测试表现建立有利子组。
2. **建立参考样本。** 用开发期内已经经过相同基本数据检查的候选，包括通过和失败者；同一母因子几十个参数变体不能把参考分布挤成“都是动量”。对母族加权或限额。
3. **保存原值与分位两套信息。** 实用效应锚点和冻结cohort分位同时展示。分位高不能救负alpha；不能每次按当前候选池重新排名使弱池自动产生S+。
4. **依据任务结果校准。** 查看不同效应区间在后续开发验证窗口中的净效用、增量、失败率与稳定性，选择有足够支持的单调分段规则。数据不足的细cohort使用更粗的父政策，并标CALIBRATION_INSUFFICIENT，不硬拟合8个等级。
5. **冻结版本。** `policy_hash`、参考候选集hash、截止日期、方法、适用范围、样本数写入calibration artifact。只能在开发区迭代，封存测试不参与定门槛。
6. **分级与选择分开。** 搜索比较原始连续效应和区间，不围绕“A+/A边界”寻优。政策更新若未改变指标定义，只重评等级/准入，不重新计算所有因子值。

可提供参考分位带S+≥97.5%、S≥90%、A+≥80%、A≥65%、B+≥50%、B≥30%、C其它作为显示；**该分位带不参与未经校准的自动准入，也不要求真实资产分布固定拥有这些比例**。优先使用验证结果校准，而不是把“分位高”误当正收益证据。

### 4.7 风险和运营维度的默认等级，不按同一Sharpe/换手数字

对已定义风险预算B，可令`u=observed_loss_or_resource/B`。一个初始低者更好的等级表为：S+≤0.35，S≤0.50，A+≤0.65，A≤0.80，B+≤0.90，B≤1.00，C≤1.20，D>1.20。**u>1仍表示预算超限**，C是报告级别，不意味着允许上线。零风险是由于不投资/无数据时先被活跃度或证据门挡住，不能靠全现金赚S+总体评价。

研究风险预算起点（不是用户实际风控承诺）：LS gross=1最大回撤25%、水下252个交易日；LO gross=1最大回撤35%、水下504个交易日；LO相对基准回撤15%。同时报告实际波动/gross/beta。正式策略采用团队批准的预算。不得为了通过grade临时提高预算或缩小仓位；风险标准变动是新policy/portfolio spec并需重新比较效用。

数据覆盖对连续稠密信号的**eligible范围**可先使用：S+≥99.9%、S≥99.5%、A+≥99%、A≥98%、B+≥97%、B≥95%、C≥90%、D<90%。95%是初始目标不是全市场 universal hard law；事件/财务需预声明适用空间、合法缺失和更新cadence。覆盖率必须与未限定全池覆盖一同显示，不能临时把缺失股票剔除后自报100%。

### 4.8 证据等级与效应等级完全分离

| evidence level | 含义 | 初始证明要求 |
|---|---|---|
| E0 | 无法解释或不能计算 | 无效、未知、不成熟、未计算、样本不足等保留具体状态 |
| E1 | 有描述性结果 | 数学定义/数据合同通过，但尚缺足够OOS、相依/选择偏差或执行证据 |
| E2 | 开发区有较可靠样本外证据 | 预声明的多次时间前推验证、原方向、配对差异及风险/成本检查，搜索族被记录；显著性方法与依赖结构匹配 |
| E3 | 冻结方案获独立验证与适用的影子/运行验证 | 候选集合、配方、交易/费用/模型政策先冻结；独立holdout不回流寻优；适用的实际运行合同通过 |

E1的点估计可以很高，但只能显示“效应S，证据E1/暂定”，不能当成熟S级生产资产。E2不必所有指标p<0.05，也不是“所有指标有值”；应预声明一个或少数primary效应假设与硬约束，避免几十项挑一个显著。FDR q≤0.05可作为项目确认政策的候选设置，但前提是输入检验有效、试验族和依赖假设匹配；自适应搜索的原始p值不能随意扔进BH就叫已纠偏。[W03]

初始日频计算下限与研究资格分开：20个有效时点可形成描述性ICIR；确认级E2建议至少3个时间前推fold、总成熟时点≥252，并检查按预声明block长度切出的有效块数（例如至少20块）。这个块数是样本充足的工程下限，不等于数学上已独立。H较长时应增加开发长度或保持E1，不能压缩block骗够样本。事件型按独立事件组和实际跨期覆盖另设资格，不用`T×N`假装有效样本巨多。

### 4.9 评级引擎怎么实现，而不是再加一套“打分小函数”

沿用现有FactorHealthPolicy、MetricGradeRule、DimensionRule和artifact类型，增加缺失的角色/适用性和校准引用。政策编译按以下顺序进行：

```text
解析用户用途/因子类别/目标horizon
 → 解析canonical metric instances与单位/方向
 → 检查required/optional/alternative-groups是否闭合
 → 检查适用算法/输入/证据能力
 → 从effect anchors或已校准规则生成各子指标等级
 → 生成14父维度的子等级向量、证据级别和阻断原因
 → 执行用途硬门与增量/替代比较
 → 保存不可变政策快照与决策
```

父维度可保留用于展示的字母，但必须由该用途冻结的primary指标和counter-evidence规则产生；同时展示全部关键子指标，不能一个维度最高值覆盖最弱的硬性项。方向失败、风险超预算、成本不可知等各自有明确阻断。没有校准过的父维度合成函数，不临时拼权重产生貌似精确的总分：可输出子等级向量和暂定状态，直到开发数据足够支持该映射。

例如预测维度：连续alpha主要看有向RankIC的效应，raw ICIR和跨窗方向是持续性/一致性证据，HAC是置信依据；不把三者当三次独立预测贡献相加。事件型改用预声明事件效应与跨事件稳定性。模型特征主要看指定模型下的增量/替换效果，原始单因子IC为辅助。这些分支均由同一政策引擎执行，而非各包私自重算。

required项缺失 → 维度证据未满足；optional且NOT_APPLICABLE → 保留原因而不伪造0；NOT_RUN_BUDGET → 不具正式该维评价；所有不适用维度不得通过“填S级”补齐。已生成的新metric若还未有grade规则，可以展示原值，但不允许调用方直接填一个desirability进入正式准入。

### 4.10 应立即停用的旧评级捷径

不再通用使用：所有因子ICIR必须0.45以上；所有指标缺一项整体打0；所有ties越少越好；所有财务30天不变就差；所有换手越低越好；所有形状必须单调；高LS替代多头评价；所有因子必须完全中性；所有模型都最终两层zscore；所有维度必须可算且一起折成一个分数；所有高相关因子自动拒绝。

## 5. 筛选与比较：有硬门，但硬门必须按用途

### 5.1 推荐准入决策树

```text
完整性门（PIT/时钟/轴/身份/成熟/复现）
 → 对应该类型的数据/新鲜度门
 → 预声明用途的required证据齐全
 → 风险、执行、成本及运行约束
 → 选择一个已声明的效用通道：
      DIRECT_LINEAR_ALPHA
      FROZEN_SHAPE_OR_TAIL_ALPHA
      MODEL_INCREMENTAL_FEATURE
      RISK_OR_STATE_CONTROL
 → 新增 / 替换 / 观察 / 不采纳
```

通道不是看到test结果后重新挑的“逃生门”。在开发阶段依据来源与诊断声明；之后独立确认。`RISK_OR_STATE_CONTROL`不是alpha评级作弊：它有不同资产角色、下游模型用途和验证，不计入独立alpha数量。

| 用途 | 初始门槛建议 | 不使用的粗暴门 |
|---|---|---|
| 连续线性独立alpha研究候选 | 有向RankIC≥0.005、raw ICIR≥0.06作廉价路由起点；进一步需要E2级净效用/风险确认 | 直接把达到两个数字当入库完成；要求S+才可使用 |
| LO头部/底部排除因子 | 冻结top/bottom规则的OOF净主动效用有意义、基准/集中度/成本合格 | 整体RankIC不足就否决、LS短腿强才算好 |
| U/事件/非线性alpha | 形状/事件证据稳定，映射冻结，OOF经济效果与样本充分 | 原始RankIC必须高、强制天然单调 |
| 模型输入特征 | 数据表示与运行合同通过；相对固定模型/特征集合的OOF增量或稳健替换价值 | 每个特征独立Sharpe≥1、所有源信息先去风格 |
| 风险/状态/辅助控制 | 角色事前声明、数据与模型功能验证、没有未来信息 | 用其单变量收益高低来否定控制功能 |
| 正式部署 | 对应所有门、E3范围内证据、实际账户规格、冻结recipe与运行能力 | 靠本文件的研究成本/风险默认直接签生产 |

“净效用有意义”是相对预声明的最小经济幅度与区间；可初始把同上下文RankIC差0.001、raw ICIR差0.02作为修复的最小关注幅度，年化净效用差20bps作为示例，但实际指标/风险规格不同必须分别设定。**这些不是三个都要同时通过的收益保证。** 小效应但足够低成本和互补也可能有价值，按固定增量通道判断。

### 5.2 比较合同必须解决样本和风险规格差异

A/B比较绑定同样的horizon、股票池、成熟时点、orientation、成本、风险预算、data snapshot及模型训练预算。共同可比样本做配对比较，另报告各自完整部署范围，避免“只看交集”掩盖覆盖损失。

逐日效应差`d_t=m_B,t-m_A,t`使用共同block draw。Sharpe/回撤等非线性统计在每次相同重采样路径上重算差值，不能减两个独立CI判断显著。跨指标联合作用使用同一draw里的联合效用分布，不把每个边际CI下界代入函数就叫95%联合下界。

建议比较返回：`SUPERIOR / NON_INFERIOR_CHEAPER / EQUIVALENT / TRADE_OFF / INCONCLUSIVE / INVALID_CONTEXT`。

- 改善：差值下界超过预声明最小有意义改善。
- 非劣：差值下界高于负的最大可容忍损失，并有成本/风险改善证据。
- 等价：差值区间完整落在预声明等价区间内；“不显著”或CI有重叠都不够。
- 各有优势：保留少量互补候选到全局比较，不强行决单冠军。
- 证据不足：不自动等价。部署默认保留已有版本，研究可继续观察。

等价检验应注明显著性水平与CI对应关系：例如标准TOST的两个单侧5%检验对应90%双侧区间；若使用95%区间包在等价界内，是更保守的规则，不把它误称为完全相同的检验。时间序列采用合适的配对块方法，不能直接套独立样本t公式。[W13]

非劣性容忍界不能在看见结果后扩大。方向只在训练中确定。高总分不能覆盖费用未算、未知样本或任何硬门失败。

### 5.3 全局选择要同时支持新增、替换和删减

\[
\Delta V_{add}(f)=V(S\cup\{f\})-V(S),
\quad
\Delta V_{replace}(f,g)=V((S\setminus\{g\})\cup\{f\})-V(S).
\]

V必须来自相同预算/切分下重新训练或重新构建的实际目标模型/组合。先少量近邻候选再重训，不对十万因子全部做大模型比较。对一簇高度相关变量，应同时看整簇删除后的变化；单变量重要性低不表示整簇没用。簇级稳定选择文献提供了有价值的思路，但金融时间相依下不自动继承其假设条件中的理论保证。[W12]

同一母因子默认保留1–3个有明确用途差别的版本，不是必须填满名额。候选分别能改善S，不代表一起加入仍各有增量；最终在联合集合上做一轮有预算的新增/替换/删减。简单贪心是工程折中，不宣称全局最优。

## 6. 什么因子尝试什么口径：按诊断选择，不把所有方案全排列

本节是**新增的路由/参数政策规格**，不是宣称每个已有算子都要重写。先读取已有FE算子元数据、FP合法配方、FO repair registry；能够直接组合的使用canonical DAG。配方、模型表示、组合交易规则分成三个对象，分别记录变动后的价值与成本。

### 6.1 因子类型 × 评价画像 × 候选处理

| 因子/诊断类型 | 优先评价画像 | 首轮允许尝试的少量方案 | 重点比较及禁止事项 |
|---|---|---|---|
| 稳定单调、已有良好数据的量价因子 | SIGNAL＋实际LO/LS用途 | raw作为基线；只有实证诊断需要时才增加处理 | 不为了凑流程无条件winsor/rank/zscore/neutralize全套 |
| 快反转、高信号换手、执行成本吃掉收益 | SIGNAL＋LO/LS net＋延迟曲线 | raw、两档因果EWMA；另用组合级buy/hold buffer或no-trade band | 比较实际净效用与信号延迟；不能只看rank变化减少就称成本下降 |
| 中慢动量或趋势信号 | SIGNAL＋多期限＋LO/LS net | 原窗口与两个经济合理邻域；必要单侧平滑 | 长窗口不能靠多读未来数据；寻找平台区而非某一尖峰 |
| 显著行业/市值/流动性偏移的信号 | SIGNAL exposure＋指定组合用途 | raw、行业中性、行业＋市值中性；最多三种主候选 | 若目标模型允许风格信息，保留原通道候选；最终组合暴露必须检查 |
| 对称U/倒U，线性IC低但形状稳定 | SHAPE＋LO/LS映射＋MODEL | 统一秩位置下的abs偏离、平方偏离；倒U按训练冻结方向 | 类型与中心只能开发区确定；父/子/重组分别复评；不能挑测试最优分支 |
| 偏斜U、左右翼不同 | SHAPE＋左右分支＋MODEL | 一个固定中心或训练拟合中心，最多左右两个hinge | 左右分支同一研究族，不能当两个独立发现；必要再验组合 |
| 顶层退化、最高极值组变差 | 20层＋top宽度＋LO | 查异常数据/微盘/可成交性；再有限饱和、clip或分段 | 不按测试收益删尾部股票，不硬把曲线修成漂亮单调 |
| 底部明显很差而top普通 | LO bottom-exclusion＋LS腿归因 | 冻结底部排除规则；有借券证据再考察short | 可能是避雷因子，不因top普通而自动否决；不假设可融券 |
| top有效、bottom没有信息 | LO active＋top稳健性 | 纯多头/topK、少量持仓宽度对比、组合级成本缓解 | LS整体指标不能否决纯多头用途，也不能假造短腿收益 |
| 财务质量/价值/成长等低更新频率 | PIT/newness＋H10/H20等对应期限＋LO | 合法公告后有界ffill、行业相对版本、训练内稳健缩放 | 数据30天不变不自动判D；不能按报告期而非可用日填充 |
| 稀疏事件/公告冲击 | EVENT＋事件窗口＋MODEL | 事件mask与事件年龄、raw冲击、少量因果事件衰减 | 不用每日重复陈旧值假装新增独立事件；事前定义事件机会集合 |
| 二元/离散/评级类信号 | DISCRETE组差＋LO排除/模型 | 保留离散编码与missing通道；有序分组对比 | 不强切20层，不因ties高判坏；Spearman存在也需独立样本/适用性判定 |
| 极端厚尾、易受异常点驱动 | robust effect＋shape＋MODEL | raw-clean、一个预声明稳健clip/MAD阈值 | 核实极端是数据错误还是机制；避免clip+rank+zscore无限组合 |
| 波动/风险/状态变量 | RISK_OR_STATE_CONTROL＋MODEL | 必要log/稳定缩放、明确历史状态特征 | 不强制当独立多空alpha；模型用途与预测泄漏仍需验证 |
| 非线性交互、低单变量IC但有明确条件假设 | MODEL＋条件/组增量 | 原值＋少量明确变换；对少量入围候选做组级增量重训 | 不能给所有低IC噪声无限“交互救援”；条件不得由未来结果定义 |
| 几乎重复、同一母因子多个参数版本 | 精确身份＋相似复核＋替换 | 优先更便宜/稳定/覆盖好的版本；必要保留两个用途不同者 | 不按固定数量强留三份；近重复不是自动相加更多alpha |
| 训练特别好、开发验证明显退化 | GENERALIZATION＋完整性检查 | 先查泄漏/分母/样本；再降自由度与窗口平台验证 | 禁止直接换测试集方向、放宽门槛、用Agent持续试到成功 |
| 分钟价量/微观结构信号 | minute时钟＋延迟/成本＋相应执行 | 少量bar尺度平滑、时段/流动性条件、必要日内归一化 | 不套日频ICIR/换手/税费阈值；数据与成交窗口必须同一时钟 |

这些类型允许多标签。一个量价财务混合因子可同时触发PIT、尾部和成本检查，但不因此开启三类方案的笛卡尔积。依据最主要、最有证据的问题安排优先级，完成一次修复后再评价新诊断。

### 6.2 默认搜索预算与对照设计

建议起步：每母因子每轮新增候选上限8，允许经显式预算政策扩到12；首轮通常2–4个，其余预算用于验证最有价值的邻域和必要交互。raw基线不删除，重复身份复用结果。另保留小比例非线性/稀疏诊断预算，例如总研究预算的10%，并记录预算用途；不是强制让10%噪声通过。

窗口候选按既有ParameterRole、合法域与经济期限生成，例如原窗口附近约0.75/1/1.5倍的有效离散窗口；不适用因子不使用此规则。EWMA半衰期必须与信号期限、数据频率和最大允许延迟关联，不把3/10日套到分钟或季度数据。

多个操作的交互只在有证据时做小型设计：raw、A、B、A→B的四点比较可以判断是否有组合价值，不能把每种算子任意排列。每个尝试记trial；重复数值/别名不再进行昂贵重算，但仍记录为何被折叠。

### 6.3 U型与rank语义需要精确到有限样本

若要把秩位置对称地映射到(0,1)，可定义`u=(average_rank-0.5)/n_valid`；不能把现有`pct_rank=rank/n`与这个定义当成同一算子版本。后者在有限样本中的均值不是严格0.5。使用哪一种由统一RankPolicy决定，所有后台、DSL和反例保持一致。

固定对称中心c=0.5时，候选可为`abs(u-c)`或`(u-c)^2`；对偏斜型，中心在训练内拟合且绑定fit-state。左右分支`max(c-u,0)`和`max(u-c,0)`可分别进入模型，但其样本外价值、成本和联合效果必须重新评价。非线性树/神经网络可能直接从原值获得关系，不以单变量变换后IC最大化取代模型增量比较。[W06]

### 6.4 三种预处理职责各用不同验收

**数据合法性处理**：由DA/FE固定，不允许为了提高收益开关PIT/轴/单位/合法缺失校验。

**信号变换**：FP描述配方，FE执行，FO选择，QE验证诊断目标和经济效果。比如平滑是否提高net效用，中性化是否在非劣范围内降低不需要的暴露。

**模型表示**：根据具体模型的输入契约选择，不覆盖原始因子资产。线性正则模型需要明确尺度；树模型不强制统一zscore；神经/序列模型有训练期拟合或明确因果截面缩放和missing通道。`zscore OR robust_zscore`必须是一个替代组，不能要求同时做两个。

最终输出性质而非“历史出现过某算子”决定重复处理：rank在子表达式出现不等于根输出rank；中性化后非线性映射可能破坏线性正交性；不同mask、权重、截距、暴露下的neutralization不是同一性质。

### 6.5 因子级与组合级优化不能混淆

平滑改变因子值；buy/hold buffer改变交易规则。两种方案可以分别比较，但不应给组合规则硬塞一个新的因子DSL并隐藏它。交易参数及费用同样属于研究试验族，不能因“不是因子参数”就逃过尝试次数记录。

允许慢成分`s=EWMA(x)`与快残差`x-s`作为少量可解释候选；两者共源，必须同族预算和增量检验。完全没有样本外证据的成分拆分不应自动入库。所有生产更新均重放固定recipe/PortfolioSpec，不每个bar重新寻优。

## 7. FA的进一步优化：从“有标签的仓库”到有用途、版本和证据的资产系统

### 7.1 分开三种关系，避免同一个family承担所有职责

| 关系 | 权威来源 | 作用 | 不可替代什么 |
|---|---|---|---|
| 血缘/来源同族 | FE公式、字段血缘、FO父子trial | 研究尝试计数、参数版本、共源信息 | 不等于数值高相关或相同风险 |
| 信息相似微簇 | QE指定窗口的相关/尾部/残差证据，FA图算法 | 近重复复核、代表选择、模型输入压缩 | 不等于盈利能力认证 |
| 风格/风险宏组 | 暴露和组合净PnL协动，FA风险分组 | 控制组合集中度、状态共振 | 不等于公式来源，不能和微簇共用asset.family |

现有`ClusterScale`/governance合同能表达的部分直接复用；D15要求集合装配真正读取这些不同身份。一个资产可同时属于一个信息微簇和多个风险暴露组。unknown不是“为每个因子生成独立簇以绕过限制”，也不是统一错误分到一个真实簇；按用途隔离、限制未知比例或等待补证据。

### 7.2 资产卡应分开definition、representation、portfolio和model utility

保留已有FactorAsset及引用链，增加必要而缺失的scope：定义/recipe/fit-state/物化值，某次QE评价，某种用途的健康卡，某一基准模型下的增量证据，某个组合及其费用实例。不能把最近一份任意horizon的高分覆盖所有用途，也不能取一个“latest timestamp”就跨越as-of读取未来结果。

建议资产筛选接口支持`use_case + as_of + universe + horizon + model_or_portfolio_ref + policy_version`。没有满足这些限定的证据就返回不适用或待评价，不从另一个用途借分。生产发布必须固定实际输入函数、费用表和数据/算子版本，显示名可以变而内容身份不变。

评级政策改变通常只需从已有正确QE原值重评分；若指标定义/费用/组合轨迹改变，才有范围地重算评价；只有因子数学/数据变了才重算物化值。**不要因为换一个字母阈值就重新落十万因子的全部历史值。**

### 7.3 相似门槛应分层，并在开发历史校准

以下为可运行的日频宽股票池研究起点，必须绑定相同窗口、horizon、orientation及mask；不是作者文献或行业最优值。

| 决策 | 初始政策 | 后续校准与证据 |
|---|---|---|
| 规范公式/recipe重复 | 内容身份相同直接复用 | 不需要相关阈值；身份含有效参数与state规则 |
| 数值等价 | 同数据/坐标/mask下的声明误差内等价 | 不能只看两天；exact与tolerance-equivalent分开 |
| 极高相关复核候选 | 多开发窗口相似度约0.995 | 比较尾部、净成本、缺失与模型替换价值；不是直接删除 |
| 同信息族候选 | 约0.95的相关性作为检索/复核起点 | 不作为所有因子入簇的统一下限 |
| 加入已有微簇 | 代表亲和下界≥0.80；多个合格邻居的中位亲和下界≥0.70；最佳与次优簇差≥0.05 | 比较方式、区间、窗口权重与所需邻居数明确；对单例仅使用其证据，不造第三个邻居 |
| 老成员迁出 | 足够有效窗口内亲和上界持续低于0.65，研究起点连续3次有效检查 | 滞回避免0.799/0.801反复迁移；数据故障不是关系永久改变 |
| ANN召回 | 先32–64邻居的资源起点 | 根据极高相关邻居召回质量调整；未召回不等于已证明不重复 |

“亲和下界”应来自适当的跨时间块不确定性估计或明确的稳健窗口下分位统计，两者用不同字段，不把描述分位称95%CI。不能对每条数百万候选边强算完整bootstrap；先廉价筛掉明显远离门槛的边，对边界/迁移/替换决策追加确认。

选择阈值时查看误合并、过度分裂、代表切换、下游增量和计算成本的折中。分辨率选择使用完整、同尺度的质量指标和稳定平台区；未测VI不能靠modularity最高自动宣布最佳。Leiden确保的图结构性质不是alpha质量、同质性或经济最优证明。[W14]

### 7.4 增量聚类生命周期的明确规则

| 情况 | 状态与动作 | 不允许的捷径 |
|---|---|---|
| 新因子数据/证据不合法 | REJECT/QUARANTINED，保留原因 | 先随便放簇以后再查 |
| 共同历史不足或指纹版本不同 | PENDING_EVIDENCE，等待/重建可比指纹 | 标成0相关或低质量 |
| 唯一已有簇通过实际亲和与支持 | ASSIGNED_OVERLAY，在研究覆盖版本中加入 | 修改正在服务模型的旧ClusterSetVersion |
| 两个簇都接近且差值不足 | AMBIGUOUS；必要标BRIDGE供研究 | 靠最大簇或字符串顺序决定 |
| 充分可比证据显示与现有簇均不匹配 | PROVISIONAL_NEW/SINGLETON；有用途证据即可保留独立候选 | 为避免单例强塞到大簇 |
| 多个新因子互相支持且不是同公式近重复 | 新簇提案，经组内质量检查后进入新版本 | 同一公式100个参数变体凑满“新簇最小人数” |
| 老成员持续不再匹配 | 按滞回提出迁移；重新核对其因子质量 | 用一天噪声立即切换模型输入 |
| 两簇跨组亲和和代表可替代性稳定 | MERGE提案，验证合并后信息/风险结构 | 一条高相关桥边合并两个大而异质的簇 |
| 簇内存在跨窗口稳定子组 | SPLIT提案，用真实多对多成员流记录 | 逐旧簇贪心只保留一个子簇，其余冒充全新发现 |
| 当前已无合格活跃成员 | RETIRED/DISSOLVED，保留历史和引用 | 物理删除旧簇使历史模型不可重放 |

创建研究单例簇不等于生产准入。簇的生命周期与单因子的效用等级分开：一个正常簇可能没有当前值得投用的成员，一个有价值的新机制也可能暂时只有一个成员。

### 7.5 何时局部刷新，何时全量重划分

建议默认：每日处理新因子/新证据的研究归属，月度局部质量检查，季度全局候选图/分辨率复核；由规模和数据频率调整。新因子或待分配占活跃集合约10%、显著边界迁移约10%、簇内质量持续低于校准门槛等可作额外触发起点；这些是运维政策，不是金融定理。

立即触发“需重建/重新验证”的情况：相似度定义、股票池、目标期限或指纹语义变了；发现图证据误绑定；代表版本失效；历史数据修订对大量边有影响。可仅重算受影响区域时不盲目全库重跑。

全局划分后，使用成员流的多对多映射检测SPLIT/MERGED/NEW/DISSOLVED，再以稳定匹配继承逻辑ID。聚类算法label变化不是新经济簇；相同成员但代表/聚合权重变化也不是同一个模型输入函数。生产feature集合是否重训由输入语义变化和已有兼容政策决定，不由“簇号变没变”决定。

### 7.6 筛选代表、控制替换频率、避免容量膨胀

代表选择先满足用途/证据门，再看对簇内信息的代表性、稳定性、数据可得性与实际计算成本。最小字符串ID最多作并列时确定性排序，不叫经济代表。簇内互补成员可以保留，但需要不同用途或新增贡献；默认1–3个只是上限起点，不是配额。

现有生产代表优先保持，只有新版本有显著改善或已证实非劣且降低成本/风险才替换。记录变更原因、比较窗口、费用和模型影响，避免每天追逐一个略高的点估计。类内控制同时约束母公式变体、信息微簇、风险宏组和整体资源，各维约束读取不同身份。

### 7.7 失败值和旧证据清理的剩余要求

沿用已实现的GC/生命周期设施，只补尚缺的引用：pending-label评价、fit-state重放、当前/回滚feature版本、共享DAG。`RETRYABLE`或标签未成熟不属于无用失败；终态无引用的试验物化值才进入清理。保留公式、有效recipe、trial族、评价摘要和失败原因，防止删除失败值等于清洗研究历史。

比较政策、税费或评级更新后，把旧评价标为对应scope下的superseded/需重评，不能改写过去已经给模型用过的“当时可知”记录。新政策不能让历史已看到的holdout恢复新鲜身份。

### 7.8 preprocess接入而不粗合并；自动化职责落实到现有入口

| 组件 | 保留职责 | 本轮差额 |
|---|---|---|
| FE/DA | 因子值、规范算子、PIT、增量状态和物化 | 参数/轴适配与状态接口一致，已有内核复用 |
| FP | 有类型配方、处理适用性、fit-state生命周期、模型表示 | OR-normalization、非劣性、实际参数/最终性质；不要新建数值真源 |
| QE | 指标、统计/配对差值与评价证据 | 完整LO/LS成本scope、各后端统一、注册/状态/单位 |
| FO | 诊断→少量提案→分阶段复评→候选集合 | 传完整请求、实际预算、共享比较、继承研究族；不决定最终发布 |
| FA | 来源/等级/用途准入/相似簇/资产版本 | 本节和D09–D22对应差额，不能仅靠总分或裸IC |

`factor_optimizer/search/runner.py`所在包负责研究循环；`quant_evaluator/runtime/evaluator.py`负责实际评价；`quant_platform/app/orchestrator.py`负责更上层候选编排。但存在入口不等于当前composition把每层都接好，D26仅要求穿透剩余适配/重试差额。每日生产更新只执行冻结计划，不需要再次调用FO或Agent。

## 8. 多指标、十万规模和逐Bar更新：只补未闭合部分，保留已有分片与校验

### 8.1 保留已有能力，剩余瓶颈要以端到端结果定位

已经有的GPU F分片、OOM缩批、validity处理与校验前移不重新造轮子。D27针对的是**主机输入、主机结果、并行队列、中间工作区和传输**仍不能由显存分片自动解决。[C01/C02/C22/C23]

提交十万个因子时，提交definition/value引用清单、MetricInstance清单、time/universe/费用/portfolio profile、预算和output mode。系统应按现有调度器的有界队列读引用，分块加载，单卡长驻worker处理，输出逐分片提交。小结果可以聚合，大的T×Q×F序列写制品并返回分页引用，不先在主机分配整个输出。

以T=2520、N=5000、F=100000为算术示例，float32全量值5.04TB；单Bar2GB；float64的T×F序列2.016GB，T×20×F完整分层40.32GB。**这不是实测吞吐**，只说明需要有界加载/输出和选择保存级别。不能用“只报指标均值”偷偷替代用户显式要保存的序列；可事先声明SUMMARY_ONLY、SERIES或FULL_DIAGNOSTIC输出档。

### 8.2 MetricInstance与共享DAG

同一基础指标的`Q=10`与`Q=20`、`cost=base`与`cost=stress`、不同H、不同leg、不同年化定义必须有独立instance key；否则字典覆盖会让“全部一起算”实际只剩最后一项。

依赖计划应共享：同mask的排序、counts/distinct/ties、每日IC、分层成员、每日真实组合轨迹、净值和episode。不同因子的joint mask不同，不能直接拿同一标签rank广播使用；信号形成的成员mask也不能被用于事后IC的label mask替代。费用情景可复用固定成交轨迹重估；若费用变化会改变交易决策，则必须执行新的PortfolioRecipe，不能只减一个数。

GPU侧可在一次排序后返回需要的rank、distinct计数和分位边界，减少重复sort；峰值包含argsort临时存储、输出、mask和pool保留内存。CPU与GPU采取相同的金融定义，数值容差按dtype与算法定义。不能先GPU算错，再让CPU改错来实现parity。

GPU计时必须包含warmup、CUDA同步/事件、H2D/D2H及端到端时间。创建stream/pinned成员并不代表实际异步重叠已经发生；以trace与硬件测量证明。CuPy与CUDA官方文档强调异步计时、传输与正确使用设备资源的重要性，但没有证明本仓库某个改法会获得固定倍数加速。[W15/W17]

### 8.3 三种执行模式，禁止以省算力隐藏缺结果

| mode | 要求 |
|---|---|
| FULL_AUDIT | 指定所有因子/指标逐项得到COMPUTED或明确非计算状态；不隐式筛掉弱因子；输出完整率可对账 |
| RESEARCH_SIEVE | 按冻结阶段/门槛进行廉价初筛、诊断修复和入围精评；预算/淘汰原因记录；不把低保真当最终证据 |
| LIVE_MONITOR | 按指标可知时间和更新频率持续更新；未成熟预测指标排队，重统计/模型增量周期执行 |

用户“十万因子一起算”是统一任务可管理，不是承诺十万个全历史面板同时驻留一张卡。需要给出真实硬件、数据布局、指标实例数、保存级别、峰值资源、缓存冷热及失败率后，才能报吞吐与资源建议。

### 8.4 逐Bar能力表与状态大小

| 指标/制品 | 能否随新Bar更新 | 应有状态/成本 | 不允许的误解 |
|---|---|---|---|
| 当前因子值/finite/eligible覆盖 | 数据可见且截面满足watermark后可更新 | 当前截面、FE增量state | 部分股票先到即伪装完整截面 |
| 既定风险暴露/截面rank | 截面完成后可更新 | 每Bar截面排序/回归，不只是标量O(1) | 不读所有相关资产也宣称精确rank |
| H期IC/分层预测收益 | **旧信号的H期标签成熟时**可更新 | pending signal/ref/mask/label interval，成熟后计算 | 新Bar因子的未来20期效果已经知道 |
| IC均值/方差/raw ICIR/胜率 | 有合法新观察时可更新 | 每因子count/mean/M2等稳定状态 | Streaming Pearson求和可自动替代Spearman |
| 当前执行PnL/NAV/累计最大回撤 | 持仓与价格区间完成后可更新 | 现金/股数/融资/峰值/episode | 多期标签直接当当期PnL |
| 滚动均值/波动/换手 | 新观察进入、旧观察退出时可更新 | ring buffer与可删除状态、周期稳定重基 | append-only累计统计就是精确滚动统计 |
| 滚动最大回撤/水下恢复 | 有序窗口状态或有界重算 | 维护峰谷次序、删失episode和窗口边界 | 只保留一个全历史峰值就能正确删除窗口旧峰 |
| 中位数/分位/ES滚动 | 可用精确有序结构或声明误差的sketch | 内存与误差取舍单独声明 | 用均值/方差推导精确VaR/ES |
| HAC/复杂bootstrap/DSR/PBO | 适用地周期更新 | 完整或有界窗口序列及有效抽样计划 | 每Bar常数代价得到完整研究显著性 |
| 模型新增/替换与全局聚类 | 作为定时/触发研究任务 | 训练、图/样本快照及预算 | 当作普通O(1)流式指标 |

Sufficient statistics只能覆盖具备相应数学归并合同的指标。Spearman要先在真实joint截面内排名，之后可以对每日RankIC在线归并；不允许把原值Pearson的五个和直接换名RankIC。[C11/C24]

每个metric登记`update_mode = APPEND_EXACT / ROLLING_EXACT / APPROXIMATE / PERIODIC_RECOMPUTE / UNSUPPORTED`及label maturation、state schema/version、merge/retract能力。APPROXIMATE不能继承精确准入的认证身份。

### 8.5 迟到、修订与恢复

状态键至少是`metric_instance + factor_value_semantics + universe + clock + window + policy/implementation_version`，事件有幂等id和as_of。重复Bar不重复计样本；状态提交与输出checkpoint一致；崩溃后从最后完整checkpoint重放。

数据修订创建RESTATED_RESEARCH快照；AS_KNOWN/AS_TRADED记录保留当时可得状态。不能用最新修订值改写历史实盘输入再宣称当时模型正确。对修订影响区间按真实lookback/holding/window传播，支持retract的精确状态可回撤重算，否则局部回放。pending-label引用不能被失败值GC误删。

### 9.5 四条端到端闭环

**连续量价闭环**：DSL→FE/DA→初评→诊断高换手→少量FP/组合候选→同窗口QE净评价→非劣低成本选择→FA用途准入/簇归属→冻结更新。

**财务/事件闭环**：公告知识时间→事件/更新cadence→合法缺失→适用事件/期限评价→不被统一ties/stale门误杀→模型/LO用途→逐Bar成熟监控。

**纯多头避雷闭环**：底部组证据→冻结排除规则→真实LO净收益与基准→active IR/相对DD/容量→用途准入；不需要伪造short可借。

**库级替换闭环**：近重复候选→共同样本配对/成本→替换模型输入后OOF效用→新feature版本→旧版本可回滚→不再生产重复计算。
