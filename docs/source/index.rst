Overview
--------

The Quant Projects platform consists of several integrated modules:

* **DataAccess**: Unified data layer for market data, fundamentals, and alternative data sources
* **Factor Engine**: High-performance factor computation engine with 1000+ operators
* **Factor Preprocess**: Data cleaning, normalization, and preprocessing utilities
* **Factor Optimizer**: Portfolio construction and factor optimization tools
* **Factor Assets**: Asset universe management and filtering
* **Quant Evaluator**: Backtesting and performance evaluation framework
* **Research Control**: Experiment tracking and research governance

Key Features
------------

* **Multi-Market Support**: A-share and US equity markets with unified API
* **Point-in-Time Correctness**: Strict PIT validation for fundamentals and corporate actions
* **High Performance**: Polars, DuckDB, and Pandas backends with automatic optimization
* **Type Safety**: Comprehensive type hints and runtime validation
* **Production Ready**: Extensive test coverage, audit trails, and governance controls
