## 本轮修复

1. A/B 比较：零阈值下，相同指标不再判为 SUPERIOR；相同成本不再判为 CHEAPER。
2. 空指标、非数值、NaN/无穷大指标与成本明确拒绝；即使效用函数忽略坏指标，或候选分数看似更优，也不能跳过证据校验。
3. NumPy 成本数组不再触发布尔值歧义异常。
4. 胜出策略拒绝 NaN/无穷大/布尔权重；有意义改进阈值不能是非有限数。
5. 重复候选 ID 明确拒绝，防止字典覆盖评分证据。
6. 批量脚本逐因子记录读取、转换、对齐和输出异常；其他因子成功不能掩盖某个因子全部候选失败；能够读取的失败因子保留 RAW 兜底，RAW 自身无有效证据则标记 invalid。
7. 常量截面不再计为 0 IC；ICIR 直接复用 QE 的样本标准差（ddof=1）实现，单有效日、零方差不再冒充有效 0 分。
8. 恢复执行不能只看 parquet 是否存在：缺少完整成功元数据或带错误/invalid 的条目会重新进入待处理列表。

对应回归分别在 factor_optimizer/tests/search/test_paired_comparison_data_validation.py、test_winner_evidence_validation.py 及根目录 tests/jobs/test_optimize_factors_v2_failure_isolation.py。

## A/B 如何计算

固定候选 B 与原始因子 A，在共同有效日期、相同资产支持上取得逐日 Rank IC，记为 IC_B(t)、IC_A(t)。日差值：

$$d_t=IC_B(t)-IC_A(t).$$

用相同连续时间块重采样双方，而非独立重采样两个边际分布。第 b 次抽样的平均差：

$$\Delta_b=\frac{1}{|S_b|}\sum_{t\in S_b}d_t.$$

以这些平均差的分位数构造区间 [L,U]。只有 L>0 且 L≥事前声明的最小有意义改进，才认定更优；相等不叫改进。区间完全位于等价带内才认定等价，而不是“两个置信区间有重叠就等价”。

本轮确认性 A/B 使用事前声明的候选，不在 holdout 中挑最高者再沿用未经调整的 95% 区间。如果未来同时确认多个候选，应预先声明多重检验控制，例如 Bonferroni/Holm；不能把重复试验当作一项检验。

## 训练期怎么优化

1. 事前固定目标、最小资产数、覆盖率、成本模型、候选预算和时间切分；收益标签横跨切分边界时进行 purge/embargo。
2. TRAIN 内用时间顺序交叉验证选参数；方向、U/倒 U 中心、截尾阈值和时间尺度只能从训练信息拟合并冻结。
3. VALIDATION 比较冻结候选与 RAW，同时检查 Rank IC、覆盖率、换手/成本及跨时间稳定性。无有效数据不是 0 分；效果不明确时保留 RAW。
4. 参数和策略完全冻结后才看一次 TEST。根据 TEST 改参数后，原 TEST 不再是独立测试集。
5. 每个输入因子都应有成功、RAW 兜底、无效或错误记录；批量不能静默漏因子。

这些是正确的研究流程要求，不等于现有旧脚本已实现全部步骤。

## 尚未闭合的实际差距

- 现有 jobs/optimize_factors_v2.py 仍是全历史研究筛选，不具备严格 TRAIN/VALIDATION/TEST 的自动研究认证。修复逐因子可靠性并不改变这一点。
- 目前 FO 对平滑/衰减有公开版本化的研究执行桥；其他方法的底层原语不等于统一自动编译、训练状态冻结和暴露绑定已经完成。RAW、ABANDON 是控制语义，不是缺失的数值变换。
- 窗口/算子替换需要原始公式，行业/风格中性化需要正确对齐的暴露；只有一张因子数值矩阵无法推断这些输入。
- 没有收到用户实际批量因子、收益标签及时间切分，本轮未进行真实市场数据回放，也未发布任何生产因子。
- 批量旧脚本的恢复检查已要求输出与成功元数据同时存在，但尚不是内容寻址缓存。输入数据/配置改变后应使用新的研究活动及输出位置，不能假设旧结果会自动失效。
