# 批量优化 TRAIN-only 独立选择测试（2026-10-03）

测试入口：`tests/test_auto_selection_multi_factor_oracle.py`。

固定随机种子 20261003，240 个日期、40 个资产、6 个因子；标签为 AR 信号的平方。
覆盖负向因子、U 型信号、常数、全缺失、滞后信号与噪声，候选包括方向翻转、
U 型修复、倒 U 型修复、因果平滑与衰减细化。

独立选择规则：仅取 status=train_evaluated 且 train_gain 大于配置门槛的候选，

负向信号选 SIGN_ORIENTATION，U 型信号选 U_SHAPE_REPAIR；常数和全缺失拒绝。
