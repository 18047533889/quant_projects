# FE SMA A/B 基准（2026-09-30）

## 方法与结果

- 200,000 行：1,000 资产 × 200 观测，window=20；FP 使用 trailing_sma，FE 使用 FO 值级 SMA 的 long-Polars adapter。
- 两条路径都计入同一组身份重复检查；先运行一次 FE 冷调用，再交错运行 FP/FE 五轮。
- 每轮输出逐元素精确比较（rtol=0, atol=0, equal_nan=True），五轮均一致。
- FE 冷调用 12.0557 秒。热路径：FP 中位数 0.0802 秒，FE 中位数 0.0409 秒，FE/FP 吞吐约 1.96×。

## 有界分段剖析

相同 200k 面板上的单阶段计时量级。毫秒以下结果受计时器和调度影响。

| 阶段 | 观察值 | 说明 |
|---|---:|---|
| 每资产日期单调性检查 | 2.6–5.0 ms | 分组单调性，不逐个 boxing |
| 窄 Pandas frame 准备 | 2.5–4.2 ms | 选择和重命名输入列 |
| Polars 转换 | 0.5–1.4 ms | 一次性 pl.from_pandas |
| FE warm plan compile | 0.3 ms | 不含 Analyzer 初始化 |
| FE collect | 10.8–18.3 ms | long grouped lagged rolling |
| 批量日期/资产键验证 | warm 0.6–0.7 ms | Pandas Index 与 NumPy 数组 |
| 旧 Python list 键验证 | 310–330 ms | 逐行 tolist()/to_list() boxing |
| Series 返回 | 0.8–1.2 ms | 保留原索引，包括重复索引 |

首次 FE 调用包含 Analyzer/FactorEngine 初始化，约 12.06 秒；冷成本应与稳态热性能分开评估。

## 日期键与范围

持久回归测试覆盖 Asia/Shanghai 时区时间戳、Python datetime.date、字符串和整数日期键；键顺序和 SMA 输出与 FP 参考一致。该合成内存基准不是全形状/部署环境保证，不改变 FO 的 research-only 状态，也不是生产资格证据。
