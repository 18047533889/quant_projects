# 自动搜索中的配对 RankIC 复用

本功能只减少重复计算，不改变选优标准、候选集或公式。每个因子的 TRAIN
搜索持有一个最多两条序列的 PairICCache；不跨因子共享，也不用于
VALIDATION 或 TEST。不是磁盘缓存，不存储整批候选矩阵。

## 为什么不能无条件复用 RAW 指标

候选可能产生更多缺失值。令原始因子为 x，候选为 z，收益为 y：

$$A_{t,i}=\mathrm{finite}(x_{t,i})\land\mathrm{finite}(y_{t,i})
              \land\mathrm{validLabel}_{t,i},$$
$$C_{t,i}=A_{t,i}\land\mathrm{finite}(z_{t,i}).$$

逐日仍由 QE 计算三个 Spearman 相关系数：

$$r^{raw}_t=\mathrm{corr}_{Spearman}(x_t[C_t],y_t[C_t]),$$
$$r^{candidate}_t=\mathrm{corr}_{Spearman}(z_t[C_t],y_t[C_t]),$$
$$r^{full}_t=\mathrm{corr}_{Spearman}(x_t[A_t],y_t[A_t]).$$

候选收益是两条共同样本 IC 之差。full 只用来检查候选是否丢失了原始
可评分日期，不可用共同样本的天数作为自己的分母：

$$coverage=\min\left(
\frac{\sum_{t,i} C_{t,i}}{\max(1,\sum_{t,i}A_{t,i})},
\frac{\#\{t:r^{raw}_t,r^{candidate}_t\ \mathrm{finite}\}}
{\max(1,\#\{t:r^{full}_t\ \mathrm{finite}\})}\right).$$

缓存键含掩码后的 RAW 数值、标签原始字节及有效性、数值 dtype、形状和
minimum_assets 的 SHA256。不能先降精度再生成缓存身份。无效标签的原始
字节也参与键，只会多触发重新计算，不会误复用旧结果。
候选的共同样本改变就重新计算相应 RAW 序列；完整 RAW 对照通常可继续复用。
两者完全相同时，本次也只计算一遍。标签有效性、标签数值、RAW 或
minimum_assets 改变均不能拿旧结果冒充新结果。

命中时只让 QE 评估本次候选和未命中的参考列；仍走原 evaluate CPU 接口，
不另写 IC 公式、不改平值处理、不降精度、不删除难评分的日期。
LRU 容量固定为两条时间序列；读写均复制，调用者修改数组不会污染证据。
输出和置信区间应与关闭此缓存逐项相同，否则不能按性能优化发布。

## 验证

新增测试先观察到缓存缺失的失败，再实现。覆盖真实 QE 求值、缓存命中
减少计算列、五类输入变化失效、丢失 40/60 个有效日时覆盖率仍为 1/3、
容量限制和数组别名隔离。另用 longdouble 标签构造了 float64 下无法区分、
真实排序却不同的反例，复现并修复本缓存及已有联合指标缓存的误命中。
两处都改为带 dtype 的原始精度身份，九项专项测试通过。

最终 FO+FP 回归：1,762 passed、1 xfailed、16 warnings，133.82 秒。
HP 的既有非因果预期失败仍为 OFFLINE_ONLY。根 pytest：1 skipped、
14 collection errors、2 warnings，57.79 秒，失败模块清单同
[既有审查记录](METHOD_AUDIT_20260922.md)，没有声称根测试通过。
中间版本曾因 API 文档与源码不同步失败；重新生成后最终回归通过。

## 最终版本的真实因子 A/B

[原始逐次计时、因子来源与源码 SHA256](paired_ic_reuse_ab_20260922.json)。
通过 DataAccess 读取一次实际 COS 因子及行情，500 日×256 股票，95 候选，
bootstrap_draws=99。同一进程分别预热两条路径，再以旧/新/新/旧/旧/新
顺序各测三次。不缓存路径只关闭本次新增的配对 IC 缓存；两条路径均保留
已有的 RAW 联合指标缓存及其精度修正。没有拷贝代码树或减少搜索方法。

| 路径 | 三次完整优化用时（秒） | 中位数（秒） |
|---|---|---:|
| 不复用配对 IC | 33.987 / 33.814 / 33.820 | 33.820 |
| 复用配对 IC | 22.633 / 23.048 / 22.965 | 22.965 |

此工作负载耗时减少约 32.1%，约 1.473 倍。所有重复运行的最终数组
（含缺失）、每个因子的完整候选记录、指标、拒绝原因、选中计划均精确一致。
本次加速没有改变该因子验证不确认时保留 RAW 的决定，TEST 没有评分。
计时不含读取与 FE 冷初始化，不能推广为所有因子或机器的性能保证。
