# 联合多指标研究选优 joint.v1

`BatchOptimizationConfig.selection_objective` 默认改为 `joint`。
`rank_ic` 为显式历史复现模式；不因联合指标缺失而暗中退回该模式。
这不是生产准入：生产仍须完整 FactorFitnessSpec、交易约束、容量与治理证据。

## 组合与成本

仅支持不重叠的单期日收益标签；多期重叠收益必须先接入 cohort 组合会计，
不能直接当每日收益复利。QE 根据决策时的因子值划分五分位，顶层做多、底层做空，
平值规则沿用 QE 权威函数，不用未来收益是否缺失来重新选股。

$$w_{t,i}=\frac{1_{i\in L_t}-1_{i\in S_t}}{|L_t|+|S_t|},\qquad
TO_t=\sum_i|w_{t,i}-w_{t-1,i}|,$$

$$r_t=\sum_i w_{t,i}y_{t,i}-c\,TO_t,\quad w_{-1}=0.$$

总名义敞口为 1，股票等绝对权重；两端数量不同时并非每端各 50%。
成本默认 `research_cost_rate=0.001`（每单位交易名义金额 10bps），
含建仓成本。这是明确的研究假设，不是对实际佣金、冲击或融券成本的估计认证。
设置 0 可显式研究毛收益。选中股票收益缺失、未知净值路径均不填零。
比较使用共同信号可用范围，仍执行 RAW 有效资产/日期覆盖门槛。

### 因平值导致空腿时的预定持仓规则

默认 `research_empty_leg_policy='signal_cash'`。QE 的百分位边界和平值
归组可能在有信号差异时仍使顶层或底层为空。此时沿用 QE 的已定义目标
权重：不能同时形成多空两端，就不持仓，而非把已知空仓收益改为 NaN。
只有至少五个有限信号且最大值大于最小值的截面才适用；全常数、样本不足
或无有效信号仍不可用。IC 的 minimum_assets、覆盖率及非有限值门禁不变。

公式补充：若两端均非空，使用上面的等绝对权重公式；若信号符合上述条件
但任一端为空，则所有目标权重为 0。原有持仓退出仍收取
`cost_rate * turnover`，连续空仓且没有交易时净收益才为 0。
此决策只取决于当时的信号，不取决于未来收益是否缺失或涨跌。
没有持仓的股票不需要用未来收益填零；有持仓且收益缺失仍为 NaN。

可显式配置 `research_empty_leg_policy='unavailable'` 复现旧的空腿拒绝
规则。该配置写入 TRAIN 上下文、联合诊断、缓存键和最终报告配置摘要；
不能跨口径复用 RAW 指标，也不能改配置重新打开同一 TEST。
本调整没有改变 QE 分层本身、平值归组或二十分层统计，也不强行拆散平值
或用股票顺序挑选多空端。它是组合执行规则的一致化，不是缺失收益插补。

## 指标与目标

指标计算沿用 QE：RankIC、未年化 RankICIR、年化 Sharpe（252 日）、最大回撤、
三个按时间分块中最差的 Sharpe，以及平均全名义换手。

$$ICIR=\bar{IC}/s(IC),\quad SR=\sqrt{252}\,\bar r/s(r),$$
$$MDD=\max_t(1-V_t/\max_{u\le t}V_u),\quad V_t=\prod_{u\le t}(1+r_u),$$
$$SR_{worst}=\min_{b=1,2,3}SR(r_{b}).$$

固定研究效用（不在验证/测试期拟合权重）：

$$U=.40\tanh(SR/2)+.20\tanh(ICIR/.5)+.15\tanh(\bar{IC}/.05)
-.10MDD+.10\tanh(SR_{worst}/2)-.05\overline{TO}/2.$$

各候选必须先通过相对 RAW 的退化底线：

| 维度 | 允许的最大恶化 |
|---|---:|
| RankIC | 0.01 |
| RankICIR | 0.10 |
| Sharpe | 0.25 |
| 最大回撤 | 0.03（3 个百分点） |
| 最差分块 Sharpe | 0.50 |
| 平均全名义换手 | 0.25 |

零方差比率、缺失组合收益、负资本尺度无合同等均明确不可用，
不伪造为零或无穷优良分数。原始数据不足以比较时保留 RAW，不暗中削弱评估目标。
这些权重和底线是透明的初始研究政策，不构成全局最优或保证曲线持续上涨。

## TRAIN 与验证

TRAIN 按 `U(candidate)-U(RAW)` 选择唯一冻结方案；
原始 RankIC 三折增益仍写入候选记录，但不再单独决定联合模式的赢家。
最差分块 Sharpe 与退化底线约束时间稳定性。

VALIDATION 使用同一组移动时间块索引抽样 RAW 和候选的每日证据，
每次抽样重新计算 Sharpe、ICIR、回撤等非线性统计，再计算效用差，
复用 `compare_paired_draws`，不相减两个独立置信区间。
预先计算的每日换手随其原日期一起抽样，不把随机拼接边界当成真实新交易。

默认 499 次、5 日块、95% 区间。点估计退化底线也必须通过；
进一步修复要求效用差下界为正且至少 `minimum_improvement`（默认 .01）。
纯基础预处理使用相同联合口径的非劣门槛；
基础预处理 TRAIN 阶段另外保留 RankIC 明显退化保护。
验证失败返回 RAW，不换候选、不用 TEST 选优。

`joint_diagnostics` 和候选记录公开目标、成本、训练/验证指标及拒绝原因。
`train_gain`、`validation_lower_bound` 在联合模式下单位为效用差，
在历史 `rank_ic` 模式下才是 RankIC 差，不能跨模式直接比较。
