# FE 宽表结果回填性能

本轮只优化 FP 与 FE 之间的结果对齐，不改变 FE 的数学算子、预处理顺序、
滞后、缺失值规则、候选集合或评分阈值。

真实因子 weekly_db5616cd85a477b3 的 warmed cProfile 运行中，
完整搜索约 31.83 秒，6 次 _stack_back 累计约 6.57 秒，
其中约 48.64 万次 pandas 单值查询。这是带剖析器开销的定位数据，
不能作为无剖析器运行速度或加速比例。

旧实现构建每个 (时间, 资产) 的字典，再逐行查找。新实现使用两个
object Index 的批量位置映射与 NumPy 取值，保留以下语义：

- 输出严格对应调用方行顺序、原始行索引和 value 列名。
- 缺少的时间或资产键为 NaN；NaN 不变成零。
- 整数 1 与字符串 "1" 不混用。
- 时间戳与其字符串表示不自动合并；只有已规范化的相同身份才匹配。
- 允许调用方重复行索引，输出不与 FE 输入数组共享可变数据。

没有使用“已经验证”的标志跳过原有输入检查，也不缓存可变的因子数组。
参考测试覆盖手算映射、空模板、时区时间戳、混合身份类型、缺失键和
输出独立性；FE 算子对照测试仍覆盖实际桥接调用。
