# 截面 OLS 中性化的自由度与数值边界

输入是对齐的因子长表与暴露长表。每个日期独立计算，使用因子及所有
声明暴露均有限的共同样本，仍必须达到 min_observations。
重复列和重复暴露键拒绝；暴露名与因子值列同名时内部重命名，避免混淆。
输出保留调用方行序及重复索引标签。

## 正确的可拟合条件

当天全零暴露列没有信息，先删除；如 add_intercept=True，再加截距。
记处理后的设计矩阵为 A，有效股票数为 n：

$$\hat\beta=\arg\min_\beta\|y-A\beta\|_2^2,\qquad
e=y-A\hat\beta,\qquad df=n-\operatorname{rank}(A).$$

采用 numpy.linalg.lstsq 的数值秩，要求 df>0。
不能仅用原始列数代替秩：完整行业 dummy 加截距常有冗余，
没有理由因此丢掉仍有残差自由度的整个截面。
相反，n 个独立方向把 n 个样本完全拟合掉的饱和模型没有可用残差信号，
必须返回缺失，而不是输出浮点舍入后的小差异供下游排名。

## 完全解释的截面不产生伪信号

设 \(M=\max(\max_i|y_i|,\max_i|\hat y_i|)\)，
\(\tau=8\epsilon_{64}\max(n,p)\)，p 是删除全零列并加入截距后的列数。
若整个有效截面残差均有限，且 M=0 或

$$\max_i|e_i|/M\le\tau,$$

则整个有效截面输出精确零。不是逐个股票随意截断小残差，也不是固定
绝对阈值；有可分辨真实残差信号时继续保留该截面的残差。
零残差不意味着有 alpha，后续 RankIC 对常量应不可用；
不能把机器舍入差异排名成看似有截面预测力的因子。

删除全零列还使“追加任意数量未出现的行业类别”不改变求解矩阵和输出，
并避免大而空的设计矩阵拖慢计算。非零共线列仍由 lstsq 处理；
没有承诺任意病态缩放下都具有高精度，建议市值暴露采用明确声明的对数口径。

## 与自动优化的关系

优化库负责 available_time 检查、TRAIN-only 退化保护和单赢家 VALIDATION
确认。本数值内核不读取未来收益，也不证明外部暴露的历史可用性。
整个中性化流水线在 TRAIN 不合格时，优化库可再检验不含中性化的
缩尾/排名流水线，但必须明确记录未中性化，不能伪装成成功。

真实因子代数验证：256 股票×31 暴露，普通结果与旧实现完全相同；
附加 300 个全零行业列后旧实现全部缺失，新实现仍为原来的 256 个残差。
这不构成 PIT 回测或盈利证据。详细来源和边界见优化库
[基础预处理说明](https://github.com/HKUST-QUANT-SOCIETY/factor_optimizer/blob/main/docs/BASELINE_PIPELINE.md)。
