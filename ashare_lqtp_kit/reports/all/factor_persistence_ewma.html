Python 源码

def factor_persistence_ewma(df):
    df_copy = df.copy()
    returns = df_copy["close"].pct_change()
    abs_return_diff = returns.diff().abs()
    smoothness = -abs_return_diff.ewm(span=10, min_periods=1).mean()
    df_copy["factor_persistence_ewma"] = smoothness.fillna(0)
    return df_copy["factor_persistence_ewma"]

因子说明

收益路径平滑度（指数加权）

衡量最近几天涨跌幅是否连贯：相邻两日收益率变化越小，走势越「顺滑」，因子值越高。

计算步骤

  1. 计算日收益率 r = close 相对昨收的涨跌幅（ts_pct(close,1)）
  2. 计算相邻两日收益率之差的绝对值 |r − 昨日r|（刻画方向是否频繁反转）
  3. 对上述序列做 10 日指数加权平均 ema（近期权重更大）
  4. 最后取负号：变化越小 → 因子值越高

因子值怎么理解

因子值高：近期收益路径较平滑、方向较一致；因子值低：涨跌切换频繁、噪声大。

公式里用到的算子

  • ts_pct：n 日收益率：x 相对 n 天前的涨跌幅，即 x/delay(x,n) − 1
  • ts_delta：当前值减去 n 天前的值
  • abs：绝对值
  • ema：指数加权平均，越近的日期权重越大

计算步骤（DuckDB 面板，非 LQTP 平台回测）：
1) 每个交易日 T，对全市场股票按因子值升序分成 10 组（G1 最低 … G10 最高）；
2) 各组内股票等权，组收益 = 组内个股 T+1 相对 T 的前瞻收益均值；
3) 当日多空 gross = mean(G10 收益) − mean(G1 收益)；
4) 扣费：假设每日单边换手 40%，日成本 = 2 × 40% × (买0.01% + 卖0.01%) = 0.0160% ；net = gross − 日成本；
5) 多空 Sharpe = mean(日 net) / std(日 net) × √252；多空累计 = ∏(1+日 net) − 1。
注意：这是研究用十分位多空，不是可交易的 TopK 组合；TopK 见下方。

④ TopK 回测（LQTP 平台 · 开盘价）
