Python 源码

def factor_volume_abnormality_liquidity_gated(df):
    df_copy = df.copy()
    vol = df_copy['volume']
    median_vol = vol.rolling(20, min_periods=20).median()
    vol_ratio = vol / median_vol.replace(0, np.nan)
    raw = vol_ratio.rolling(15, min_periods=15).std()
    high_liquidity = df_copy['style_gate_liquidity_high'] > 0
    factor = np.where(high_liquidity, raw, raw * 0.7)
    df_copy['factor_volume_abnormality_liquidity_gated'] = factor
    return df_copy['factor_volume_abnormality_liquidity_gated']

因子说明

成交量异常 × 流动性门控

衡量成交量相对自身中位水平的偏离，但流动性太差的股票直接置零。

计算步骤

  1. 当日成交量 ÷ 20 日成交量中位数，得到相对放量/缩量程度
  2. 若 20 日平均成交额低于流动性阈值，因子 = 0（过滤不可交易标的）
  3. 否则输出成交量偏离得分

因子值怎么理解

因子值高：在可交易股票中明显放量；门控为 0 表示流动性不足被剔除。

公式里用到的算子

  • ts_mean：过去 n 个交易日的算术滑动平均
  • volume：成交量

③ 多空（G10 做多 − G1 做空）

怎么看图：多空累计净值曲线：每日做多 G10、做空 G1 的净收益（已扣假设换手成本）复利累积。曲线向上 = 高因子组长期跑赢低因子组；向下 = 反向。注意：这是研究用十分位多空，不是下方 TopK 可交易组合。

计算步骤（DuckDB 面板，非 LQTP 平台回测）：
1) 每个交易日 T，对全市场股票按因子值升序分成 10 组（G1 最低 … G10 最高）；
2) 各组内股票等权，组收益 = 组内个股 T+1 相对 T 的前瞻收益均值；
3) 当日多空 gross = mean(G10 收益) − mean(G1 收益)；
4) 扣费：假设每日单边换手 40%，日成本 = 2 × 40% × (买0.01% + 卖0.01%) = 0.0160% ；net = gross − 日成本；
5) 多空 Sharpe = mean(日 net) / std(日 net) × √252；多空累计 = ∏(1+日 net) − 1。
注意：这是研究用十分位多空，不是可交易的 TopK 组合；TopK 见下方。

④ TopK 回测（LQTP 平台 · 开盘价）
