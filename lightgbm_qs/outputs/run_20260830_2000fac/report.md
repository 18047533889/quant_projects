## 五、风险与合规提示

1. **换手率与持仓数据为代理口径**：2000fac 的 weights_final 已被 allfac 覆盖且无 git 历史，换手/持仓指标用同链同参数 818full 权重矩阵计算并已标注；两 run 的回测参数完全一致，代理误差主要来自因子集差异（783 vs 818 只）。

4. **口径红线**：收益一律 Vwap-to-Vwap 后复权；基准为中证全指 TR（000985.CSI）；T+1 执行、执行日 Vwap 成交。
