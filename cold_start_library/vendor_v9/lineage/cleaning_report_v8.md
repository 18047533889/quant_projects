# FactorEngine冷启动库V8清理报告

本版本对V7的 **8861** 条AST唯一因子重新做了剔除式复审。

## 最终结果

- V8保留：**6292**
- 删除/隔离：**2569**
- 默认核心+可派生字段池：**6163**
- 可选数据池（enriched/fundamental/microstructure）：**129**
- A股：**2924**
- 美股：**3368**

## 实际执行

对V7原有6458条production candidate使用820个交易日、20只股票的合成面板逐条执行：

- 通过：**6454**
- 失败：**4**
- 失败算子涉及：`ts_max_buildup`、`ts_moment`

## 删除规则

1. 非production candidate不再作为可执行冷启动库交付；
2. 删除真实运行失败、运行警告、尾部有效率低于10%的公式；
3. 删除恒等式、同输入回归残差、窗口不足的峰度等结构性错误；
4. 删除数据质量、字段一致性、缺失率等诊断指标；
5. 删除全市场聚合后对每只股票输出相同值的伪横截面因子；
6. 删除纯实验非线性映射和几乎恒定的离散化公式；
7. 删除rank下严格单调变换造成的排序等价重复。

## 注意

V8不再追求“所有语法算子都必须出现”。算子只有在能够构造生产可执行、非诊断、非恒等、具有个股区分度的公式时才保留。被删除记录及原因保存在`removed_factors_v8`中，但不会进入任何可执行因子池。
