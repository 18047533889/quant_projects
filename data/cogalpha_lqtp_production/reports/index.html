一、表格里的指标是什么意思

所有 IC 类指标都遵循同一对齐：T 日收盘后得到因子值，与 T+1 日收益率做相关。不使用未来数据。

  • Mean RankIC：每个交易日，把全市场股票的因子值做截面排序（名次），再与次日收益率的Spearman 相关系数；最后对所有交易日取平均。数值越大，说明“因子值高的股票，次日更容易涨”。
  • RankICIR：Mean RankIC ÷ RankIC 的日度标准差，类似“信息比率”。越大说明 RankIC 不仅高，而且每天比较稳定。
  • RankIC 胜率：RankIC > 0 的交易日占比。
  • LS Sharpe（多空夏普）：按因子值分成 10 组，做多最高组、做空最低组，用收益差算日度序列再年化除以波动。研究口径，主要看分层是否单调。
  • TopK Sharpe / 累计 / 回撤 / 年化：LQTP 平台回测。每日选因子值最高的前 10%（最多 50 只），次日开盘价等权买入，含平台费用假设。

怎么同时看 RankIC 和 TopK？

RankIC 衡量“排序对不对”；TopK 衡量“只买头部一组、按开盘成交”的组合表现。两者可能不一致，汇报时建议两个都看。

二、因子值是怎么算出来的（三条路径）

  • LQTP 原生 DSL 直算：公式直接提交 LQTP RunFactor，平台线上落值。
  • 自研 factor_engine DSL 落值：Python 转 DSL 后，用本地 factor_engine + COS A 股数据落值。
  • 纯 Python 落值：含平台暂不支持的逻辑，直接跑 Python 函数出因子值。

无论哪条路径，评估口径统一：RankIC / 分层 / 多空在本地面板重算；TopK 另走 LQTP OPEN 回测。

三、公式里常见算子（怎么算）

算子一句话具体算法
ts_pct(x, n)n 日收益率x 相对 n 天前 x 的涨跌幅，即 x/delay(x,n) − 1
ts_mean(x, n)n 日滑动平均过去 n 个交易日 x 的算术平均值
ema(x, n)n 日指数加权平均过去 n 日 x 的指数加权均值，越近的日期权重越大
ts_std(x, n)n 日标准差过去 n 日 x 的样本标准差，衡量波动大小
ts_delta(x, n)n 日差分x 减去 n 天前的 x
delay(x, n)滞后 n 日取 n 个交易日之前的 x 值
ts_max / ts_sum滚动最大/求和过去 n 日内 x 的最大值或累加和
rank(x)截面排序同一交易日全市场股票对 x 排序，映射到 0~1 分位
zscore(x)标准化(x − 均值) / 标准差，使不同股票可比
safe_div(a, b)安全除法a÷b；分母为 0 或缺失时返回空值，避免除零
where(条件, a, b)条件选择条件成立取 a，否则取 b（类似 if-else）
log / abs / tanh数学函数自然对数、绝对值、双曲正切压缩（把大数压到 −1~1）
cap(x, ε)下限截断把 x 限制在不小于 ε，防止 log(0)
ATR(h,l,c,n)平均真实波幅n 日真实波幅的滑动平均，衡量价格波动幅度
ROC(x, n)n 日变化率x 相对 n 天前的涨跌幅，同 ts_pct

说明：ts_* 按单只股票历史序列滚动；rank / zscore 为同一交易日全市场横截面运算。
