def factor_asym_vol_cont_gate_30(df):
    df_copy = df.copy()
    returns = df_copy['close'].pct_change()
    down_returns = returns.clip(upper=0)
    up_returns = returns.clip(lower=0)
    down_vol = down_returns.rolling(60, min_periods=20).std(ddof=0).clip(lower=1e-10)
    up_vol = up_returns.rolling(60, min_periods=20).std(ddof=0).clip(lower=1e-10)
    asym_vol = np.log(down_vol / up_vol)
    vol_ma = df_copy['volume'].rolling(20, min_periods=20).mean().replace(0, np.nan)
    vol_ratio = (df_copy['volume'] / vol_ma).clip(upper=3.0, lower=0.0)
    factor = asym_vol * vol_ratio
    factor = factor.replace([np.inf, -np.inf], np.nan).fillna(0)
    df_copy['factor_asym_vol_cont_gate_30'] = factor
    return df_copy['factor_asym_vol_cont_gate_30']

因子说明

下跌/上涨波动不对称 × 量比

分别统计下跌日、上涨日的波动率，取 log 比，再用成交量连续加权。

计算步骤

  1. 下跌日收益率（涨跌幅<0）→ 60 日 ts_std 得下跌波动
  2. 上涨日收益率（涨跌幅>0）→ 60 日 ts_std 得上涨波动
  3. log(下跌波动/上涨波动) × (volume/20日均量)
  4. zscore 标准化

因子值怎么理解

因子值高：下跌时波动相对更大（跌更乱）；因子值低：上涨波动主导。

公式里用到的算子

  • where：条件选择：条件成立取第一项，否则取第二项
  • ts_std：过去 n 日样本标准差，衡量波动大小
  • log：自然对数，常用于比值或压缩尺度
  • safe_div：安全除法：分母为 0 或缺失时返回空，避免除零
  • zscore：(值 − 均值) / 标准差，用于标准化
  • volume：成交量

分层回测（十分位 G1…G10）

怎么看图：横轴 G1~G10 为按因子值从低到高的十个分组（G1 因子最低，G10 最高）。纵轴为各组累计收益（复利净值 − 1）。理想情况：G10 明显高于 G1，且中间组大致单调递增，说明因子排序有分层能力。若 G1 与 G10 差距小或交叉，说明分层弱。

③

多空（G10 做多 − G1 做空）

怎么看图：多空累计净值曲线：每日做多 G10、做空 G1 的净收益（已扣假设换手成本）复利累积。曲线向上 = 高因子组长期跑赢低因子组；向下 = 反向。注意：这是研究用十分位多空，不是下方 TopK 可交易组合。

计算步骤（DuckDB 面板，非 LQTP 平台回测）：
1) 每个交易日 T，对全市场股票按因子值升序分成 10 组（G1 最低 … G10 最高）；
2) 各组内股票等权，组收益 = 组内个股前瞻收益均值（VWAP T+1→T+2）；
3) 当日多空 gross = mean(G10 收益) − mean(G1 收益)；
4) 扣费：按 真实 G10/G1 等权组合相对前日的单边换手 （0.5·Σ|w_t−w_{t-1}|，多空两腿相加）× (买0.01% + 卖0.01%)； net = gross − 日成本。日均换手/成本见上方卡片；
5) 多空 Sharpe = mean(日 net) / std(日 net) × √252；多空累计 = ∏(1+日 net) − 1。
覆盖率 = 当日（因子∩收益）股票数 / 收益宇宙股票数。
注意：这是研究用十分位多空曲线，用于观察因子单调性与分组收益。
