设计意图： This mutation preserves the parent’s lower-tail fragility mechanism: it measures the share of recent realized variance attributable to losses. A short causal exponential smoothing layer is added to reduce transient day-to-day shifts in the bounded concentration estimate, targeting more stable cross-sectional ordering and lower signal churn without introducing another economic feature family.

因子路由 / 公式   下行半方差平滑 (低下行波动 + 持续低风险溢价)

cs_rank(ema(span=5, ts_mean(20, neg_returns^2) / ts_mean(20, ret^2)))
依赖列: close

📝 计算步骤 (一步一步解释)

  1. 1) ret = (close - ts_delay(close,1)) / ts_delay(close,1) 当日收益
  2. 2) neg_returns = min(ret, 0) 仅取亏损部分
  3. 3) down_var = ts_mean(20, neg_returns^2) 20 日下行方差
  4. 4) total_var = ts_mean(20, ret^2) 20 日总方差
  5. 5) down_ratio = down_var / total_var 下行方差占比
  6. 6) smoothed = ema(span=5, down_ratio) EMA 平滑
  7. 7) factor = cs_rank(smoothed) 截面分位排名
说明：逻辑: 下行方差占比越低 → 收益分布越对称 → 风险越低 → 期望超额收益。已验证 FE DSL 实算时该公式可被 parser 接受 (近似)；个别因子因代码含自定义算子, 已用 closest 形式表达。
