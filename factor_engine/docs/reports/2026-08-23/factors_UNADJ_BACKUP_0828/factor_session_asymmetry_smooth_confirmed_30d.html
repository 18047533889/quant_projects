设计意图： Measures the normalized imbalance between downside and upside squared return shocks across overnight and intraday sessions. A 30-session rolling average smooths transient shocks, while a bounded EMA30 volume ratio provides lightweight participation confirmation without changing the core session-asymmetry mechanism.

因子路由 / 公式

multiply(divide(subtract(ts_mean(add(power(-(minimum(MYDSL("decompose_overnight_intraday", close, open, overnight_ret), 0.0)), 2), power(-(minimum(MYDSL("decompose_overnight_intraday", close, open, intraday_ret), 0.0)), 2)), 30), ts_mean(add(power(maximum(MYDSL("decompose_overnight_intraday", close, open, overnight_ret), 0.0), 2), power(maximum(MYDSL("decompose_overnight_intraday", close, open, intraday_ret), 0.0), 2)), 30)), add(ts_mean(add(power(-(minimum(MYDSL("decompose_overnight_intraday", close, open, overnight_ret), 0.0)), 2), power(-(minimum(MYDSL("decompose_overnight_intraday", close, open, intraday_ret), 0.0)), 2)), 30), ts_mean(add(power(maximum(MYDSL("decompose_overnight_intraday", close, open, overnight_ret), 0.0), 2), power(maximum(MYDSL("decompose_overnight_intraday", close, open, intraday_ret), 0.0), 2)), 30))), add(0.75, multiply(0.25, clip(divide(volume, ts_ema(volume, span=30)), 0.0, 2.0))))
依赖列: open, high, low, close, volume

📝 计算步骤 (一步一步解释)

  1. 1) (overnight, intraday) = decompose_overnight_intraday(close, open) [alpha_tools]
  2. 2) downside = ts_mean(30, (-min(o,0))^2 + (-min(i,0))^2)
  3. 3) upside = ts_mean(30, max(o,0)^2 + max(i,0)^2)
  4. 4) asymmetry = (downside-upside)/(downside+upside)
  5. 5) participation = 0.75 + 0.25*clip(volume/ts_ema(30,volume), 0, 2)
  6. 6) factor = asymmetry * participation
