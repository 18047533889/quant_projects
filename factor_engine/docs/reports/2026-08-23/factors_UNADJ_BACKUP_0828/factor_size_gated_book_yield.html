设计意图： Combine book yield (value) from parent1 with size-conditional adjustment from parent2: for small caps, apply leverage penalty to avoid distressed value traps; for large caps, multiply by ROE as quality boost. This transfers the size-gating mechanism from cash flow yield to book yield, leveraging the more stable book value.

因子路由 / 公式 ⚠ FE DSL 暂不支持

book_yield = 1/pb_lf; small_signal = book_yield * max(0, 1 - debttoassets/100); large_signal = book_yield * max(0, roe_ttm2/100); final = if size_small: small_signal, else if size_large: large_signal, else book_yield; then cs_rank
依赖列: pb_lf, debttoassets, roe_ttm2, style_gate_size_small, style_gate_size_large
