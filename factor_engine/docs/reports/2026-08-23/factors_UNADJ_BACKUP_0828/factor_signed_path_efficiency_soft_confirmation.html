设计意图： Uses 126-bar signed path efficiency as the core directional persistence signal and applies a bounded, continuous 63-bar confirmation weight. Recent efficiency magnitude controls the strength of the adjustment, while tanh-based directional agreement modestly boosts aligned trends and attenuates opposing trends without creating a binary gate or adding a separate feature family.
