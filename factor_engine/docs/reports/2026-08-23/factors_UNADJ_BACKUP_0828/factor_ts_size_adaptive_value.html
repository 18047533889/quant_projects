设计意图： Time-series size context: stocks that are relatively large in their own history use earnings yield; relatively small use book yield adjusted for leverage to avoid distress; in between, a blend. This conditions value on size without using cross-sectional size rank, and incorporates a leverage penalty for small-cap value. Cross-sectional rank is applied post-hoc for comparability.

因子路由 / 公式 ⚠ FE DSL 暂不支持

If rolling size percentile > 0.7: 1/pe_ttm. If < 0.3: (1/pb_lf) * max(1 - debttoassets/100, 0). Else average of both.
依赖列: pe_ttm, pb_lf, debttoassets, mkt_cap_float
