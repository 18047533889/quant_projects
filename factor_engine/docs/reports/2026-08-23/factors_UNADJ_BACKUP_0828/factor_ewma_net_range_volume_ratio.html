设计意图： Simplifies the asymmetry component by using net range (close-open) smoothed with a 5-day EWMA instead of separate up/down ranges with 10-day EWMA. This reduces code complexity and lag, targeting improved IC while preserving the volume ratio confirmation and the parent's RankIC strength.

因子路由 / 公式 ⚠ 已翻转（IC<0）⚠ FE DSL 暂不支持

-((ewm_mean(5, close-open) / ewm_mean(5, high-low)) * (volume / ts_mean(10, volume)))
