设计意图： Simplifies the parent by replacing the manual EMA volume ratio with the classify_volume_regime active tool, reducing code while preserving the economic mechanism: lagged return amplified by normalized volume and volatility, with regime-adaptive smoothing for robustness in high residual volatility states.

因子路由 / 公式

-(where(gt(style_gate_resvol_high, 0.0), ts_ema(multiply(multiply(subtract(divide(close, ts_delay(close, 5)), 1.0), log(clip(MYDSL("classify_volume_regime", volume, 30, vol_ratio), 1e-12, 1000000000.0))), divide(ATR_WILDER(high, low, close, 20), close)), span=10), ts_ema(multiply(multiply(subtract(divide(close, ts_delay(close, 5)), 1.0), log(clip(MYDSL("classify_volume_regime", volume, 30, vol_ratio), 1e-12, 1000000000.0))), divide(ATR_WILDER(high, low, close, 20), close)), span=5)))
依赖列: open, high, low, close, volume, style_gate_resvol_high

📝 计算步骤 (一步一步解释)

  1. 1) ret_5 = close/ts_delay(close,5)-1
  2. 2) vol_ratio = classify_volume_regime(volume,30).vol_ratio [alpha_tools 自命名 DSL]
  3. 3) log_vol_ratio = log(clip(vol_ratio, 1e-12, 上界))
  4. 4) atr_20 = ATR_WILDER(high, low, close, 20)
  5. 5) vol_adj = atr_20 / close
  6. 6) raw = ret_5 * log_vol_ratio * vol_adj
  7. 7) factor = where(resvol_high>0, ts_ema(10,raw), ts_ema(5,raw))
