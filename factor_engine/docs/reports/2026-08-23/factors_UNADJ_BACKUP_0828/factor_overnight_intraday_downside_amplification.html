因子路由 / 公式 ⚠ FE DSL 暂不支持

log(1 + (ts_mean(-min(overnight_ret,0)) + ts_mean(abs(close_ret))) / (ts_mean(max(intraday_ret,0)) + ts_std(high-low)))
依赖列: open, high, low, close, volume

算子

算子含义
loglog(x) → 自然对数 ln(x)
ts_meants_mean(x, n) → x 在过去 n 天的滚动均值 (rolling mean)
minmin(x, n) → 滚动最小值 / 或元素级 min
absabs(x) → 绝对值
maxmax(x, n) → 滚动最大值 / 或元素级 max
ts_stdts_std(x, n) → x 在过去 n 天的滚动标准差 (rolling std)

🔍 公式逐行拆解（算子释义）

  1. min(overnight_ret,0) — min(x, n) → 滚动最小值 / 或元素级 min
  2. abs(close_ret) — abs(x) → 绝对值
  3. max(intraday_ret,0) — max(x, n) → 滚动最大值 / 或元素级 max
  4. std(high-low) — std(x, n) → 滚动标准差
