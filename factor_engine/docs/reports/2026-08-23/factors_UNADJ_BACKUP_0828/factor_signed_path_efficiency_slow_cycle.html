设计意图： Measures the signed efficiency of the close price's 126-bar path and attenuates it by the absolute efficiency of the more recent 63-bar path. Persistent directional movement receives larger magnitude while choppy movement is reduced. Zero path lengths are treated as missing to avoid unstable division, and the function uses only current and trailing close observations.

因子路由 / 公式 ⚠ 已翻转（IC<0）⚠ FE DSL 暂不支持

-([(C_t - C_{t-126}) / sum_{i=0}^{125}|Delta C_{t-i}|] * |(C_t - C_{t-63}) / sum_{i=0}^{62}|Delta C_{t-i}||)

"kw">class="kw">def factor_signed_path_efficiency_slow_cycle(df): """Measure persistent directional phases with a slower recent path-efficiency confirmation.""" df_copy = df.copy() close = df_copy["close"] net_move = close - close.shift(126) path_length = close.diff().abs().rolling(126, min_periods=126).sum() efficiency = net_move / path_length.replace(0.0, np.nan) recent_efficiency = (close - close.shift(63)) / close.diff().abs().rolling(63, min_periods=63).sum().replace(0.0, np.nan) phase_signal = efficiency * recent_efficiency.abs() df_copy["factor_signed_path_efficiency_slow_cycle"] = phase_signal.replace([np.inf, -np.inf], np.nan) "kw">class="kw">return df_copy["factor_signed_path_efficiency_slow_cycle"]
