设计意图： Reversed long-term trend cycle position: flips the sign so that positive values indicate oversold (price below 200-day SMA) and negative values indicate overextended uptrend. This aligns the factor with mean-reversion intuition: buy oversold, sell overextended. Removing cross-sectional rank preserves the raw magnitude for direct payoff.

因子路由 / 公式 ⚠ FE DSL 暂不支持

-(close - ts_mean(200, close)) / ts_atr(20)
依赖列: open, high, low, close, volume
