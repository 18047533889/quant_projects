算子

算子含义
ts_mediants_median(x, n) → x 在过去 n 天的滚动中位数
absabs(x) → 绝对值
ts_meants_mean(x, n) → x 在过去 n 天的滚动均值 (rolling mean)
loglog(x) → 自然对数 ln(x)
