因子路由 / 公式 ⚠ FE DSL 暂不支持

where(gt(style_gate_resvol_high, 0.0), multiply(divide(-(divide(subtract(close, ts_max(close, 63)), ts_max(close, 63))), ts_mean(true_range(high, low, close), 63)), 0.5), divide(-(divide(subtract(close, ts_max(close, 63)), ts_max(close, 63))), ts_mean(true_range(high, low, close), 63)))
依赖列: open, high, low, close, volume, style_gate_resvol_high

📝 计算步骤 (一步一步解释)

  1. 1) peak = ts_max(close, 63) 63日滚动高点
  2. 2) dd = (close - peak) / peak
  3. 3) depth = -dd 回撤深度
  4. 4) tr = true_range(high, low, close) 真实波幅
  5. 5) atr = ts_mean(tr, 63) 63日 ATR（SMA 平滑）
  6. 6) normalized = depth / atr ATR 归一化
  7. 7) factor = where(high_resvol, normalized*0.5, normalized) 高残差波动期半权重
