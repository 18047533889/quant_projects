设计意图： Extends the drawdown geometry factor by incorporating volume-confirmed recovery. The parent's recovery slope is multiplied by relative volume rank so that only recoveries accompanied by elevated volume contribute strongly, introducing nonlinear interaction that can improve MI. Depth and duration components remain additive to preserve rank stability.

因子路由 / 公式 ⚠ FE DSL 暂不支持

add(add(rank(divide(subtract(ts_max(close, 252), close), ts_max(close, 252))), rank(duration)), multiply(rank(-(ts_delta(divide(subtract(ts_max(close, 252), close), ts_max(close, 252)), 5))), rank(divide(volume, ts_mean(volume, 20)))))
依赖列: close, volume

📝 计算步骤 (一步一步解释)

  1. 1) rolling_high = ts_max(close, 252) 252日高点
  2. 2) drawdown = (rolling_high - close) / rolling_high
  3. 3) duration = 自高点以来的天数（new_peak 分组 cumcount）
  4. 4) recovery = -drawdown.diff(5) 5日回撤加深的负值 = 恢复强度
  5. 5) rel_volume = volume / ts_mean(volume, 20)
  6. 6) 各项各自截面 rank（rank pct=True）
  7. 7) factor = rank(dd) + rank(duration) + rank(recovery)*rank(rel_volume)
