设计意图： Combines book-value yield with a leverage penalty to avoid distressed value traps, and a bell-shaped size weight that favors mid-cap securities. The size weight is derived from the stock's own trailing percentile of log market cap, emphasizing value when size is near its historical median range. Avoids monotonic size amplification and targets value with financial health in a moderate size window.

因子路由 / 公式 ⚠ FE DSL 暂不支持

book_yield = 1/pb_lf; leverage_adj = (1 - debt_ratio) clipped [0.1,1]; size_weight = 4*percentile_rank*(1-percentile_rank) clipped [0.1,1]; signal = book_yield * leverage_adj * size_weight
依赖列: pb_lf, debttoassets, mkt_cap_float
