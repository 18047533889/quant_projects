设计意图： Mutation from time-series quantile clip to z-score-based trimming. The core float-conditioned cheapness with leverage penalty is preserved. Rolling z-score trimming normalizes outliers by volatility, improving the Pearson IC without damaging the strong rank-based metrics (RankIC, RankICIR, MI). This directly targets the parent's IC bottleneck while preserving its rank and MI strengths.

因子路由 / 公式 ⚠ FE DSL 暂不支持

raw = (1/pb_lf) / log(1+free_float_shares) * 1/(1+debttoassets/100); then clip to rolling mean ± 3*std over 252 days

"kw">class="kw">def factor_float_conditioned_cheapness_ztrim(df): df_copy = df.copy() cheapness = 1.0 / df_copy["pb_lf"].replace(0, np.nan) float_adj = 1.0 / np.log1p(df_copy["free_float_shares"].clip(lower=1e6)) debt_ratio = df_copy["debttoassets"] / 100.0 penalty = 1.0 / (1.0 + debt_ratio) raw = cheapness * float_adj * penalty mean_ = raw.rolling(252, min_periods=60).mean() std_ = raw.rolling(252, min_periods=60).std(ddof=1) upper = mean_ + 3.0 * std_ lower = mean_ - 3.0 * std_ trimmed = raw.clip(lower=lower, upper=upper) "kw">class="kw">return trimmed.rename("factor_float_conditioned_cheapness_ztrim")
