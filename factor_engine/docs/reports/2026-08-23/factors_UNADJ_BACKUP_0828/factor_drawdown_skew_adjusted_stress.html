设计意图： Keeps drawdown volatility-adjusted stress as primary payoff mechanism (strong payoff evidence). Adds a lightweight bounded weight (0.8-1.2) based on 126-day return skewness to modulate the signal: negative skew (downside tail) amplifies drawdown signal, positive skew attenuates it. This addresses the parent's low rank IC by incorporating return asymmetry regime information from secondary parent.

因子路由 / 公式 ⚠ 已翻转（IC<0）⚠ FE DSL 暂不支持

-(stress = ts_sum(5, (close/rolling_max(close,20)-1)/true_range(20)) weight = 1 - 0.2*tanh(skew(returns,126)); factor = stress * weight)
依赖列: open, high, low, close, volume
