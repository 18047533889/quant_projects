设计意图： Captures drawdown depth normalized by trailing return volatility (rolling std of returns over 21 days). This sharpens the mean-reversion signal by using a more responsive volatility measure, potentially improving IC while preserving the core drawdown-depth intuition. Cross-sectional rank remains relevant for comparing relative depth across assets.

因子路由 / 公式 ⚠ FE DSL 暂不支持

depth = (close / ts_max(42, close) - 1) * -1; normalized = depth / ts_std(21, ts_pct(close))
依赖列: open, high, low, close, volume

📚 字段与算子释义

输入字段

字段含义说明
open开盘价当日首笔成交价，T-1 close 跳空缺口分析需要
high最高价当日成交最高价；计算日内振幅 / 上影线
low最低价当日成交最低价；计算日内振幅 / 下影线
close收盘价当日收盘价；多数因子都用 close 而非 vwap
volume成交量 (股数)默认未平减；反映参与度
depth回撤深度rolling_max(close, N) - close, 再除以 peak 归一
normalized归一化值标准化到 0~1 或 -1~1

算子

算子含义
ts_maxts_max(x, n) → x 在过去 n 天的滚动最大值
ts_stdts_std(x, n) → x 在过去 n 天的滚动标准差 (rolling std)
