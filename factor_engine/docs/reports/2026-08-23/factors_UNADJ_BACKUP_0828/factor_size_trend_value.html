设计意图： Combines earnings yield with a size trend deviation. When a stock is cheap (high earnings yield) and its market cap is shrinking relative to its own 60-day average (negative size deviation), the factor amplifies the signal. This conditions value on a size downturn, potentially capturing overlooked value in temporarily distressed small caps.

因子路由 / 公式 ⚠ FE DSL 暂不支持

size_trend_value = cheapness * -((log_size - ts_mean(60, log_size)) / ts_mean(60, log_size))
依赖列: pe_ttm, mkt_cap_float
