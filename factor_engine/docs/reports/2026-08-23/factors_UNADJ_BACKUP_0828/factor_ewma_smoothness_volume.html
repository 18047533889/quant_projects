设计意图： Mutate parent factor_return_change_smoothness by replacing rolling mean with EWMA for faster response, flipping direction so smoother price action (lower jitter) predicts continuation, and using continuous bounded volume scaling. Targets Price-Volatility Behavior layer: low return jitter confirmed by active volume indicates conviction.

因子路由 / 公式

-(multiply(ts_ema(abs(subtract(ts_pct(close, 1), ts_delay(ts_pct(close, 1), 1))), span=10), clip(MYDSL("classify_volume_regime", volume, 20, vol_ratio), 0.5, 1.5)))
依赖列: open, high, low, close, volume

📝 计算步骤 (一步一步解释)

  1. 1) ret = close.pct_change()
  2. 2) jerk = |ret - ts_delay(ret,1)| 收益二阶差（急动度）
  3. 3) smoothness = ts_ema(10, jerk) EWMA 平滑
  4. 4) vol_ratio = classify_volume_regime(volume, 20).vol_ratio [alpha_tools 自命名 DSL]
  5. 5) vol_weight = clip(vol_ratio, 0.5, 1.5)
  6. 6) factor = -smoothness * vol_weight
