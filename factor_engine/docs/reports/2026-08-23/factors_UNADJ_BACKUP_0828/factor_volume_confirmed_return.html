设计意图： Mutates the original price-volume coherence factor by using percentage price return instead of absolute price change, making the signal scale-invariant across stocks with different price levels. Volume confirmation mechanism is preserved. The multiplication by 10000 scales the factor to a typical range. 因子路由 / 公式 ⚠ FE DSL 暂不支持

factor = (close / lag(close) - 1) * (volume / ts_mean(20, volume) - 1) * 10000
依赖列: close, volume
