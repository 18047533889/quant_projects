设计意图： Mutates parent's leverage-adjusted earnings yield to use book yield (1/PB) instead of deducted earnings yield. Book value is more stable and less prone to negative earnings distortions, potentially improving predictive power while retaining the same leverage penalty mechanism.

因子路由 / 公式 ⚠ FE DSL 暂不支持

book_yield = 1/pb_lf; factor = book_yield * max(0, 1 - debttoassets/100)
