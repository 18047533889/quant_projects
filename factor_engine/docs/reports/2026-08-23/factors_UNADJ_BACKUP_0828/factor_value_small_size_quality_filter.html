设计意图： Value signals (book yield) are conditioned on size by applying a quality filter (positive ROE) only for stocks in a time-series small-cap regime (current float market cap below its 1-year rolling median). This avoids amplifying distressed small-cap value traps while preserving the cheapness signal for large caps. The mechanism uses size as a conditional gate, not a monotonic multiplier.

因子路由 / 公式 ⚠ FE DSL 暂不支持

PB_cheapness = 1 / pb_lf; if mkt_cap_float < ts_median(252, mkt_cap_float) AND roe_ttm2 <= 0 then nan else PB_cheapness
依赖列: pb_lf, roe_ttm2, mkt_cap_float
