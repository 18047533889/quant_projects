🔍 公式逐行拆解（算子释义）

  1. ts_std(neg_ret,20) — ts_std(x, n) → x 在过去 n 天的滚动标准差 (rolling std)
  2. ts_std(pos_ret,20) — ts_std(x, n) → x 在过去 n 天的滚动标准差 (rolling std)
  3. ts_mean(volume,20) — ts_mean(x, n) → x 在过去 n 天的滚动均值 (rolling mean)
  4. ewm(span=5) — ewm(...) → pandas 指数加权
