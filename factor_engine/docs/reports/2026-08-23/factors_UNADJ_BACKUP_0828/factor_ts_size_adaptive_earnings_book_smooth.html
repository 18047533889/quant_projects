设计意图： Smooth blend between earnings yield and book yield with leverage penalty, weighted by time-series size z-score via logistic function. This preserves the core economic intuition of size-adaptive value while improving signal continuity and reducing binary switch noise, targeting IC/ICIR improvement.

因子路由 / 公式 ⚠ FE DSL 暂不支持

-(add(multiply(divide(1.0, add(1.0, exp(-(clip(divide(subtract(mkt_cap_float, ts_mean(mkt_cap_float, 60)), ts_std(mkt_cap_float, 60)), -10.0, 10.0))))), divide(1.0, pe_ttm)), multiply(subtract(1.0, divide(1.0, add(1.0, exp(-(clip(divide(subtract(mkt_cap_float, ts_mean(mkt_cap_float, 60)), ts_std(mkt_cap_float, 60)), -10.0, 10.0)))))), multiply(divide(1.0, pb_lf), clip(subtract(1.0, divide(debttoassets, 100.0)), 0.0, 1000000000.0)))))
依赖列: mkt_cap_float, pe_ttm, pb_lf, debttoassets

📝 计算步骤 (一步一步解释)

  1. 1) size_z = clip((mkt_cap_float - ts_mean(60,mkt_cap_float))/ts_std(60,mkt_cap_float), -10, 10)
  2. 2) weight = 1/(1+exp(-size_z))
  3. 3) ey = 1/pe_ttm；by = 1/pb_lf
  4. 4) lev_penalty = clip(1 - debttoassets/100, 0, 大)
  5. 5) factor = weight*ey + (1-weight)*by*lev_penalty
