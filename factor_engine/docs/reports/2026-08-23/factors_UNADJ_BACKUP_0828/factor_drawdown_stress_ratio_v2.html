设计意图： Measures drawdown severity normalized by typical range, then modulated by volume: elevated volume during drawdown confirms selling pressure, improving payoff selectivity. Preserves core stress mechanism while adding volume confirmation.

因子路由 / 公式 ⚠ FE DSL 暂不支持

stress_ratio = -(close/ts_max(20)-1) / ts_mean(20, high-low); factor = stress_ratio * (1 + 0.5*vol_ratio)
依赖列: open, high, low, close, volume

📚 字段与算子释义

输入字段

字段含义说明
open开盘价当日首笔成交价，T-1 close 跳空缺口分析需要
high最高价当日成交最高价；计算日内振幅 / 上影线

vol_ratio量比volume / ts_mean(volume, N)，>1 放量,<1 缩量

算子

算子含义
ts_maxts_max(x, n) → x 在过去 n 天的滚动最大值
ts_meants_mean(x, n) → x 在过去 n 天的滚动均值 (rolling mean)
