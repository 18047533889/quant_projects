设计意图： Value signals conditioned on market cap size: small caps use book yield with leverage penalty to reduce distress risk; large caps use earnings yield with profitability boost. This avoids the distress amplification of dividing value by log size.

因子路由 / 公式 ⚠ FE DSL 暂不支持

If small-cap: (1/PB) * (1 - Debt/100); else: (1/PE) * (1 + ROE/100)
依赖列: pe_ttm, pb_lf, debttoassets, roe_ttm2, style_gate_size_small, style_gate_size_large
