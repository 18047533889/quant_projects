设计意图： Shorter-duration drawdown stress adjusted by volatility. Uses 10-day rolling max and 10-day ATR to capture more responsive drawdown depth, summed over 5 days. Preserves parent's payoff mechanism while aiming to improve predictive IC/RankIC by reacting more quickly to recent peaks. This compact mutation changes only the lookback windows, keeping the core economic intuition intact.

因子路由 / 公式 ⚠ 已翻转（IC<0）⚠ FE DSL 暂不支持

-(ts_sum(5, (close / rolling_max(close,10) - 1) / true_range(10)))
