设计意图： Mutated from the size-gated parent by removing the size gate (simplification) and adding time-series winsorization (local outlier control). The core float-conditioned cheapness with a universal leverage penalty preserves the economic mechanism: stocks with low PB, low free-float shares, and low debt are attractive. The winsorization reduces extreme values to improve the continuous IC without damag

因子路由 / 公式 ⚠ FE DSL 暂不支持

raw = (1/pb_lf) / log(1+free_float_shares) * 1/(1+debttoassets/100); then clip to rolling 1st-99th percentile over 252 days
依赖列: pb_lf, free_float_shares, debttoassets

🐍 原始 Python 代码 (factor_delivery)

"kw">class="kw">def factor_float_conditioned_cheapness_winsorized(df): df_copy = df.copy() cheapness = 1.0 / df_copy["pb_lf"].replace(0, np.nan) float_adj = 1.0 / np.log1p(df_copy["free_float_shares"].clip(lower=1e6)) debt_ratio = df_copy["debttoassets"] / 100.0 penalty = 1.0 / (1.0 + debt_ratio) raw = cheapness * float_adj * penalty low = raw.rolling(252, min_periods=60).quantile(0.01) high = raw.rolling(252, min_periods=60).quantile(0.99) winsorized = raw.clip(lower=low, upper=high) "kw">class="kw">return winsorized.rename("factor_float_conditioned_cheapness_winsorized")
