设计意图： Simplified mutation of the hybrid drawdown depth/ATR factor. Removes the volatility expansion ratio modifier to target the pure drawdown depth/ATR signal. The core contrarian drawdown mechanism is preserved: stocks with deep drawdowns relative to own volatility tend to mean-revert. Using talib.ATR for efficient computation.

因子路由 / 公式 ⚠ FE DSL 暂不支持

depth = (ts_max(63, close) - close) / ts_max(63, close); normalized = depth / ts_atr(high, low, close, 63)
依赖列: open, high, low, close, volume

📚 字段与算子释义

输入字段

字段含义说明
open开盘价当日首笔成交价，T-1 close 跳空缺口分析需要
high最高价当日成交最高价；计算日内振幅 / 上影线
low最低价当日成交最低价；计算日内振幅 / 下影线
close收盘价当日收盘价；多数因子都用 close 而非 vwap
volume成交量 (股数)默认未平减；反映参与度
depth回撤深度rolling_max(close, N) - close, 再除以 peak 归一
normalized归一化值标准化到 0~1 或 -1~1

算子

算子含义
ts_maxts_max(x, n) → x 在过去 n 天的滚动最大值
