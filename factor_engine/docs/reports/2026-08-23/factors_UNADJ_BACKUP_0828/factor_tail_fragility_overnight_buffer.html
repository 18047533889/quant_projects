设计意图： The primary mechanism preserves the payoff-first parent’s drawdown-conditioned downside-tail fragility signal. A single bounded modifier from the overnight-repricing parent attenuates the fragility penalty when recent price discovery is led by overnight repricing rather than intraday surrender, since that information-led return source can indicate better shock absorption than comparable intraday-l

因子路由 / 公式 ⚠ 已翻转（IC<0）⚠ FE DSL 暂不支持

-(20-day downside tail-energy share) × (60-day close drawdown) × [1 - 0.35 × clip((sum_20 overnight return - sum_20 intraday return) / sum_20(|overnight return| + |intraday return|), -1, 1)]
