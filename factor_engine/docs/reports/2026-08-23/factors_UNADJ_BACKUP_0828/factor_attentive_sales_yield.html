设计意图： Sales yield (1/ps_ttm) is a stable value metric. When free-turn (attention) is low, the undervalued signal is stronger as neglected stocks have more room for correction. Multiplying sales yield by inattention (1 - rank of free_turn) amplifies the value effect when attention is low, and attenuates it when attention is high. Forward-fill is applied to both components to reduce missing values while p
