设计意图： This expresses market structure through path geometry: a signed long-horizon net move is rewarded when the recent path is also efficient rather than oscillatory. The mechanism distinguishes directional accumulation or distribution phases from noisy cycle interiors without relying on moving-average level comparisons or serial-autocorrelation classifiers.

"kw">class="kw">def factor_signed_path_efficiency_cycle(df): """Measure whether the recent price path is forming a persistent directional phase.""" df_copy = df.copy() close = df_copy["close"] net_move = close - close.shift(126) path_length = close.diff().abs().rolling(126, min_periods=126).sum() efficiency = net_move / path_length.replace(0.0, np.nan) recent_efficiency = (close - close.shift(42)) / close.diff().abs().rolling(42, min_periods=42).sum().replace(0.0, np.nan) phase_signal = efficiency * recent_efficiency.abs() df_copy["factor_signed_path_efficiency_cycle"] = phase_signal.replace([np.inf, -np.inf], np.nan) "kw">class="kw">return df_copy["factor_signed_path_efficiency_cycle"]
