设计意图： This factor measures temporal consistency of returns using an exponentially weighted moving average of absolute consecutive return changes. The EWMA places more weight on recent observations, adapting faster to regime changes while still capturing persistence. Negative sign inverts so higher values indicate more persistent return direction.

🧮 计算步骤（DSL 算子链）

  1. 步骤1：col('AdjClose') → 取指定列字段（如 col('close') → 收盘价序列）
  2. 步骤2：ts_pct(v1(col)) → 1 期d 期变化率：(x − x_shift(d)) / x_shift(d)
  3. 步骤3：ts_delta(v2(ts_pct)) → 1 期n 期差分：x − x_shift(n)
  4. 步骤4：abs(v3(ts_delta)) → 计算绝对值
  5. 步骤5：ts_ema(v4(abs)) → 窗口 10 的n 期指数移动平均（EWMA）
  6. 步骤6：neg(v5(ts_ema)) → 返回-x
  7. 步骤7：fillna(v6(neg), 0) → 用指定值填充 NaN

🔬 陌生算子/字段释义

算子/字段含义

ts_pctd 期变化率：(x − x_shift(d)) / x_shift(d)

📝 计算步骤（一步一步解释）

  1. 1) returns = 日收益序列
  2. 2) abs(returns) 收益绝对值 (噪声/波动度)
  3. 3) ewma(span=10, abs_returns) 短期波动 EWMA
  4. 4) 取负: 越平稳越靠前
  5. 5) factor = cs_rank(...)
来源：手写步骤（factor_manual_61 / formula_lqtp 人工核对）
