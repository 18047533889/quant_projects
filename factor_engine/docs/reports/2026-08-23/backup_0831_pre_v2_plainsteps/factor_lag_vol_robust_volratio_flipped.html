📝 计算步骤 (一步一步解释)

  1. 1) ret = close/ts_delay(close,5)-1
  2. 2) range_med = ts_median(20, high-low)
  3. 3) range_mad = ts_mean(20, |range-range_med|)
  4. 4) range_z = (range-range_med)/range_mad
  5. 5) vol_ratio = classify_volume_regime(volume,20).vol_ratio [alpha_tools]
  6. 6) factor = ts_ema(10, ret*range_z*vol_ratio)
