## Status discipline

- `FIXED` requires a live implementation plus focused executable proof. It does not mean task #165 ran that proof.
- `FIXED_ALREADY_WITH_CURRENT_HEAD_PROOF` is used only where the requested mechanism predates this ledger or is an independently inspectable current implementation.
- `ARCHITECTURE_BACKLOG_WITH_MEASURED_JUSTIFICATION` is used for incomplete, opt-in, metadata-only, identity-only, or unmeasured behavior. An adjacent type or golden test is not behavioral closure.
- This ledger never uses `PARTIAL`, `OPEN`, `NOT_RUN`, or an invented status.
