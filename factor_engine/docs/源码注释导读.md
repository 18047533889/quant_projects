# 源码注释导读

> **零基础请先读**：[`FactorEngine完全指南.md`](FactorEngine完全指南.md) — 总文档。本文面向 **读源码** 的开发者。

阅读 `factor_engine` 源码时的 **注释约定** 与 **按目录导读**。各目录还有独立 `README.md`，本页做总索引。

---

## 1. 注释怎么写（维护者约定）

| 层级 | 要求 |
|------|------|
| **模块** | 文件顶部的 `"""..."""`：本文件职责、上下游、非职责 |
| **类** | 一句话用途 + 关键字段说明 |
| **公开函数/方法** | 参数、返回值、典型调用场景；复杂逻辑写「为什么」 |
| **私有函数 `_xxx`** | 至少一行说明输入输出；算法非显然时写步骤 |
| **算子类 `calculate`** | 类 docstring 写语义；`base_polars` 基类已统一 `calculate` 说明 |
| **嵌套函数** | 仅在逻辑非显然时补一行（如 numba `@njit` 内核） |

语言：**中文为主**，与现有 `runtime/`、`backend/` docstring 风格一致。

## 2. 数据流（先建立全局图）

```
api（DSL、Factor）
  → expr（ColumnRef / Literal / CleanedCall）
  → ir.Analyzer（Expr → IRNode，推导 lookback、引用列）
  → planner（IR → PlanNode，CSE、优化）
  → backend.execute（PlanNode → MultiIndex Series）
  → storage/materializer（可选落盘）

读数据：storage.DataAccessSource → data_access.get_store()
算子：cleaned_operators.OperatorRegistry.calculate()
编排：runtime.FactorEngine
```

## 4. 关键入口函数（建议先读）

| 函数 | 文件 | 作用 |
|------|------|------|
| `FactorEngine.run` | `runtime/engine.py` | 单因子编译+执行 |
| `FactorEngine.run_many` | `runtime/engine.py` | 多因子 + CSE |
| `build_data_source` | `storage/factory.py` | 构造 DataSource |
| `build_backend` | `backend/factory.py` | 选择 Pandas/Polars/SQL |
| `Analyzer.lower` | `ir/analyzer.py` | Expr → IR |
| `Lowerer.to_logical_plan` | `planner/lowerer.py` | IR → PlanNode |
| `PandasBackend.execute` | `backend/pandas_backend.py` | 递归求值 PlanNode |
| `compile_registry_op` | `backend/polars_registry_bridge.py` | Registry 算子 long 表编译 |
| `compile_plan_to_sql` | `backend/sql_pushdown/emitter.py` | Plan → SQL |
| `OperatorRegistry.get` | `cleaned_operators/registry.py` | 按 backend 取算子实现 |

## 5. 注释覆盖进度（2026-07 批量补全）

| 模块 | 状态 |
|------|------|
| `api/`（9 文件） | 全部函数/类已补中文 docstring |
| `planner/`（17 文件） | 全部已补 |
| `expr/`、`ir/`、`cache/`、`util/` | 全部已补 |
| `backend/`（52 文件） | 模块 + 公开 API + 大部分私有 helper；`numba_kernels.py` 为遗留可选加速 |
| `backend/polars_expr_emitter.py` | 67 个顶层函数 + 模块说明 |
| `backend/sql_pushdown/` | 9 文件全部已补 |
| `runtime/` | `engine.py` 全部 public 方法 + 主要 private；子目录 pipeline/quality/reconcile 已补 |
| `storage/` + `sources/` | 28 个实现文件已补 |
| `cleaned_operators/`（57 非测试 py） | **全部模块 docstring**；425+ 算子类 docstring |
| `scripts/`（21 文件）+ `run_pipeline.py` | 全部已补 |
| `tests/` | 测试函数有说明；不逐 assert 注释 |

**说明：** 部分文件仍有 **嵌套函数**（如 emitter 内 `walk`、polars 内 `_fn`）或 **Pandas 算子 `_calculate_series`** 等重复模式未逐行注释；语义以 [`operators_semantics.md`](operators_semantics.md) 与各类 `OperatorMetadata.description` 为准。
