## Decision rules

This ledger applies `AI_GUIDE/07_RESEARCH_CONTROL_AND_CORPORA.md`, `AI_GUIDE/11_PUBLIC_REPO_LESSONS_AND_LICENSE.md`, and `.claude/skills/quant-factor-platform-development/references/license.md` to the local working tree. The server checkout is the evidence source; repository URLs identify provenance but do not replace local license artifacts.

- Absence of a license is `unknown`, never an implied permissive license. Unknown source may be used only as `IDEA_ONLY` or isolated `CORPUS`; it may not be copied into a new runtime.
- `DIRECT_DEPENDENCY` means package/import linkage under its declared terms, not vendoring its source. `SOURCE_COPY` requires a license that affirmatively permits copying and preservation of all notices.
- A repository commit proves the inspected snapshot, not ownership or license. Monorepo path-specific commits below are the latest commits touching each path.
- Runtime-copy verdicts apply to Wave 0 and are engineering controls, not legal advice. Any external distribution still requires owner/legal confirmation and a locked dependency/notice review.

## GPL policy and final gates

The local artifact scan found no genuine GPL/AGPL declaration in GTJA, Week2, either LQTP tree, factor cold start, factor-pool-standard, AutoFactorEvaluation, toolkit, DA, or FE. The only affirmative third-party source license found in the scoped legacy trees was MIT for the exact AlphaPurify-origin subtree. This local result **does not override** the blueprint's GPL policy for external QuantSkills: those repositories remain `IDEA_ONLY` by default, GPL source is not copied into proprietary runtime, and corpus use requires repository-specific commit/license provenance.

Wave 0 release gates:

1. FE must receive an authoritative declared license before source distribution, vendoring, or external extraction.
2. A-share LQTP kit and LQTP Python examples remain unknown/unlicensed for reuse; no runtime/source/generated-code copy is allowed.
3. Every corpus adapter must store source path/repository, immutable commit or digest, source ID, license status, original formula/metadata, and translation/unsupported-semantics notes.
4. Every deployable package set must be locked and scanned from exact artifacts; lower-bounded `pyproject.toml`/requirements declarations are not an SBOM or transitive-license conclusion.
5. Any `SOURCE_COPY` must have a file-level mapping and preserved notices. The AlphaPurify MIT finding applies only to the proven subtree, not to `factor_layer` generally.
