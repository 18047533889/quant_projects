## 修复内容

修正旧参数位置和名称、字符串枚举、部分技术指标旧模板、财报单季字段与报告期绑定、布尔事件类型、泛参数输入绑定以及优化前后语义保持。对缺失财务数据保留空值，不填造未披露数值。

实际批量测试还修复了：
1. run 与 run_many 最终结果行顺序不一致，改为稳定的时间、股票排序并保留稀疏轴。
2. hammer 形态在正式实现中不可执行，以及无效行情被误标为命中的问题。

5. 连续收益率误传入布尔状态切换计数；改为显式 ret > 0 状态，并补规划期类型拒绝。
6. 支撑／阻力线的历史窗口不足以容纳所需确认拐点；精确旧模板改为 60 行历史，仍保留 3 个拐点要求。

部分改写属于用户授权的替代定义，不与旧表达式等价。例如状态定义、历史窗口和部分算子替代。表中保留原公式与逐项 migration_changes，不把这些改写标成等价转换。

## 剩余 1,011 条为什么失败

| 原因 | 条数 |
| --- | ---: |
| 字段未绑定，包括来源表、指数身份或字段缺失 | 295 |
| 语法错误、文字占位或参数数量限制 | 287 |
| 未注册算子或旧名称 | 218 |
| 参数名称、数量、范围或类型错误 | 181 |
| 输入语义或单位不匹配 | 24 |
| 标量参数仍是未定义符号 | 6 |

字段绑定失败不等于已证实服务器完全没有这类数据。例如 IndexReturn 缺少明确基准，ShareNumber 可能对应不同股东表。oi_spread、chip_profit_share 等尚未找到明确来源。另有自然语言说明而非 DSL 的单元格，以及缺少必要实体快照的关系算子模板。

没有用常数、随意换字段或关闭检查来制造“全部通过”。指数选择、事件方向、尾部概率等不明确定义仍需补齐。另发现的两项 Polars 问题（Kramers–Moyal local stability 和 entropy-production 参数元数据）已记录，尚未修复。
