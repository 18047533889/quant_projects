# factor_engine DSL — 可用字段与算子（A 股日频价量）
# 唯一合法语法：factor_engine（FactorEngine）函数式 DSL。
# 禁止 AlphaGen / qlib / pandas 表达式。
# 与 cold_start_library V9、disk.v1 投递一致（miner_delivery_spec）。
# 目标：下列白名单内算子均可使用；生成时应主动轮换不同算子族，勿只扎堆 ts_mean/rank。

## 0. 引擎与语法（必读）
- 引擎：factor_engine（我们自己的因子引擎）
- 写法：函数嵌套；字段名**不加** `$`
- 名称必须与白名单**完全一致**（含大小写：`RSI_WILDER`、`MACD_hist`、`ADX` 等）
- 合法：`rank(ts_mean(close, 20))`、`rank(RSI_WILDER(close, 14))`
- 非法：`$close`、`TsMean($close, 5)`、`Div(a,b)`、`Mul(a,b)`、`Ref(close,1)`、`close + open`、`%d`
- 禁止 Python 运算符 `+ - * /`；一律用 add/subtract/multiply/divide/safe_div_null

## 1. 字段（价量日频 + 估值；本地 COS 镜像可加载）
open       — 开盘价
high       — 最高价
low        — 最低价
close      — 收盘价
volume     — 成交量（股数）
vwap       — 成交量加权均价
pre_close  — 前收（构造收益优先用它）
amount     — 成交额
factor     — 复权因子（较少用）
pe         — 市盈率（估值）
pb         — 市净率（估值）
turnover_ratio — 换手率（估值）
market_cap — 总市值（估值）
circulating_market_cap — 流通市值（估值）

禁止：财报科目、美股专有字段（bid/ask、ret__overnight 等）、行业分组字段（当前挖掘引擎未接 industry）。
禁止裸写字段名 `ret`（A 股底层可能是 bp）；需要收益时写：
  `safe_div_null(close, pre_close) - 1.0`
  或 `ts_log_return(close, 1)` / `ts_pct(close, 1)` / `pct_change(close, 1)` / `returns(close)`

## 2. 常量与窗口
- 滚动窗口：正整数，从下列集合选取（短/中/长都要覆盖）：
  1, 2, 3, 4, 5, 7, 10, 12, 15, 18, 20, 25, 30, 35, 40, 50, 60, 70, 80, 90, 100, 120, 150, 180, 200, 220, 250, 300, 500, 800, 1000
- 技术指标常用：RSI/ADX/ATR 用 7/14/20；MACD 用 12,26,9
- 算术常数：0.0、0.01、0.001、0.0001、1.0、2.0、0.1、0.9、252.0 等
- 禁止科学计数法（写 0.0001，不要 1e-4）；禁止占位符 `%d`
- **单条表达式可含多个不同窗口**（推荐）：每个滚动算子各自写整数，不必全式共用一个窗口
- 长窗（≥250）更重；批内短/中/长搭配，勿全扎堆在 5/10/20

## 4.1 多窗口（单条内强烈推荐）
- rank(subtract(ts_mean(close, 5), ts_mean(close, 60)))
- rank(safe_div_null(ts_std(close, 10), ts_mean(close, 60)))
- subtract(rank(ts_delta(close, 5)), rank(ts_delta(close, 60)))
- rank(subtract(ts_rank(close, 20), ts_rank(close, 120)))
- if_else(gt(ts_mean(close, 5), ts_mean(close, 20)), rank(ts_delta(volume, 10)), rank(ts_delta(volume, 60)))

## 4.2 窗口档位
超短 1–5 / 短 7–20 / 中 25–60 / 中长 70–150 / 长 180–300 / 超长 500–1000
单式内嵌套滚动算子时优先跨档；一批内至少覆盖两类尺度。

## 4.3 算子覆盖要求（生成时）
在一批多条输出中，尽量让不同条目命中不同算子族，例如：
技术指标 / 相关协整 / 回归斜率 / 分位数与 topk / 条件计数 / 回撤夏普 / 截面稳健 z / 逻辑门控。
不要整批全是 `rank(ts_mean(...))` 换窗口。
